    WHERE WE ARE

    모든 도메인에 동작하는 경로가 있지만, 정의서의 규칙까지 채운 기능은 일부입니다. 자체 학습 모델은 파일럿 학습까지 했고 서비스에 연결되지 않았습니다. 일정상 다음 주(10주차)부터 추천 연동 · 성능 평가 · 통합 테스트 단계입니다.

    먼저 막아야 할 자리

    • 추천이 규칙 기반입니다. 공고 점수는 match-score.ts, 재료 추천은 materials/ranking.ts가 계산합니다. 모델 A · B를 부르는 AI학습서버가 없습니다.
    • 공개 사이트에 방문 수집기가 없습니다. 수집 API와 대시보드는 있지만 배포한 포트폴리오가 이벤트를 보내지 않아 방문 분석에 실데이터가 쌓이지 않습니다.
    • 6단계로 만든 포트폴리오는 편집 기능 대부분을 쓸 수 없습니다. 생성 지면에는 섹션 숨김 · 블록 편집 · 이력 · 복원 지점이 없습니다.
    • 커리어 편집기 v2가 운영에서 꺼져 있습니다. PR #101이 플래그를 지우는 작업입니다.
    • 관리자 권한과 관리자 화면이 없습니다. 공고 수집 소스 등록 · 수집 실행은 로그인한 사용자 누구나 호출할 수 있습니다.
    HOW TO READ

    판정 네 가지의 정의와 출처는 「판정 기준과 출처」 절에 있습니다. 「완료」는 정의서(docs/task-spec.js)의 동작과 규칙을 모두 충족하고 웹 화면에서 쓸 수 있을 때만 줬습니다.
