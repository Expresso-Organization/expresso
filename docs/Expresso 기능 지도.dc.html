F1.1카테고리 관리

F1.2기록 생성
직접 만들기 AI로 만들기 인터뷰에서 자동 생성 외부에서 가져오기 상태 자동 판정
F1.3기록 문서 편집
문서 패널 열기 속성 편집 AI 정리 블록 문서 단위 AI 요청 삭제와 영향 범위
F1.4뷰 · 필터 · 정렬
뷰 전환 5종 뷰 저장 필터 · 정렬 · 표시 속성 갤러리 카드 시각화 목록 집계
F1.5연결과 사용처 추적
기록 연결 사용처 표시 인용 문단 추적 중복 · 병합 제안
F1.6스킬 자동 집계
기록에서 스킬 추출 숙련도 산출 근거 열람 공고 수요 비교 숫자 연결 제안

F2.1수집과 정규화
정기 수집 사용자 직접 등록 필드 정규화 중복 제거 · 만료 신규 표시
F2.2자연어 검색 · 조건 해석
문장 → 조건 변환 조건 수정 · 재검색 결과 0건 대응 검색 저장 · 알림 최근 · 추천 질의
F2.3일치도 산출과 설명
점수 계산 4축 한 문장 사유 축별 충족 내역 낮은 점수 접기 결과 집합 요약
F2.4상세 열람 · 요건 대조
원문 렌더링 요건별 충족 판정 스택 대조 보강 경로 제시 기업 톤 정보 관심 공고 관리

F4.2생성 모드 · 분량 설정

F5.2응답 수집 · 기록 생성
