### 11쪽 · 추천 모델 평가 결과
- 제목: 추천 모델 평가 결과

  - 점수 오차(MAE): 막대 두 개. 파일럿 MLP 8.26점, 추천 모델 7.19점
  - 정답 점수와 예측 점수: 모델마다 산점도 하나. 가로가 정답 점수, 세로가 예측 점수, 점 하나가 프로필 · 채용 공고 한 쌍(1,280쌍 전부, 흔들기 · 표본 추출 없음). 두 축 모두 0 ~ 60, 대각선은 정답과 같은 예측
  - 요건별 근거 기록: 정답 근거 기록을 찾은 요건의 비율. 상위 1건 61.9%, 상위 2건 80.6%, 상위 3건 88.7%. 요건 종류별 상위 3건은 필수요건 89.3%, 담당업무 86.4%, 우대요건 89.8%. 아래에 Recall@3 74.4% · MRR@3 0.740
- 이 페이지의 결론: 파일럿 MLP는 한국어 채용 공고에서 순서를 가리지 못했고(순서 일치율 0.497), 추천 모델은 순위 지표 셋이 모두 오르며 요건의 88.7%에서 근거 기록을 찾음
- 레이아웃: 왼쪽 위에 순위 품질 막대와 MAE 막대, 왼쪽 아래에 산점도 두 개와 읽는 법 세 줄, 오른쪽 세로 칸에 요건별 근거 기록
- 시각화 방식: 파일럿은 회색, 추천 모델은 에스프레소색. 지표 이름 아래에 읽는 법을 한 줄씩 적음. 설계서 발표의 MAP@10 자리는 Spearman 상관으로 바꿈(한국어 평가에는 60점 이상 쌍이 한 건뿐이라 MAP을 낼 수 없음)
- 비주얼 에셋: 없음
- 근거 · 확인할 사항
  - NDCG@10 · Hit@3 · MRR@3 · Recall@3는 `codex/integration-match-release`의 `docs/assets/match-release-2026-11-19/evaluation.json` 값
  - 순서 일치율 · Spearman 상관 · MAE · 구간별 평균 예측 점수 · Hit@1 · Hit@2 · 종류별 Hit@3는 같은 실험의 예측값(`predictions/test.jsonl`)과 라벨(`test-pool/labels.jsonl`) 1,280쌍에서 2026-11-23에 다시 계산한 값. 같은 계산으로 NDCG@10 0.2362 · 0.5893, Hit@3 0.8869, MRR@3 0.7396, Recall@3 0.7444가 공식 값과 일치하는 것을 확인. 원자료는 저장소 밖(로컬 실험 백업 폴더)에 있음
  - 순서 일치율은 정답 점수 차이가 5점 이상인 쌍 13,303개에서 더 높은 쪽을 앞에 둔 비율. 예측이 같으면 0.5로 셈. Spearman 상관은 프로필별 값을 평균
  - 정답 점수는 평균 7.8점, 최고 60점. 구간별 평균 예측 점수는 추천 모델 7.5 → 10.6 → 12.1 → 14.7 → 19.0(정답 0–9 · 10–19 · 20–29 · 30–39 · 40 이상), 파일럿 MLP 7.2 → 7.2 → 6.3 → 5.1 → 4.7. 추천 모델의 예측 점수는 정답보다 낮지만 정답 순서대로 오름
  - 가상 계정 6명에서는 Hit@3가 45.8%(문단 검색 뒤 51.0%)로 낮음. 기록이 50 ~ 100건인 계정에서 근거를 놓침. Q&A 대비
  - 정답은 교사 LLM의 판정이며 사람이 따로 판정한 값이 아님
