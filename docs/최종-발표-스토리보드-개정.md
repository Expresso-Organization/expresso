### 11쪽 · 개발 범위
- 제목: 개발 범위
- 부제목: 사전 계획의 마일스톤과 실제 수행한 버전
- 이 페이지에서 보여줄 것: 윗줄에 제안서의 마일스톤 네 개, 아랫줄에 각 마일스톤을 수행한 버전. 추가 범위(1.1 ~ 2.0)는 2.0 공개 전이라 이 장에 넣지 않음

  | 마일스톤 (사전 계획) | 버전 (실제 수행) |
  | --- | --- |
  | M1 커리어 기록과 공고 탐색 | 0.1 개발 기반 구축, 0.3 커리어 기록, 0.4 공고 검색 |

  | M4 포트폴리오 배포와 방문 분석 | 0.6 배포 · 방문 분석, 1.0 설계 범위 완성 |

- 이 페이지의 결론: 계획한 마일스톤 네 개를 0.1 ~ 1.0으로 수행
- 레이아웃: 윗줄에 M1 ~ M4가 이어진 막대(칸 안에 마일스톤 번호와 이름). 아랫줄에 마일스톤마다 색이 옅게 깔린 묶음을 두고 그 안에 버전 카드를 쌓음. 줄 이름은 「사전 계획 · 제안서의 마일스톤」, 「실제 수행 · 버전」
- 시각화 방식: 제안서 「프로젝트 진행 마일스톤」의 이어진 알약 막대(칸마다 색이 진해짐). 버전 카드는 버전 번호 · 이름 · 한 줄 설명. M3 묶음은 추천 모델 개발 한 장에 네 단계를 적고, 1.0 카드만 어두운 색으로 강조
- 비주얼 에셋: 제안서 마일스톤 장의 막대 스타일. 버전 이름은 버전 히스토리 덱 2쪽
- 근거 · 확인할 사항
  - 마일스톤과 구현 범위는 제안서 「프로젝트 진행 마일스톤」, 버전은 PR과 커밋 기록
