# 3. 데이터 분석 및 전처리

제안서의 학습 과제는 사용자에게 맞는 **채용 공고 추천**과 지원 공고에 맞는 **커리어 기록 추천**이다. 두 기능은 커리어 기록과 채용 공고를 공통 입력으로 사용한다. 현재 서비스는 `jobs/match-score.ts`와 `materials/ranking.ts`의 규칙 기반 점수로 정렬한다. 아래 데이터셋과 학습 모델은 구축 계획이다.

## 3.1. 데이터 수집출처 및 수집방법

| 자료 | 출처와 처리 | 상태 |
| --- | --- | --- |
| 채용 공고 | `job_sources` 어댑터로 수집·정규화하고 `job_postings`에 저장한다. 공고의 요구 역량은 `job_posting_requirements`로 추출한다. | 수집·추출 경로 구현 |
| 커리어 기록 | 사용자가 입력한 프로젝트·경력·학력·역량과 AI 대화에서 보완한 역할·행동·성과를 기록한다. | 저장 경로 구현 |
| 합성 프로필 | 한국고용정보원 청년패널조사 YP2021의 학력·직업·경력 분포로 프로필의 골격을 구성하고, AI Hub 채용면접 인터뷰 71592의 실제 경험 서술을 조건으로 기록 내용을 합성한다. 사건·연차·수치는 근거 자료에서 보존하고, 출처를 남긴다. | 제안서의 구축 계획 |
| 적합도 라벨 | 프론티어 LLM이 공고 요구사항과 기록 ID를 연결하고 충족 수준을 판정한다. 고정된 루브릭으로 0–100점을 계산한다. | 제안서의 구축 계획 |

합성 데이터는 실제 사용자의 상세 기록이 충분하지 않은 초기 학습용이다. 생성한 기록의 입력 조건, 근거 자료, 검증 결과를 함께 저장한다. 실제 기록과 합성 기록은 평가 시 구분한다.

## 3.2. 데이터 전처리 및 입력 구성

공고에는 직무·주요 업무·필수 자격·우대 요건을, 프로필에는 경력 연차·기록 제목·기본 속성·본문을 포함한다. 중복 공고를 제거하고 개인정보를 마스킹한다. 학습·서빙에서 같은 텍스트 구성과 토큰화 규칙을 사용한다.

**1차 후보 선별**에는 사전학습 `multilingual-e5-base` 인코더를 사용한다. 프로필과 공고를 각각 최대 512토큰으로 인코딩하고 평균 풀링과 L2 정규화를 거쳐 768차원 벡터를 만든다. 두 입력은 가중치를 공유하며 인코더는 동결한다. 공고 벡터는 공고가 바뀔 때, 프로필 벡터는 기록이 바뀔 때 갱신한다. `multilingual-e5-base`, `KURE-v1`, `BGE-M3`, `Qwen3-Embedding-0.6B`는 같은 데이터와 평가 조건에서 비교할 후보이다.

**2차 재정렬**에는 선별된 공고와 관련 기록 최대 8개를 함께 입력한다. 관련 기록은 공고와 기록의 E5 코사인 유사도 상위 항목에서 고른다. 입력 길이와 기록 누락률을 함께 확인한다. 기록 추천은 같은 공고·기록 표현을 사용하되, 공고 추천의 2차 모델과 학습 단위·평가 집단을 분리한다.

## 3.3. 데이터세트 정의 및 생성

| 항목 | 공고 적합도 데이터셋 | 기록 적합도 데이터셋 |
| --- | --- | --- |
| 단위 | 프로필 × 후보 공고 | 공고 × 커리어 기록 |
| 용도 | 공고 추천 모델의 선별·재정렬 학습 | 재료 고르기의 기록 추천 학습 |
| 입력 | 공고 원문·요구사항, 프로필·관련 기록 | 공고 원문·요구사항, 개별 기록 |
| 라벨 | 루브릭 적합도 0–100 | 공고 요건과 기록의 관련성·근거 |
| 상태 | 제안서의 구축 계획 | 제안서의 구축 계획 |

제안서는 공고 적합도 학습용으로 **합성 프로필 1,000개와 프로필당 공고 10개, 총 10,000쌍**을 제시한다. 분할은 학습 8,400쌍, 검증 900쌍, 평가 700쌍이다. 같은 프로필이나 공고가 분할 사이에 중복되지 않도록 묶음 단위로 나눈다. 기록 추천용 쌍 수와 분할은 라벨 구축 후 별도로 확정한다.

교사는 요구사항별 근거 기록 ID와 충족 수준을 먼저 출력한다. 점수 계산은 코드가 수행한다. 필수요건 45%, 담당업무 40%, 우대요건 15%를 기본 가중치로 두고 해당하지 않는 축은 제외한 뒤 재정규화한다. 근거 강도는 강한 직접 근거 100, 직접 근거 75, 부분 충족 50, 인접 경험 25, 근거 없음 0으로 계산한다. 이 가중치와 점수 구간은 사람 평가와 비교해 타당성을 검증할 계획이다.

각 행에는 프로필·공고·기록 식별자, 원천 자료와 합성 조건, 교사 모델·프롬프트 버전, 요구사항별 근거, 루브릭 점수, 분할, 데이터셋 버전을 남긴다. 평가에서는 교사 점수와 사람 판정을 함께 비교해 라벨 오류를 확인한다. 모델의 측정 결과는 9.2에 기록한다.
