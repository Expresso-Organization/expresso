# 졸업작품 설계서 초안

가천대학교 컴퓨터공학과 졸업작품(네트워크보안프로그래밍) **AI트랙 설계서** 양식에 맞춘
초안이다. 양식 원본은 `설계서-AI트랙.hwp.pdf`(48쪽 템플릿)이고, 목차의 쪽번호가 곧 기대
분량이라 최종 제출본은 약 270쪽이 된다.

이 초안은 **2026-08-13 시점의 저장소 형상**을 근거로 쓴다. 확정을 기다리지 않고 지금
코드에 있는 것을 그대로 서술한다. 사실이 바뀌면 문서를 고친다.

## 문체

본문은 **평서체**(`~한다`)로 쓴다. 양식의 예시 본문과 `docs/architecture/`의 기존 설계
문서가 모두 평서체이기 때문이다. 저장소의 공유 문서(HTML)가 쓰는 존댓말과는 다르다.

## 그림

양식은 그림을 PPT 또는 UML 툴로 그려 캡처해 넣을 것을 요구한다. 본문 글씨크기와 그림 속
글씨크기가 같아야 하고, 화질이 선명해야 한다. 초안에서는 그림이 들어갈 자리를

> `[그림 N.N] 제목 — 필요한 내용`

으로 표시한다. 이 표시가 남아 있는 동안은 제출 가능한 상태가 아니다.

## 양식이 만드는 분량

세 규칙이 270쪽을 만든다.

- 기능 1개 = 시퀀스 다이어그램 1쪽 (6.2 · 6.3)
- 메뉴 1개 = 화면 설계 1쪽 (5.3 · 5.5)
- API 1개 = 설계 1쪽 (7.3)

현재 형상 기준으로 사용자 기능 151개, 화면 29개, API 125개다. 양식을 곧이곧대로 따르면
6장만 151쪽이 된다. 제출 분량은 지도교수와 조정해야 한다 — 이 초안은 조정 없이 전량을
목록화하고, 시퀀스 다이어그램은 대표 흐름부터 채운다.
