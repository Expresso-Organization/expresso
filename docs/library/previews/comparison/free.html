03

사례 상세

각 사례의 주인공은 화면입니다. 이미지는 가상 프로젝트를 위해 그린 설계 산출물입니다.

CASE 01 · 지역 탐색 서비스

모아 지도

동네의 공공 공간을 찾는 흐름을 정리한 탐색 서비스 콘셉트입니다. 장소를 비교하고 방문 계획을 저장하는 화면을 설계했습니다.

ROLE
UX 리서치 · 제품 설계
TERM
2026.01 — 2026.04
TAGS
UX Research, Product Design

01문제

시설 정보가 여러 화면에 나뉘어 있어 장소를 비교하기 어렵다는 상황을 가정했습니다.

02나의 기여

지도와 장소 목록을 함께 살펴보는 화면을 설계하고, 접근성 조건과 운영 시간을 비교 항목으로 정리했습니다.

03결과

장소 탐색에서 방문 계획 저장까지 연결되는 시제품을 구성했습니다. 실제 사용자 효과는 측정하지 않은 가상 사례입니다.

EVIDENCE 장소 탐색 흐름 장소 비교 기준

01문제

읽은 자료가 폴더 안에 쌓여 주제 사이의 관계를 다시 찾기 어려운 상황을 설정했습니다.

02나의 기여

기록 · 연결 · 재발견의 흐름을 정의하고, 관련 자료를 연결하는 화면과 읽기 목록을 구성했습니다.

03결과

자료 간 연결을 탐색할 수 있는 시제품을 구성했습니다. 이 화면은 가상 설계 과정의 결과물입니다.

EVIDENCE 기록의 정보 구조

CASE 03 · 공공 공간 안내

온길 안내

낯선 건물에서 필요한 시설을 찾도록 돕는 안내 화면 콘셉트입니다. 큰 글자와 간단한 선택지로 이동 경로를 표현했습니다.

ROLE
접근성 · UI 설계
TERM
2025.03 — 2025.06
TAGS
Accessibility, Design System

01문제

낯선 건물에서 층별 시설과 이동 경로를 함께 파악하기 어려운 상황을 다뤘습니다.

02나의 기여

목적지를 먼저 고르는 흐름과 계단 없는 경로 선택을 설계했습니다. 큰 글자와 설명이 있는 아이콘을 사용했습니다.

03결과

목적지와 이동 조건을 한 화면에서 선택하는 시제품을 구성했습니다. 실제 시설에 적용한 이력은 없습니다.

EVIDENCE 안내 화면 검토표

05

근거 자료

설계 판단의 바탕이 된 기록입니다. 제목을 눌러 펼치면 내용이 보이고, JavaScript 없이도 동작합니다.

모아 지도2

설계 기록 장소 탐색 흐름 검색부터 비교, 방문 계획 저장까지의 연결
  1. 검색어 입력
  2. 지도와 목록 탐색
  3. 운영 시간 · 접근성 조건 비교
  4. 방문 계획 저장

각 단계에서 필요한 정보가 이어지는지 확인하기 위한 가상 설계 기록입니다.

검토 기준 장소 비교 기준 비교 화면에서 놓치지 않아야 할 정보
  • 운영 시간
  • 이동 거리
  • 계단 없는 출입구
  • 이용 가능한 시설

위 네 항목을 항상 같은 순서로 표시합니다. 실제 기관에서 수집한 조사 자료를 포함하지 않습니다.

루멘 노트1

구조 설계 기록의 정보 구조 자료와 주제 사이의 관계
  • 01제목
  • 02요약
  • 03주제
  • 04관련 기록

자료에는 위 네 가지를 둡니다. 하나의 자료를 여러 주제와 연결하고 읽기 목록에서 다시 방문할 수 있게 설계한 가상 예제입니다.

온길 안내1

접근성 검토 안내 화면 검토표 큰 글자와 명확한 이동 선택
  • 글자 확대 시 정보가 잘리지 않는지
  • 키보드로 목적지를 선택할 수 있는지
  • 색상 외의 설명으로 경로를 구분할 수 있는지

가상 프로젝트의 안내 화면을 검토하기 위해 사용한 항목입니다.
