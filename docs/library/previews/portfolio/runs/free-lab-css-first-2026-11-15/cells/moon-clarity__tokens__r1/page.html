3일 걸리던 실험 리포트를 반나절로: A/B 테스트 분석 표준화

2025.08 – 2026.02

실험마다 새로 짜던 분석 노트북을 하나의 패키지와 화면으로 묶어, 리포트 시간과 필요 표본을 함께 줄였습니다.

문제

실험마다 분석가가 노트북을 새로 짜다 보니 결과 하나를 내는 데 3일 정도 걸렸습니다. 표본 크기 계산을 건너뛰는 경우도 있었습니다.

해결

실험 설계서 양식, 표본 크기 계산, 결과 리포트를 하나의 Python 패키지와 Streamlit 화면으로 묶었습니다.

CUPED

사전 기간 매출을 공변량으로 쓰는 분산 축소(CUPED)를 기본 옵션으로 넣었습니다.

결과

실험 결과 리포트 작성이 3일에서 반나절로 줄었습니다. 분기당 실험 수는 6건에서 15건으로 늘었고, 필요 표본 크기는 평균 약 30% 줄었습니다.
