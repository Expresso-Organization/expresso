LCP 3.8초를 1.9초로: 상품 상세 App Router 전환

전환 중에도 기존 주소와 SEO 메타를 그대로 유지했습니다. 배포마다 Lighthouse CI로 성능 예산을 검사했습니다. 데이터 요청 위치 결정, 캐시 무효화, 점진 전환 방법은 글로 정리했습니다.
