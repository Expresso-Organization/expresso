01 홈 피드 후보 생성 · 2020.06 – 2021.03

새 콘텐츠는 다음 날에야 후보에 들어가고, 오늘 본 이력은 반영되지 않던 배치 추천을 Two-tower로 바꿨습니다.

03 학습·배포 운영

지표가 떨어지면 배포되지 않는 학습 파이프라인

품질 기준을 사람이 아니라 파이프라인이 지키게 만들었습니다.

모델별로 따로 돌던 cron 학습 작업을 Kubeflow Pipelines로 옮기고, 평가 지표 기준에 못 미치면 배포를 막는 단계를 넣었습니다. 스트림온에서는 Airflow로 데이터 추출 작업을 스케줄링했습니다.
