01 대표 사례 · 2025.08 – 2026.02

3일 걸리던 실험 리포트를 반나절로: A/B 테스트 분석 표준화

실험마다 노트북을 새로 짜던 방식을, 설계부터 리포트까지 한 흐름의 도구로 바꿨습니다.

문제

실험마다 분석가가 노트북을 새로 작성하다 보니 결과 하나를 내는 데 3일 정도 걸렸습니다. 표본 크기 계산을 건너뛰는 경우도 있었습니다.

내가 한 일

실험 설계서 양식, 표본 크기 계산, 결과 리포트를 하나의 Python 패키지와 Streamlit 화면으로 묶었습니다. 사전 기간 매출을 공변량으로 쓰는 분산 축소(CUPED)를 기본 옵션으로 넣어, 통계적 엄밀성이 절차 안에 들어가게 했습니다.

결과

분기당 실험 · 이전6건
분기당 실험 · 이후15건

리포트 작성 3일 → 반나절. 필요 표본 크기는 평균 약 30% 줄었습니다. 같은 인력으로 실험을 더 자주, 더 적은 표본으로 돌릴 수 있게 됐습니다.

02 제품 분석 · 2023.11 – 2024.04

검색 후 나가는 세션을 검색어 유형별로 쪼개 보기

“클릭 없이 나가는 세션이 많다”는 막연한 문제를, 바로 실행할 수 있는 제안 하나로 좁혔습니다.

  1. 문제 제기검색 후 상품 클릭 없이 나가는 세션이 많다.
  2. 분해검색어 유형별로 이탈을 나눠 원인 구간을 좁혔다.
  3. 제안결과 0건 검색어 상위 200개를 정리해 동의어 사전 보강을 제안했다.
7.4% → 4.1% 결과 0건 검색 비율

동의어 사전 보강은 제가 낸 제안이며, 위 비율은 제안 이후의 변화입니다. 개선 전체를 단독 성과로 말하지 않습니다.

03 데이터 기반

분석이 기대는 데이터 기반을 직접 만들고 운영합니다

분석에 필요한 데이터를 기다리지 않고, 마트와 배치와 비용까지 직접 정비합니다.

데이터 마트
dbt 주문 데이터 마트를 dbt로 옮기며 모델 구조, dbt test, dbt docs를 운영했습니다.
배치
Airflow 데이터 마트 일일 갱신과 발주량 예측 배치를 DAG로 작성했습니다.
비용
BigQuery 파티션·클러스터링 설정으로 대시보드 집계 비용을 줄였습니다.
분석
SQL · Python 윈도 함수와 CTE로 업무 분석 쿼리의 대부분을 직접 작성합니다. pandas, scikit-learn, statsmodels로 모델링과 실험 분석을 합니다.
시각화
Tableau 고른마켓 판매자 대시보드를 만들고 운영했습니다.
