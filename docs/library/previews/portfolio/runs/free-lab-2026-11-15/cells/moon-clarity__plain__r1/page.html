대표 사례 · 2025.08 – 2026.02

3일 걸리던 실험 리포트를 반나절로: A/B 테스트 분석 표준화

분석 절차를 도구로 만들어, 팀이 더 많은 실험을 더 적은 표본으로 판단하게 했습니다.

문제

실험마다 분석가가 노트북을 새로 짜다 보니 결과 하나를 내는 데 3일 정도 걸렸습니다. 표본 크기 계산을 건너뛰는 경우도 있었습니다.

해결

실험 설계서 양식, 표본 크기 계산, 결과 리포트를 하나의 Python 패키지와 Streamlit 화면으로 묶었습니다. 사전 기간 매출을 공변량으로 쓰는 분산 축소(CUPED)도 기본 옵션으로 넣어, 통계적 엄밀성이 분석자의 기억이 아니라 절차에 들어 있게 했습니다.

모호한 문제 제기를, 바로 실행할 수 있는 제안으로 좁혔습니다.

  1. 문제 제기검색 후 상품 클릭 없이 나가는 세션이 많다.
  2. 분해검색어 유형별로 이탈을 나눠 원인 구간을 좁혔습니다.
  3. 정리결과 0건 검색어 상위 200개를 정리했습니다.
  4. 제안동의어 사전 보강을 제안했습니다.

위쪽이 제안 이전, 아래쪽이 이후입니다. 동의어 사전 보강은 제가 제안한 내용이고, 이 수치는 제안 이후의 변화입니다. 제 단독 성과로 읽지 않기를 권합니다.
