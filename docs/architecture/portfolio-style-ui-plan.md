# 포트폴리오 스타일 선택 UI 구현 계획

> 실행: 현재 작업 브랜치에서 테스트 → 구현 → 브라우저 확인 순서로 진행합니다.

**목표:** 승인받은 30종 스타일 필터와 미리보기를 기존 디자인 선택 화면에 연결합니다.

**구조:** 계약의 `TemplatePreview`를 화면에서 필터링합니다. 서체·밀도·구성과 화면에 표시한 팔레트는 계약 검증을 거쳐 생성 요청에 전달합니다. 외부 스타일은 카드 내부 견본에만 적용합니다.

**기술:** Next.js 16, React 19, Zod, CSS Modules, Vitest.

**기준:** `docs/Expresso Screens.dc.html`의 03 디자인 선택 화면 및 2026-08-28 사용자 승인.

## 제약

- 왼쪽 3열 카드, 오른쪽 요약·생성 버튼, 카드 선택 표시와 배지를 유지합니다.
- 필터는 기존 정의서의 필터 자리만 사용합니다. 밝기와 서체를 조합해 찾습니다.
- 필터는 선택을 바꾸지 않습니다. 결과가 없을 때 안내와 초기화 버튼을 제공합니다.
- 카드 견본은 최종 생성 결과가 아니라 스타일을 설명하는 미리보기입니다.
- 앱 색과 글자 크기는 기존 역할 토큰을 사용합니다. 미리보기 팔레트는 계약 데이터입니다.
- 운영 배포와 실제 AI 호출은 하지 않습니다. 구현 후 사용자와 화면을 확인합니다.
