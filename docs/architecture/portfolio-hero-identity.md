# 포트폴리오 첫 화면의 자기 정의

포트폴리오 첫 화면에서는 이름을 가장 큰 제목으로 표시하고, 바로 아래 한 문장으로 직무와 실제 작업을 설명한다.

- `profile.name`은 첫 화면의 유일한 `h1`이다. 이름의 글자 크기는 자기 정의 문장보다 크다.
- `profile.headline`은 이름 바로 아래에 놓는 자기 정의 문장이다. 줄바꿈 없이 짧은 한 문장으로 쓰고, 입력된 `profile.role`과 `profile.focus` 중 한 분야를 포함한다. 한글·한자·일본어는 두 단위로 세어 표시 길이 72단위 이내로 제한한다.
- 문장에는 다루는 대상과 수행하는 행동을 적는다. 경력·프로젝트 자료에 없는 성과나 전문성을 덧붙이지 않는다.

가상 예제의 입력은 다음과 같다.

> **서이준**
>
> 복잡한 자료의 정보 구조를 설계하는 서비스 디자이너입니다.

`profile.intro`는 그 아래에서 작업 방식과 맥락을 풀어 설명한다. 첫 문장이 추상적인 구호가 되지 않도록 콘텐츠 작성 단계에서 직무·대상·행동을 확인한다. 렌더러는 이름과 자기 정의의 위치를 모든 히어로 표현에서 동일하게 적용한다. 한 문장·직무·분야 검사는 `portfolio/v1/catalog.mjs`에 있고, 390px·1440px의 글자 크기와 위치는 브라우저 검증에서 확인한다.
