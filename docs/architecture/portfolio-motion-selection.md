# 포트폴리오 생성용 컴포넌트 모션 선별

코드가 확보된 섹션·콘텐츠 요소 368개를 점검하고, 현재 포트폴리오 데이터로 실행할 수 있는 원본 8개를 선별했다. 생성용 모션 컴포넌트 목록은 14종으로 확장했다.

- 코드 신호 기준으로 자체 애니메이션·스크롤·캔버스 효과 240개, 전환·호버 중심 103개, 뚜렷한 신호가 없는 항목 25개다.
- 선별 8개, 구조 참고 7개, 본문 후보 제외 5개, 후속 검토 348개다. 항목별 결과는 `docs/library/previews/portfolio/source-motion-audit.json`에 남겼다.
- 현재 생성용 조합은 기본, 카드 펼침, 벤토 세 가지다. 두 추가 조합에서는 제목·프로젝트·경력·근거·연락처 표현을 함께 바꾼다.
- 가상 인물·프로젝트 데이터만 사용하며, 숫자 성과와 코드 예제를 새로 지어 넣지 않는다.

## 생성 입력과 채택한 표현

| 수집 원본 | 생성 역할 | 모션·조작 | 연결 방식 |
| --- | --- | --- | --- |
| Watermelon `hero-1` | 소개 제목 | 원문 줄별 등장 | 원본의 제목 순차 등장 방식을 현재 소개 지면에 맞춤 |
| Componentry `annotated-text` | 제목 강조 | 등장 뒤 밑줄 그리기 | 수집한 원본을 렌더링하고 공통 실행기가 SVG 획을 제어 |
| Watermelon `bento-1` | 프로젝트 목록 | 크기가 다른 카드 순차 등장·이미지 확대 | shadcn Card에 프로젝트 화면·제목·사례 링크 연결 |
| Componentry `orbit-card-stack` | 프로젝트 목록 | 카드 선택·전면 배치 | 네이티브 라디오로 재구성해 키보드·저장 HTML에서도 선택 가능 |
| Magic Portfolio `timeline` | 경력 | 기존 노드·연결선·본문 등장 | 수집한 원본 타임라인 사용 |
| shadcn Timeline | 경력 | 번호·연결선·역할 설명 등장 | 기간·역할·조직을 리본형 목록에 연결 |
| Watermelon `preview-link-card` | 근거 자료 | 카드 순차 등장·본문 펼치기 | 외부 URL 없이 원문 요약과 본문을 네이티브 `details`에 연결 |
| Watermelon `contact-1` | 연락처 | 제목·카드 등장·이메일 화살표 반응 | 실제 입력에 있는 이메일 한 개만 표시 |

선별 상태는 개발 포털의 라이브러리 목록에도 반영한다. 수집 원본의 독립 실행 예제는 각 항목 상세에서 볼 수 있다. 생성용 조합에서 원본을 직접 쓰는 항목과 포트폴리오 데이터 계약에 맞춰 조합한 항목은 위 표에 구분했다.

## 구조 참고로 남긴 항목

차트와 코드 블록은 현재 입력에 검증된 수치·코드 본문이 없다. Magic Portfolio의 Work 섹션·Projects 섹션·Project Card는 현재 경력 타임라인과 프로젝트 카드 구성에 역할이 겹친다. 이 다섯 항목은 구조 참고로 보존한다.

Case Study Flip Stack은 카드 수에 따라 여러 화면 높이의 스크롤 구간을 만들고 현재 개별 사례 섹션과 내용이 겹친다. Sticky Scroll Cards는 문서 전체에 Lenis를 적용하며, Collection Surfer는 원본에 50,000px 스크롤 공간과 고정 화면이 있다. Kinetic Text Reveal 원본은 React 실행 전 제목을 숨겨 스크립트 없는 단일 HTML과 맞지 않는다. 이번 제목 순차 등장은 원문이 처음부터 보이도록 구성했다.

## 검증 기준

원본 코드의 문자열 신호는 실제 재생 품질을 뜻하지 않는다. 생성용 조합은 네 가지 가상 입력에서 원문·앵커·이미지 대체 표시를 보존하고, 390px와 1440px 화면, 키보드, 모션 감소, 저장용 HTML, 스크립트 없는 HTML을 확인한다. 모션 프리셋 `none`에서는 내용과 조작을 그대로 두고 전환 시간을 제거한다. 프로젝트가 5개를 넘는 Orbit 표현은 나머지 프로젝트를 같은 섹션의 링크 목록에 표시한다.
