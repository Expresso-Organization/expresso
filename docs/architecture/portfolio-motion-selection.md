# 포트폴리오 생성용 컴포넌트 모션 선별

코드가 확보된 섹션·콘텐츠 요소 368개를 점검하고, 현재 포트폴리오 데이터로 실행할 수 있는 원본 11개를 선별했다. 생성용 모션 컴포넌트 목록은 17종이다.

- 코드 신호 기준으로 자체 애니메이션·스크롤·캔버스 효과 234개, 전환·호버 중심 109개, 뚜렷한 신호가 없는 항목 25개다.
- 선별 11개, 구조 참고 7개, 본문 후보 제외 5개, 후속 검토 345개다. 항목별 결과는 `docs/library/previews/portfolio/source-motion-audit.json`에 남겼다.
- 기본·카드 펼침·벤토의 고정 조합 72개는 회귀 확인에 사용한다. 모델 생성에서는 선별된 히어로 3종과 프로젝트 목록 4종을 직접 선택한다.
- 가상 인물·프로젝트 데이터만 사용하며, 숫자 성과와 코드 예제를 새로 지어 넣지 않는다.

선별 상태는 개발 포털의 라이브러리 목록에도 반영한다. 수집 원본의 독립 실행 예제는 각 항목 상세에서 볼 수 있다. 생성용 조합에서 원본을 직접 쓰는 항목과 포트폴리오 데이터 계약에 맞춰 조합한 항목은 위 표에 구분했다.

모델 생성은 먼저 선별된 히어로·프로젝트 목록과 색·서체·배치를 선택하고, 이어서 이 선택을 제한 조건으로 삼아 json-render Spec을 만든다. 생성용 Registry에 등록한 17종과 수집 자료 1,127개 전체는 범위가 다르다. 이번 추가 3개는 원본의 구도와 상호작용 방식을 입력 데이터에 맞춰 재구성한 컴포넌트다. 같은 가상 입력으로 생성한 결과와 모델 출력은 `docs/library/previews/portfolio/runs/library-{ambient,spotlight,poster}-service-designer/`에 보관한다.

첫 화면은 [이름과 자기 정의 규칙](portfolio-hero-identity.md)을 따른다. 모든 히어로가 이름을 가장 크게 표시하고 직무·분야·작업을 설명하는 한 문장을 그 아래에 배치한다.

## 수집 라이브러리 전체 모션

수집된 컴포넌트 1,333개 중 실행 코드가 확보된 1,127개 예제에 모션 정책과 실행 브리지를 연결했다. 전체 목록과 분류 근거는 `docs/library/previews/component-motion-coverage.json`에 있다.

- 원본에 자체 모션 신호가 있는 442개는 원본 조작과 모션을 유지한다. 개발 포털 상세에서 원본 실행·모션 최소화·다시 재생을 제공한다.
- 나머지 685개에는 공통 등장 모션을 제공한다. 차분하게는 전체 요소의 짧은 등장, 쇼케이스는 주요 제목·카드·이미지·버튼의 순차 등장을 적용한다. 모션 최소화에서는 CSS와 Web Animations를 즉시 완료한다.
- 모션 최소화는 라이브러리 실행 예제의 미리보기 제어다. React Motion의 전역 설정과 `prefers-reduced-motion`도 함께 전달한다. 캔버스·GSAP·타이머 기반 원본 효과는 일부 남을 수 있으므로 항목별 `reduction` 상태를 보고서에 남긴다.
- 원본 확보나 이용 조건 확인이 필요한 206개는 실행 브리지 대상에서 제외했다. 이 가운데 188개는 이용 조건 검토, 18개는 원본 접근이 막혀 있다.

원본 HTML 재생성 후에는 `node scripts/library/renderer/build-component-motion-coverage.mjs`와 `node scripts/library/renderer/materialize-component-motion.mjs`를 실행한다. 각 원본 생성기에도 같은 브리지 삽입을 연결했다. 이 정책은 개발 포털의 수집 예제에 적용된다. 생성 파이프라인의 데이터 결합과 AI 컴포넌트 선택은 위 선별된 생성용 목록을 기준으로 이어서 개발한다.

## 구조 참고로 남긴 항목

차트와 코드 블록은 현재 입력에 검증된 수치·코드 본문이 없다. Magic Portfolio의 Work 섹션·Projects 섹션·Project Card는 현재 경력 타임라인과 프로젝트 카드 구성에 역할이 겹친다. 이 다섯 항목은 구조 참고로 보존한다.

Case Study Flip Stack은 카드 수에 따라 여러 화면 높이의 스크롤 구간을 만들고 현재 개별 사례 섹션과 내용이 겹친다. Sticky Scroll Cards는 문서 전체에 Lenis를 적용하며, Collection Surfer는 원본에 50,000px 스크롤 공간과 고정 화면이 있다. Kinetic Text Reveal 원본은 React 실행 전 제목을 숨겨 스크립트 없는 단일 HTML과 맞지 않는다. 이번 제목 순차 등장은 원문이 처음부터 보이도록 구성했다.

## 검증 기준

원본 코드의 문자열 신호는 실제 재생 품질을 뜻하지 않는다. 생성용 조합은 네 가지 가상 입력에서 원문·앵커·이미지 대체 표시를 보존하고, 390px와 1440px 화면, 키보드, 모션 감소, 저장용 HTML, 스크립트 없는 HTML을 확인한다. 모션 프리셋 `none`에서는 내용과 조작을 그대로 두고 전환 시간을 제거한다. 프로젝트가 5개를 넘는 Orbit 표현은 나머지 프로젝트를 같은 섹션의 링크 목록에 표시한다.
