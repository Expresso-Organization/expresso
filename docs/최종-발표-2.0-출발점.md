# Expresso 2.0의 출발점

작성일 2026-11-22 · 상태 초안 · 발표 자료의 10 ~ 12쪽이 이 문서를 따릅니다.

Expresso 2.0은 분절돼 있던 기능을 Expresso Agent의 채팅 인터페이스 하나로 묶어, 사용자와 사용자의 커리어, 포트폴리오가 함께 성장하는 구조를 만든 버전입니다.

- 1.0은 GUI 기반의 포털식 플랫폼입니다. 채용 공고 보기, 커리어 기록 작성, 포트폴리오 제작을 각각의 화면으로 제공했습니다.
- 1.0의 기능은 서로 이어지지 않았습니다. 작성할 활동이 없는 사용자는 시작할 수 없었고, 기록을 포트폴리오로 잇는 일은 사용자 스스로의 동기에만 의존했습니다.
- 2.0은 기능을 채팅 기반의 단일 인터페이스로 통합하고, Expresso Agent가 구직 목표 파악에서 포트폴리오 작성까지를 이어 줍니다.

## 1.0의 한계

1.0은 GUI 기반의 포털식 플랫폼입니다. 사용자는 메뉴에서 기능을 골라 들어가 각 화면에서 일을 마칩니다.

| 기능 | 1.0이 제공한 것 |
| --- | --- |
| 채용 공고 보기 | 공고 탐색 · 검색 · 상세 · 공고 분석 |
| 커리어 기록 작성 | 문서형 기록 편집기 · 속성 · 저장 뷰 |
| 포트폴리오 제작 | 재료 고르기 · 디자인 선택 · 생성 · 다듬기 · 배포 · 방문 분석 |

1. **기능의 분절.** 세 기능이 각자의 화면에 있고 서로 이어지지 않습니다. 공고를 본 뒤 무엇을 해야 하는지, 기록을 쓴 뒤 어디로 가야 하는지를 제품이 알려 주지 않습니다.
2. **커리어 기록이 없는 사용자.** 포트폴리오는 커리어 기록에서 만들어집니다. 작성할 활동이 없는 사용자는 기록을 쓸 수 없고, 제품을 쓸 출발점이 없습니다.
3. **사용자 스스로의 동기에 의존.** 커리어 기록을 쓰는 일과 그 기록을 포트폴리오 제작으로 잇는 일이 모두 사용자의 동기에 달려 있습니다.

## 2.0의 방향

**채팅 기반의 단일 인터페이스.** 분절된 기능을 대화 하나로 통합했습니다. 사용자는 Expresso Agent와 대화하고, 필요한 기능은 대화 안에서 열립니다.

**Expresso Agent 기준의 기능 묶음.** Expresso가 가진 기능을 Expresso Agent의 역할 순서로 다시 묶었습니다.

| 순서 | Expresso Agent의 역할 | 기반 기능 |
| --- | --- | --- |
| 1 | 사용자의 구직 목표를 파악한다 | 사용자 프로필 · 구직 목표 설정 |
| 2 | 목표 달성에 필요한 활동을 추천한다 | 채용 공고 · 공모전 · 해커톤 탐색, 부족한 역량 진단 |
| 3 | 커리어 기록 작성을 유도하고 보조한다 | 커리어 기록 |
| 4 | 기록을 포트폴리오로 작성하도록 돕는다 | 포트폴리오 제작 · 배포 |

채팅 기반의 단일 인터페이스가 기능의 분절을 해결합니다. 2번은 기록이 없는 사용자의 출발점입니다. 작성할 활동이 없으면 Expresso Agent가 목표에 맞는 활동부터 권합니다. 3번과 4번은 사용자 스스로의 동기에 맡겼던 기록 작성과 포트폴리오 제작을 Expresso Agent가 먼저 권하고 돕습니다.

## 2.0의 핵심

사용자, 사용자의 커리어, 포트폴리오가 Expresso Agent의 도움으로 동시에 성장하는 구조입니다.

- **사용자**는 추천받은 활동을 하며 목표에 필요한 역량을 쌓습니다.
- **커리어**는 그 활동이 기록으로 남으며 쌓입니다.
- **포트폴리오**는 쌓인 기록으로 만들어지고 새 기록이 생길 때 다시 작성됩니다.

1.0에서는 사용자가 이미 가진 기록으로 포트폴리오를 만드는 데서 끝났습니다. 2.0에서는 포트폴리오를 만드는 과정이 사용자의 다음 활동과 다음 기록으로 이어집니다.

## 버전과의 대응

| Expresso Agent의 역할 | 버전 |
| --- | --- |
| 채팅 기반 단일 인터페이스 | 1.1 대화형 홈 화면 · 1.2 새 공고 기반 AI 맞춤 제안 |
| 구직 목표 파악 | 1.3 사용자의 구직 목표 설정 |
| 활동 추천 | 1.4 사용자의 부족한 역량 진단 · 1.5 역량 보완 활동 추천 |
| 커리어 기록 작성 유도와 보조 | 1.6 추천 활동의 진행 확인 · 1.7 커리어 기록 작성 도움 에이전트 |
| 포트폴리오 작성 도움 | 1.8 포트폴리오 디자인 대화 · 1.9 포트폴리오 작성 과정 채팅 UI 기반으로 이전 |
| 통합의 완성 | 2.0 에이전틱 플랫폼 전환 |
