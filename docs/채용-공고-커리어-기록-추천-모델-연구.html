    채용 공고·커리어 기록 추천 모델 연구

    Expresso가 왜 자체 추천 모델을 만들려는지, 어떤 데이터를 넣고 어떤 결과를 내는지를 설명합니다. 모델을 처음 접하는 독자에게도 연구 방향과 검증 기준을 설명합니다.

    01

    제품에서 하는 일

    공고와 기록을 양쪽에서 연결합니다

    Expresso 사용자는 프로젝트, 업무 경험, 성과와 기술을 커리어 기록으로 저장합니다. 제품은 이 기록을 채용 공고와 연결해 지원할 공고를 추천하고, 포트폴리오에 넣을 기록을 고릅니다.

    모델받는 데이터내놓는 결과제품 화면
    채용 공고 추천 모델사용자의 커리어 기록 전체사용자에게 맞는 공고 순위홈 · 공고 탐색
    커리어 기록 추천 모델채용 공고와 사용자의 기록 목록포트폴리오에 쓸 기록 순위와 선택안재료 고르기
     두 모델은 같은 공고와 기록을 사용합니다. 순위를 매기는 대상과 실행 시점은 서로 다릅니다.
    현재 연구 방향

    공고와 기록의 의미를 이해하는 공통 표현 모델을 학습하고, 공고 추천과 기록 추천에 맞는 계산기를 각각 연결합니다.

    현재 제품 상태

    제품은 문자열 포함 여부와 토큰 중첩으로 순위를 계산합니다. 이 규칙을 연구 모델의 기준선으로 고정하고, 모든 후보를 같은 시험 데이터에서 비교합니다.

    02

    기본 용어

    처음 나오는 기술 이름을 풀어 씁니다
    용어뜻이 연구에서 하는 일
    LLM많은 문장으로 학습한 대규모 언어 모델합성 기록 생성 · 학습용 순위 판정 · 근거 설명 생성
    임베딩문장의 의미를 숫자 배열로 바꾼 값뜻이 가까운 공고와 기록을 빠르게 찾는 데 사용
    인코더텍스트를 임베딩으로 변환하는 모델공고 · 기록 · 사용자 프로필 표현 생성
    랭커후보마다 점수를 계산해 순서를 정하는 모델공고 목록과 기록 목록의 순위 계산
    재랭커상위 후보를 더 자세히 비교하는 모델빠른 검색 결과의 최종 순서 조정
    어려운 음성 예시겉모양은 가깝고 정답은 다른 짝연차·역할·조건 차이를 구분하는 학습에 사용

    이 연구에서 “독자 모델”은 Expresso가 데이터, 학습 목표, 모델 구조, 평가셋과 최종 가중치를 직접 소유하는 모델을 뜻합니다. 공개된 기초 언어 모델도 한국어 의미 표현 학습의 출발점 후보에 포함합니다.

    03

    추천 문제의 구조

    빠른 공고 검색과 세밀한 기록 선택

    채용 공고 추천 모델

    사용자의 커리어 기록 전체를 한 프로필 표현으로 모읍니다. 프로필과 가까운 공고를 먼저 찾고, 상위 공고의 연차·직무·근무 조건을 다시 확인해 최종 순위를 계산합니다.

    커리어 기록 추천 모델

    공고의 요건마다 관련 있는 기록과 근거 문장을 찾습니다. 최종 선택에서는 기록 하나의 관련도와 함께 전체 선택안의 요건 범위와 기록 간 중복을 계산합니다.

    기록 선택의 핵심

    비슷한 프로젝트가 상위 기록을 모두 차지하면 포트폴리오가 같은 강점을 반복합니다. 선택 점수는 관련도 + 새로 덮는 요건 + 근거 강도 − 기록 간 중복을 함께 반영합니다.

    04

    학습 데이터

    합성 데이터와 실제 검증 데이터를 구분합니다
    데이터만드는 방법학습에서 맡는 역할
    채용 공고국내 채용 사이트와 기업 채용 페이지에서 수집실제 직무·요건·조건 분포 제공
    합성 커리어 프로필직무·연차·기술·성과 구조를 정한 뒤 LLM으로 기록 생성직군과 희소 사례의 학습 범위 확장
    LLM 교사 라벨한 프로필의 공고 후보 또는 한 공고의 기록 후보를 비교순위·동률·근거 span 제공
    사람 라벨교사 결과를 가린 상태에서 독립 검수 후 합의교사 신뢰도 측정 · 최종 시험
    제품 행동노출·조회·저장·지원·기록 선택과 해제 기록운영 이후 개인화 학습

    합성 커리어 프로필 생성

    1. 프로필 구조 샘플링목표 직무, 연차, 산업, 기술, 프로젝트 규모와 근무 조건을 먼저 정합니다.
    2. 연결된 기록 생성한 사람의 경력 안에서 기간, 역할과 기술이 이어지도록 여러 기록을 생성합니다.
    3. 표현 변형 생성한국어·영어 혼용, 기술 약어, 짧은 기록과 긴 기록을 포함합니다.
    4. 논리 검증기간 충돌, 경력 연차 합계, 기술 사용 시점과 수치 근거를 검사합니다.
    5. 생성 이력 기록생성 모델, 프롬프트 버전, 원본 구조와 수정 내역을 데이터셋에 남깁니다.
    검증 원칙

    합성 데이터는 학습 범위와 어려운 사례를 넓힙니다. 실제 사람이 작성한 기록으로 구성한 봉인 시험셋이 최종 배포 여부를 결정합니다.

    이름, 성별, 나이, 국적과 학교 서열은 추천 피처에서 제외합니다. 이 정보는 한 항목씩 바꿔 순위가 달라지는지 확인하는 공정성 감사셋에 사용합니다.

    05

    모델 동작

    입력에서 최종 순위까지
    1. 공고와 기록 정규화기술 별칭을 같은 개념으로 연결하고 공고의 필수·우대 요건과 원문 위치를 보존합니다.
    2. 문장 의미 표현 생성한국어·다국어 인코더가 공고, 요건, 기록과 근거 문장을 숫자 배열로 변환합니다.
    3. 사용자 프로필 집계기록별 의미, 기간, 최신성, 카테고리와 검증 상태를 모아 프로필 표현을 생성합니다.
    4. 공고 후보 검색과 재랭킹프로필과 가까운 공고를 빠르게 찾고 상위 후보의 구조 피처를 자세히 비교합니다.
    5. 기록 세트 선택공고 요건을 넓게 증명하면서 중복이 적은 기록 조합과 근거 span을 선택합니다.

    처음 비교할 인코더

    후보강점확인할 점
    KURE한국어 검색에 맞춰 학습된 공개 모델기술 약어와 한국어·영어 혼용 공고 성능
    BGE-M3dense·sparse·multi-vector 검색과 긴 문서 지원서빙 메모리와 다중 벡터 지연
    Qwen3 Embedding다국어·코드 검색과 32K 입력, 여러 모델 크기한국어 공고 품질과 운영 비용
     공개 벤치마크 순위는 출발점입니다. Expresso 데이터의 동일 시험셋에서 최종 후보를 정합니다.

    상위 공고 재랭킹은 cross-encoder 또는 late-interaction 모델을 사용합니다. 기록 추천은 후보 수가 작고 비동기 처리 시간을 쓸 수 있어 세밀한 요건–문장 비교에 더 많은 연산을 배정합니다.

    06

    입력과 출력

    제품 계약으로 남길 값

    입력 피처

    묶음포함하는 값쓰임
    공고 텍스트제목 · 업무 · 필수·우대 요건 · 기술직무와 요구 역량 표현
    공고 구조직군 · 요구 연차 · 산업 · 게시·마감 시점의미 유사도가 놓치는 조건 보완
    커리어 기록제목 · 본문 · 성과 수치 · 역량 · 근거 문장사용자 기록에 있는 경험 표현
    기록 문맥기간 · 카테고리 · 상태 · 출처 · 최신성프로필 집계와 근거 강도 계산
    명시적 선호목표 직무 · 근무 형태 · 지역 · 급여 조건사용자가 정한 조건 반영

    출력 피처

    채용 공고 추천 모델커리어 기록 추천 모델
    rankScore — 공고 순위 계산값relevanceScore — 기록 관련도
    fitBand — 보정된 적합 구간marginalCoverageGain — 새로 덮는 요건의 양
    evidenceRecordIds — 근거 기록redundancyScore — 선택 기록 간 중복
    requirementIds — 관련 요건evidenceSpans — 근거 문장 위치
    confidence · 모델 버전selectedRank · confidence · 모델 버전
    점수 표시

    원시 랭킹 점수는 순서를 정하는 내부 값입니다. 실제 사람 라벨로 확률 보정을 마친 모델만 사용자 화면에 0–100 적합도 또는 확률로 표시합니다.

    추천 모델은 순위와 검증 가능한 근거를 계산합니다. 외부 LLM은 이 근거를 사용해 covered · partial · missing 판정과 사용자용 설명을 생성합니다.

    07

    학습 방법

    비교 · 순위 · 근거를 함께 학습합니다
    학습 목표모델이 배우는 내용
    양방향 대조학습맞는 프로필–공고와 공고–기록은 가깝게, 어려운 음성 예시는 멀게 배치합니다.
    공고 listwise 랭킹한 프로필에 제시된 공고 후보 전체의 상대 순서를 학습합니다.
    기록 세트 선택관련도, 요건 범위와 중복을 함께 반영한 기록 조합을 학습합니다.
    근거 정렬공고 요건과 기록의 근거 문장 위치를 연결합니다.
    교사 증류큰 LLM이 만든 순위와 판단 신뢰도를 작은 서빙 모델에 전달합니다.
    확률 보정내부 점수를 실제 정답 빈도에 맞는 신뢰도로 변환합니다.

    LLM 교사 라벨

    • 한 프로필의 공고 후보를 함께 보여 주고 순위와 동률을 받습니다.
    • 한 공고의 기록 후보를 함께 보여 주고 최종 기록 세트와 근거 span을 받습니다.
    • 후보 순서를 바꿔 같은 요청을 반복하고 위치 편향을 측정합니다.
    • 0–100 절대점수는 보조값으로 기록하고 비교 결과를 주 학습 라벨로 사용합니다.
    • 생성 모델과 교사 모델의 이름, 버전, 프롬프트와 실행 시각을 모두 기록합니다.

    어려운 음성 예시

    같은 직군에서 요구 연차가 다른 공고, 기술 이름이 비슷하고 역할이 다른 기록, 핵심 요건 하나가 비어 있는 후보를 학습에 포함합니다. 현재 모델 점수 상위권의 미라벨 후보는 별도 검수한 뒤 음성 예시로 사용합니다.

    08

    평가와 배포 기준

    실제 사용자 데이터가 최종 기준입니다

    시험 분할

    • 학습에 포함된 사용자와 새로운 공고의 조합을 평가합니다.
    • 새로운 사용자의 기록과 학습에 포함된 공고를 평가합니다.
    • 새로운 사용자와 새로운 공고가 함께 등장하는 조건을 평가합니다.
    • 특정 시점 이후에 수집된 공고와 행동으로 시간 순서 성능을 평가합니다.
    • 실제 사람이 작성한 기록만 포함한 봉인 시험셋을 별도로 평가합니다.
    평가 대상지표답하는 질문
    공고 검색Recall@50 · NDCG@10 · MAP관련 공고를 찾고 상위에 배치했는가
    기록 선택Precision@8 · 요건 커버리지@8 · 중복도쓸 만한 기록을 넓게 고르고 중복을 줄였는가
    근거span Precision · Recall · F1판정에 사용한 원문 위치가 맞는가
    신뢰도Brier score · ECE · 선택적 오류율모델 자신감이 실제 정답률과 맞는가
    공정성반사실 순위 변화 · 직군별 최저 성능민감 속성과 직군에 따라 품질이 달라지는가
    운영p50 · p95 지연 · 메모리 · 처리량제품 응답 시간 안에서 실행되는가
    배포 판단

    규칙 기반, BM25, LightGBM, 고정 임베딩, 학습 임베딩과 세트 선택 모델을 같은 데이터에서 비교합니다. 실제 기록 시험셋의 품질, 공정성, 신뢰도와 지연 기준을 모두 통과한 버전만 배포 후보가 됩니다.

    09

    연구 실행 순서

    단계마다 다음 투자를 판단합니다
    1. 데이터 계약과 평가셋 확정공고, 프로필, 기록, 라벨과 근거 span 스키마를 정하고 봉인 시험셋을 만듭니다.
    2. 기준선 재현현재 규칙, BM25와 LightGBM의 품질·지연을 같은 평가 코드로 측정합니다.
    3. 공개 인코더 비교KURE, BGE-M3와 Qwen3 Embedding의 한국어 공고 검색 성능을 비교합니다.
    4. Expresso 인코더 학습양방향 대조학습과 어려운 음성 예시로 공고·기록 표현을 미세조정합니다.
    5. 기록 세트 선택 모델 학습요건 범위와 기록 중복을 포함한 listwise 선택기를 학습하고 독자 모델의 기여를 검증합니다.
