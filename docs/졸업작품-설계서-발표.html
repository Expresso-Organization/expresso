01프로젝트 소개
설계서 1.1 · 3장

추천 모델 두 종

포트폴리오 생성은 외부 LLM, 두 추천은 이 프로젝트에서 학습하는 모델

모델 A

채용 공고 추천

「이 사용자에게 어떤 공고가 적합한가」

  • 입력: 사용자의 기록 전체
  • 출력: 적합한 공고의 순위
  • Bi-Encoder+MLP로 전체 공고 선별 → 상위 후보만 Cross-Encoder로 재평가
모델 B

커리어 기록 추천

「이 공고에 어떤 경험을 담아야 하는가」

  • 입력: 지원할 공고 하나
  • 출력: 포트폴리오에 담을 기록
  • 모델 A의 Cross-Encoder 재사용 — (공고, 기록 1건) 쌍을 채점

학습 라벨: 실사용 로그가 없어 LLM 교사가 매긴 적합도 점수(0–100)로 학습 · 「교사 지식 증류」에서 자세히

순위 지표

추천은 점수 하나가 아니라 공고의 순서를 정하는 일

스크리닝 · Bi-Encoder+MLP

Recall@K

적합한 공고를 상위 K개 안에 빠짐없이 남겼는가

상위 K개 안의 적합 공고 ÷ 전체 적합 공고
  • K개 안의 순서는 보지 않음
  • 여기서 빠진 공고는 재정렬에서 되살릴 수 없음
재정렬 결과 · Cross-Encoder

NDCG@10

상위 10개의 순서가 이상적인 순서에 얼마나 가까운가

DCG@k ÷ IDCG@k · 순위마다 log₂(순위 + 1)로 나눔
  • 0–1, 1이면 교사 점수 순서와 같음
  • 위쪽 순위의 실수를 더 크게 깎음

적합한 공고 = 교사 적합도 60점 이상 (ROC 양성 · MAP@10 · MRR@10과 같은 기준)
