# 운영 채팅 검색의 국가 표기 불일치
- 세션: 20261124-0318-chat-usability (T1.1)
- 문제: 모델이 country에 대한민국을 보내면 기존 한국 필터의 지역 목록이 비어 결과가 0건이 됨.
- 해결 방안: 수집의 지역 사전으로 국가 표기를 정규화하고 저장한 검색 조건·공고 필터·근무지 미확인 포함 정책에 함께 적용함.
- 사용자 기여:
  - 기여 측면: 운영 반영과 before/after 화면 보고를 완료 기준으로 지정함.
  - 접근과 판단: 개발 검사에 이어 운영의 실제 검색 결과를 확인하는 범위가 정해져, 모델의 실제 입력에서 발생한 국가 표기 불일치를 발견함.
- 결과: 타입 검사·단위 12개·실제 MongoDB 통합 68개 통과. 운영 재검증은 후속 배포 뒤 수행함.
