# 분석 빈 상태가 본문 왼쪽으로 치우침
- 세션: 20261124-0318-chat-usability (T6)
- 문제: AppBody는 가로 flex이고 blank에는 확장 규칙이 없어 안내 문구 폭만 차지함.
- 해결 방안: 기존 content를 재사용해 폭·여백·스크롤을 적용하고 blank를 남는 높이로 확장함.
- 사용자 기여:
  - 기여 측면: 화면 오류 발견과 재현 근거 제공.
  - 접근과 판단: 운영 분석 화면 스크린샷으로 넓은 본문의 왼쪽에 고립된 안내를 지목함. 이전 사용성 개선 작업에 포함하도록 작업 연결을 지정함.
- 결과: 해결됨. 5개 화면 크기와 사이드바 접힘에서 중앙 배치 확인. 전체 타입 검사와 테스트 통과.
