# 전체 준비와 Worker 변경 처리의 체크포인트 경합
- 세션: 20261122-1315-match-release-readiness (T2/T4)
- 문제: Worker가 삭제를 반영한 뒤 늦은 전체 준비 요청이 과거 스냅샷을 쓰면, 체크포인트 보존만으로는 벡터 참조를 바로잡지 못함.
- 해결 방안: 체크포인트 CAS 실패 후 원천을 다시 읽고 준비 시작 시점으로 CAS가 성공할 때까지 대조. CLI와 Worker 최초 준비가 같은 함수를 사용.
- 사용자 기여: 없음 · 에이전트 단독 해결
- 결과: 삭제 참조 복구와 준비 도중 변경 재처리 시점의 회귀 시험 2개 통과. 실제 전환·실패·복구와 운영 원천 재대조 통과.
