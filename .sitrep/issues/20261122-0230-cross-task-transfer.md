# 공고·프로필 리랭커의 요건·문단 전이 성능 저하
- 세션: 20261122-0203-evidence-retrieval-v2 (T3·T4)
- 문제: 기존 학습 Cross-Encoder를 새 문단 후보에 바로 적용하면 더미 계정 Hit@3가 41.8%였음. 기존 모델의 학습 목표는 공고 전체와 프로필의 부합도였음.
- 해결 방안: 기존 체크포인트의 마지막 두 층을 요건·문단 hard negative와 기록별 max loss로 추가 학습하고 같은 후보에서 Decisions와 대조함.
- 사용자 기여:
  - 기여 측면: 모델 비교 기준과 학습 전략 결정, 실행 자원 제공
  - 접근과 판단: 사용자가 범용 리랭커 도입 제안에 대해 기존 학습 리랭커와 Decisions의 비교를 지정하고 hard negative 반영을 선택함. 5080 PC를 SSH로 사용할 수 있다고 알려 실제 추가 학습과 비교를 실행할 자원을 제공함.
- 결과: 추가 학습 Cross-Encoder의 더미 Hit@3 54.9%, Decisions 76.5%. 한국어 표본에서는 로컬 근거 헤드가 더 높아 외부 검증을 선택형으로 유지함.
