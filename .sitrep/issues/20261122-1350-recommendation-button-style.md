# 추천 실행 버튼의 공고 화면 스타일 누락
- 세션: 20261122-1315-match-release-readiness (T5)
- 문제: 기존 공용 Button의 utility 스타일을 그대로 사용해 에이전트 화면 밖의 추천 버튼이 브라우저 기본 모양으로 표시됨.
- 해결 방안: 공용 Button 동작과 공고 화면의 `brewCta` CSS Modules를 재사용하고 보조 버튼·초점·비활성 상태를 기존 토큰으로 연결.
- 사용자 기여:
  - 기여 측면: 검증 범위 정의
  - 접근과 판단: 최신 main 통합과 실제 배포 전 검증을 요청해 기존 제품 화면에서 확인하도록 범위를 정함. 분리 브랜치의 빌드 통과에 이어 실제 공고 탐색·추천·근거 화면을 검증하는 기준이 됨.
- 결과: 실제 버튼 실행·근거 인용 화면 확인, 웹 585개 시험·빌드 통과.
