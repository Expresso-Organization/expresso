# 문단 검색의 요청당 토크나이저 복제 비용
- 세션: 20261122-0203-evidence-retrieval-v2 (T5)
- 문제: 새 인코딩 0건인 Oracle 단일 CPU 시험에서도 선택 공고 근거 검색 p95가 1.058초였음. 요청마다 큰 토크나이저를 직렬화하고 복제했음.
- 해결 방안: 부팅 시 검색 전용 토크나이저를 준비해 재사용함. 공고 순위 배치에는 문단 검색을 적용하지 않고 외부 검증은 이미 만든 후보를 재사용함.
- 사용자 기여: 없음 · 에이전트 단독 해결
- 결과: 같은 1공고·6계정·18순차요청 p95 56.5ms, 새 인코딩 0건. 207기록의 분할 결과 동일성·버전 재준비·후보 재사용 시험 통과함.
