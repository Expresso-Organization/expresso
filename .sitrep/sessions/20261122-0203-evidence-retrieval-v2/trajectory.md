# 근거 검색 개선 및 학습 리랭커 비교

## 2026-11-22

### 시작 · 사용자 지정 네 작업 이어받음
- 기존 모델 브랜치에서 새 워크트리 생성. 원본 백업은 읽기 전용으로 참조함.
- 원래 공고 점수와 새 근거 검색을 분리함.
- hard negative 학습: 한국어 train만 채굴하고 valid MRR로 선택. 원래 헤드를 epoch 0 후보로 유지함.
- API 키: 사용자가 이 작업 환경에 설정하기로 답변함. 키 값은 열람하지 않음.

### T2 완료 · 문단 검색과 제품 인용 연결
- 제목·문단·속성의 원문 위치 보존, 혼합 후보 검색과 기록별 집계 구현. 인증 API에서 소유권과 인용 원문 대조함.
- 전체 typecheck·test 통과. test:infra 350건 통과, 모델 API 추가 시험 4건·웹 인용 시험 1건 통과.
- 첫 문단 검색만으로 persona Hit@3 43.8%, 기록 hard negative 헤드 47.7%. 후보 회수율은 cap 12/24/48에서 77.1/90.2/97.4%임.
- 모델 B의 문단 입력 분포 차이를 다루기 위해 기록별 max 문단 점수로 학습하는 실험을 5080 PC에서 시작함.
- PC에 기존 공고-프로필 Cross-Encoder 체크포인트 확인. 같은 후보에 전이 적용해 비교할 예정임.

### 완료 · 근거 검색 개선 및 학습 리랭커 비교
- pnpm typecheck·test, 웹·백엔드 빌드, 변경 모델 API 인프라 4건·인용 원문 2건, Python 검색 4건·서비스 영속화 4건 통과함.
- 실제 인증 제품 API에서 근거 인용 19개와 추천 6개 반환, 소유권·원문 대조 통과함.
- CPU 배포 파일을 새 폴더에서 PyTorch 없는 환경으로 복원해 추천·근거 조회 실행 통과함. CPU archive와 CE 가중치의 SHA256을 배포 명세에 기록함.
- 평가 원자료의 집계·학습 이력·동일 후보 대조·Oracle CPU 실측과 한계를 docs/architecture/evidence-retrieval-v2.md 및 docs/assets/evidence-retrieval-2026-11-22에 기록함.
- 남은 전달 단계는 최신 main 통합·팀 레포 push·운영 배포임. 현재 변경의 구현과 검증 범위에서 완료됨 100%로 마감함.
