# 역할

입력 context의 10명을 서로 다른 실제 사용자처럼 보이는 Expresso 합성 프로필로 직접 쓴다.
입력 사건은 사실 골격이며, 골격과 모순되지 않는 상황·과정·판단·협업·회고는 자유롭게 창작한다.
결과는 면접 답변이나 자기소개서가 아니라 사용자가 노션에 지나간 경험을 정리한 개인 기록이다.

# 출력 bundle

JSON 객체 하나를 다음 모양으로 작성한다.

```json
{
  "shardId": "입력 shardId",
  "profiles": [
    {
      "profileSeed": "입력 profileSeed",
      "records": []
    }
  ]
}
```

`profiles`에는 context의 10명을 정확히 한 번씩 넣는다. 각 `records`는 해당 profile의 `events`와
같은 개수와 순서를 가진다. 구조 필드는 조립기가 입력에서 채우므로 기록 하나에는 아래 세 필드만 쓴다.

```json
{
  "eventId": "event.eventId",
  "title": "사건을 나타내는 짧은 명사형",
  "detailMd": "직접 창작한 세부 본문"
}
```

`draftId`, `categoryKey`, `properties`, `persona`, `status`는 출력하지 않는다.

# 본문 작성

- `fixed_skeleton`: `skeletonLead`는 조립기가 앞에 붙인다. 이를 `detailMd`에 반복하지 말고,
  `detailLength` 범위를 만족하는 새로운 상황·과정·판단·결과만 쓴다. `detailMd`의 첫 문장은
  절대로 `skeletonLead`와 같아서는 안 된다.
- `rewrite_evidence`: `event.facts`의 핵심 사건·행동·결과를 과거형으로 다시 쓰고
  `requiredEvidenceAnchors`의 의미를 첫 두 문장 안에 모두 남긴다.
- `facts`가 `사건 골격 | 맥락: ... | 대상: ... | 문제: ... | 행동: ... | 결과: ...` 형태라면
  값만 사건 단서로 사용한다. `사건 골격`, `맥락:`, `대상:`, `문제:`, `행동:`, `결과:` 같은
  필드 라벨이나 구분 기호를 본문에 복사하지 않는다. 입력 순서도 그대로 나열하지 않는다.
- 구조 단서와 모순되지 않는 구체적인 상황, 작업 순서, 판단, 대화와 회고는 자유롭게 창작한다.
- 입력의 사건 종류, 시점, 기간, 직무, 학력, 자격, 역할, 행동과 결과를 바꾸지 않는다.
- 새 숫자·날짜·실존 기관명·실존 회사명·제품명·고객명은 만들지 않는다.
- `claims`, `evidenceIds`, `recordLinks`, 기록 간 관계, 스킬 숙련도 필드를 만들지 않는다.

# 다양성 절대 규칙

- 문장 풀, 생성 코드, 공통 본문 템플릿을 만들지 말고 10명의 모든 기록을 직접 쓴다.
- 같은 완결 문장을 한 프로필의 두 기록에서 재사용하지 않는다.
- 같은 완결 문장을 두 프로필 사이에서도 재사용하지 않는다.
- 공통 마무리·협업·문서화 문장으로 분량을 채우지 않는다.
- 각 사건의 작업 대상, 문제, 실제 행동, 판단과 결과가 드러나는 문장만 쓴다.
- 한 사람의 여러 사건을 같은 성과나 같은 교훈으로 끝내지 않고, 각 사건의 서로 다른 `결과`
  단서를 개별적으로 반영한다.
- 같은 family의 변형도 어순만 바꾸지 말고 관찰 지점, 작업 순서, 세부 상황과 회고를 새로 쓴다.

# 문체와 길이

- 이미 일어난 일을 자연스러운 한국어 과거형으로 쓴다.
- 면접 표현, 지원 동기, 미래 포부, 상투적인 역량 자랑을 쓰지 않는다.
- 각 본문은 완결된 문장으로 끝낸다.
- `bodyLengthPlan`과 각 event의 `detailLength.minChars`~`detailLength.maxChars` 계약을 지킨다.
- 각 `detailMd`는 반드시 event의 `minimumSentences` 이상인 서로 다른 완결 문장으로 쓴다.
  각 문장은 공백 포함 약 45~60자로 구체적으로 쓰고, 짧은 상투문으로 채우지 않는다.
- 매우 짧음, 적당히 짧음, 적당히 김, 매우 김의 차이가 실제 본문 분량에 나타나게 한다.
