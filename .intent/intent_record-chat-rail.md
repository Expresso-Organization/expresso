# 커리어 기록 화면 채팅 우측 레일 배치

## 개발 목표와 의도

커리어 기록 전체 페이지(`/career/records/[recordId]`)에서 AI 채팅이 문서 본문 아래에 붙어 있다.
요청: "이건 채용 공고 화면에서와 같이 우측에 있어야 해."
지금은 기록을 쓰다가 채팅을 쓰려면 본문 끝까지 내려가야 하고, 채팅 아래에 「선택 영역 빠른 편집」이 다시 이어져 화면 구조가 공고 상세와 다르다.
공고 상세의 우측 채팅 레일을 기록 화면에서도 그대로 쓰게 해, 두 화면이 같은 구조로 보이게 한다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 기록 화면 우측 채팅 레일 | 1024px 이상에서는 채팅이 본문 오른쪽 레일에 서고, 본문과 따로 스크롤된다 | 문서를 보면서 채팅을 쓸 수 있어야 한다. 아래에 있으면 문서와 채팅을 함께 볼 수 없다 |
| 접기 · 너비 조절 | 머리의 채팅 버튼으로 레일을 접고 펴며, 왼쪽 경계를 끌어 너비를 바꾼다. 상태는 기억한다 | 공고 상세와 같은 조작이어야 한다. 넓은 문서를 볼 때 채팅을 치울 수 있어야 한다 |
| 공고 상세와 같은 레일 코드 | 공고 상세의 레일을 공용 컴포넌트로 옮겨 두 화면이 함께 쓴다 | 같은 레일을 두 벌 두면 한쪽만 고쳐지고 모양이 갈라진다 |
| 본문 아래 채팅 제거 | 편집기 본문 아래에 끼어 있던 채팅을 뺀다 | 레일로 옮긴 채팅이 아래에 또 그려지면 안 된다 |

## 개발 목표

- 1280px 창에서 기록 페이지를 열면 채팅이 본문 오른쪽 316px 레일에 보인다.
- 머리의 채팅 버튼으로 접고 펴지고, 새로 고침해도 접힘 · 너비가 유지된다.
- 1024px 미만에서는 채팅이 본문 아래로 내려가고 화면 전체가 한 번에 스크롤된다.
- 공고 상세 화면의 레일 동작과 모양은 그대로다.

## 범위 밖과 제약

- 카테고리 목록의 문서 패널(680px 서랍)의 채팅은 자리가 없어 지금처럼 문서 아래에 둔다.
- 기록을 바꿀 때 어떤 대화를 복원할지(공고처럼 기록별 대화 복원)는 바꾸지 않는다.
- 팀 레포라 푸시와 PR은 사용자가 정할 때 한다.
