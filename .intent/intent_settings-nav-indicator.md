# 설정 화면의 사이드바 활성 표시

## 개발 목표와 의도

설정 화면(`/account`)에 들어가면 좌측 사이드바의 "지금 여기" 표시가 사용자가 누른 설정 줄이 아니라 맨 위 "홈"에 붙는다. 그래서 설정 화면을 보고 있는데 사이드바는 홈에 있다고 말한다.

> "좌측 사이드바에서 설정 버튼 누르면 인디케이터가 홈으로 가는 문제가 있네"

장면: 사이드바 아래쪽의 내 이름 줄을 눌러 설정으로 가면, 홈 줄이 굵은 글씨와 채워진 아이콘으로 바뀌고 내 이름 줄은 그대로다. 설정 화면에 있는 동안은 눌렀던 줄이 활성 표시를 받아야 한다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 홈 줄의 활성 표시를 설정에서 거둔다 | 설정 화면에서 "홈" 줄이 평소 상태(얇은 글씨, 윤곽 아이콘)로 보인다. 폰 하단 탭바의 "홈"도 같다. | 설정은 홈이 아닌데 홈이 활성이면 사이드바가 현재 위치를 틀리게 알려 준다. |
| 내 이름 줄에 활성 표시를 단다 | 설정 화면에서 사이드바 아래쪽 내 이름 줄이 다른 활성 줄과 같은 배경색으로 칠해진다. | 설정으로 가는 입구가 이 줄이므로, 활성 표시가 여기 있어야 눌렀던 곳에 현재 위치가 남는다. |

## 개발 목표

- 설정 화면: "홈" 줄이 활성이 아니고 내 이름 줄이 활성이다.
- 홈 화면: "홈" 줄이 활성이고 내 이름 줄은 평소 상태다.
- 사이드바를 접은 상태: 설정 화면에서 아바타 줄에 같은 활성 배경이 보인다.

## 범위 밖과 제약

설정 화면의 내용, 다른 메뉴의 활성 규칙, 사이드바 모양은 건드리지 않는다. 폰 하단 탭바에는 설정 입구가 없으므로 탭바는 활성 항목 없음 상태가 된다.
