# 설정 프로필에서 표시 이름 변경

## 개발 목표와 의도

표시 이름은 가입할 때 한 번 적으면 끝이다. Google로 가입한 계정은 구글 프로필의 이름이
그대로 들어오고, 오타를 냈거나 활동명을 바꾸고 싶어도 고칠 자리가 없다. 설정 → 프로필에는
이름이 보이지만 읽기만 된다. 이 이름은 사이드바 아래 계정 칸과 편집기 같은 화면에 계속
나타나므로, 틀린 채로 남는 것이 눈에 계속 걸린다.

설정 → 프로필의 표시 이름 줄에서 직접 이름을 고칠 수 있게 한다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 표시 이름 줄의 「이름 바꾸기」 | 프로필의 표시 이름 줄 오른쪽에 버튼이 생긴다. 누르면 이름이 입력칸으로 바뀌고 「저장」「취소」가 나온다. | 이름을 고칠 방법이 지금은 없다. 오타나 구글 이름을 그대로 쓰게 된다. |
| 저장 즉시 반영 | 저장하면 입력칸이 다시 글자로 돌아가고 새 이름이 보인다. 사이드바 아래 계정 칸의 이름도 새로고침 없이 바뀐다. | 저장했는데 다른 화면에 옛 이름이 남으면 바뀐 것인지 알 수 없다. |
| 잘못된 이름 거절 | 비우거나 공백만 적으면 저장되지 않고 입력칸 아래에 사유가 한 줄 나온다. 앞뒤 공백은 지워서 저장한다. | 빈 이름이 저장되면 계정 칸이 비어 보인다. 가입 화면도 같은 규칙으로 막고 있다. |
| 이름 변경 API | 로그인한 본인의 표시 이름을 바꾸는 요청을 서버가 받는다. | 화면만 있고 서버가 받지 않으면 저장이 되지 않는다. |
| 대신 로그인 중에는 막기 | 관리자가 더미 계정을 대신 보고 있을 때 이름 바꾸기 버튼이 없다. | 관리자가 보고 있는 더미 계정의 이름이 실수로 바뀌는 것을 막는다. |

## 개발 목표

- 설정 → 프로필에서 「이름 바꾸기」를 누르고 새 이름을 적어 저장하면 줄이 새 이름으로 바뀐다.
- 저장 뒤 홈 · 커리어 화면의 사이드바 아래 계정 칸에도 새 이름이 보이고, 페이지를 새로고침해도 유지된다.
- 이름을 비우거나 공백만 적고 저장하면 저장되지 않고 사유가 보인다.
- 「취소」를 누르면 적던 내용이 사라지고 원래 이름이 보인다.
- 대신 로그인 중인 화면의 프로필에는 「이름 바꾸기」가 없다.

## 범위 밖과 제약

- 이메일 주소 · 비밀번호 변경은 하지 않는다.
- 프로필 사진 · 한 줄 소개 같은 필드를 추가하지 않는다.
- 이름 중복은 막지 않는다. 이름은 계정을 구분하는 값이 아니고 이메일이 구분한다.
- 이미 만든 포트폴리오 본문에 적힌 이름은 바꾸지 않는다. 포트폴리오는 만들 때 계정의 표시
  이름을 읽어 쓰므로(`page/service.ts`), 이름을 바꾼 뒤 새로 만들거나 다시 생성하는
  포트폴리오부터 새 이름이 들어간다.
- 화면은 기존 프로필 줄의 레이아웃과 `--ex-*` 토큰을 그대로 쓰고 새 토큰을 만들지 않는다.
