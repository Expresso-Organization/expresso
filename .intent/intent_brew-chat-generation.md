# 대화에서 포트폴리오 만들기

## 개발 목표와 의도

> "대화 창을 유지하도록 하되, 기다리는 동안 사용자가 심심하니까 기존 기다리기 로딩창 애니메이션은 최대한 재사용하자. 그리고 생성 중에도 에이전트와 대화가 가능하도록 하자(생성을 방해하지 않는 대화). 그리고 보여줄 수 있는 지면이 뜨면, 지면이 가운데로, 대화 창은 사이드로 자연스럽게 이동"

제작 흐름을 에이전트 채팅으로 옮기는 다섯 번째 단계다. 지금은 「디자인」 카드의 「이 스타일로 만들기」를 누르면 대화를 떠나 생성 화면으로 넘어가고, 끝나면 다듬기로 간다. 이제 대화 창이 그대로 남는다. 기다리는 동안은 지금의 생성 화면이 쓰는 브루잉 애니메이션이 대화에 뜬다. 고른 첫 화면이 지면으로 뜨면 지면이 화면 가운데로 들어오고 대화 창은 옆으로 비켜선다. 지면이 써지는 2분쯤 동안에도 에이전트와 이야기할 수 있다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 대화에서 만들기 | 「이 스타일로 만들기」를 누르면 주소가 그대로이고, 대화 맨 아래에 「생성」 카드가 붙는다. 두 번 눌러도 생성은 하나다. | 화면이 넘어가면 대화가 끊긴다. 만드는 일은 이번 달 횟수를 쓰므로 두 번 시작되면 안 된다. |
| 기다리는 동안의 애니메이션 | 「생성」 카드에 지금의 생성 화면과 같은 브루잉(고른 기록이 잔으로 내려가는 그림, 진행 막대, 지금 읽는 입력 한 줄)이 뜬다. 오래 걸리면 지금처럼 입력 묶음(공고 · 디자인 · 섹션 · 기록)이 이어서 쌓인다. | 기다리는 동안 볼 것이 있어야 한다. 요청자가 정해 온 기존 애니메이션을 그대로 쓴다. |
| 지면은 가운데로, 대화는 옆으로 | 고른 첫 화면이 지면의 맨 앞으로 뜨면 지면이 화면 가운데에 들어오고 대화 창이 옆으로 비켜선다. 지면은 지금처럼 그 자리에서 이어 써진다. 공고 화면에서는 공고 내용 자리에 지면이 들어오고(대화는 이미 오른쪽에 있다), 독립 채팅 화면에서는 대화가 오른쪽으로 옮겨 간다. 움직임은 화면 전환 효과로 잇고, 움직임 줄이기 설정이면 바로 바뀐다. | 만들어지는 지면은 실제에 가까운 크기로 봐야 한다. 대화를 닫지 않고도 지면을 크게 본다. |
| 생성 중의 대화 | 지면이 써지는 동안 입력창이 열려 있고 에이전트가 답한다. 에이전트는 지금 만드는 중이라는 것을 알고, 디자인을 바꾸는 도구는 쓰지 않는다. 기록을 고쳐도 이번 생성에는 들어가지 않는다고 말한다. | 2분 남짓 기다리는 동안 대화가 막히면 안 된다. 생성은 시작할 때 자료를 읽으므로 대화가 생성을 망가뜨리지 않는다. |
| 끝난 뒤 | 다 써지면 「생성」 카드에 「다듬기에서 열기」가 놓인다. 가운데 지면은 그대로 남는다. | 지금은 끝나면 다듬기로 바로 넘어간다. 대화를 유지하므로 다음 걸음은 사용자가 누른다. |
| 멈추기 · 실패 | 「생성」 카드의 「생성 멈추기」로 멈추면 크레딧을 쓰지 않는다. 실패하면 사유와 「다시 만들기」가 뜬다. | 지금의 생성 화면이 하는 일을 대화에서도 한다. |

## 개발 목표

- 「디자인」 카드에서 「이 스타일로 만들기」를 누르면 주소가 그대로이고, 대화에 「생성」 카드가 붙어 브루잉 애니메이션이 돈다.
- 몇 초 뒤 고른 첫 화면이 뜨면 지면이 가운데로 들어오고 대화가 옆으로 비켜서며, 지면 아래가 이어 써진다.
- 지면이 써지는 동안 "지금 뭐 하고 있어?"를 보내면 에이전트가 만드는 중이라고 답하고, 생성은 끝까지 간다.
- 다 써지면 「생성」 카드에 「다듬기에서 열기」가 뜬다.

## 범위 밖과 제약

- 생성이 끝났을 때 에이전트가 먼저 말하는 것은 넣지 않는다(요청에 없었다). 카드와 지면이 끝난 것을 보인다.
- 지면은 생성 스트림이 남아 있는 30분 안에서만 새로 고친 뒤에도 다시 그려진다. 그 뒤에는 카드의 「다듬기에서 열기」로 연다.
- 다듬기는 지금의 화면이 맡는다.
- 지금의 생성 화면(`/brew/<id>/design`)은 지우지 않는다.
