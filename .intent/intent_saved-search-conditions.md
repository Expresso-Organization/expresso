# 저장한 검색 조건 반영과 목록

## 개발 목표와 의도

공고 검색에서 「이 검색 저장」을 누른 뒤 태그(해석 칩)를 바꾸면 바꾸기 전 조건으로 저장된 채이고, 저장한 검색을 어디서 보는지 모르겠다는 제보가 왔다(Discord #issue 11-12).

저장 여부를 검색 문장만으로 판단해서, 태그를 바꿔도 버튼이 「저장한 검색」으로 잠긴 채 남았다. 저장한 검색을 보여 주는 화면은 없었다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 조건까지 보는 저장 여부 | 태그를 바꾸거나 끄면 「이 검색 저장」이 다시 눌린다 | 바꾼 조건을 저장할 수 있어야 한다 |
| 저장한 검색 목록 | 공고 화면 오른쪽에 「저장한 검색 N」 카드. 누르면 저장한 문장과 조건으로 다시 검색한다 | 저장한 검색을 볼 자리가 없었다 |
| 저장한 검색 지우기 | 줄마다 「지우기」. 서버에 지우기 API를 더한다 | 저장은 10개까지라 지울 수 없으면 더 저장할 수 없다 |

## 개발 목표

- 「서울 TypeScript」를 저장하고 지역 태그를 부산으로 바꾸면 「이 검색 저장」이 다시 눌린다.
- 오른쪽 「저장한 검색」에서 그 줄을 누르면 저장한 태그 그대로 검색된다.
- 「지우기」를 누르면 그 줄이 사라진다.
