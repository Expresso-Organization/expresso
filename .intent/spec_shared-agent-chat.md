# 요구사항
- 대화 ID를 세 화면에서 공유하고, 사용자 소유권을 모든 조회·실행·승인에서 검사한다.
- MongoDB에 대화·메시지·실행 상태를 저장한다. 동시에 실행할 수 있는 턴은 대화당 하나다.
- 스트림을 다시 연결하면 저장된 상태부터 표시한다. 화면 이탈은 실행 취소와 분리한다.
- 문맥은 공고/기록 ID로 전달하고 서버가 조회한다. 클라이언트의 시스템 지시는 받지 않는다.
- SDK는 도메인 도구만 사용한다. 기록 변경은 기존 제안 서비스를 통해 검토 후 적용한다.
- 중단 신호를 SDK에 전달하고, 종료/실패/서버 재시작을 구분한다.
- 기존 --ex-* 토큰과 앱 셸을 사용한다. AI 미설정 상태를 명확히 표시한다.
