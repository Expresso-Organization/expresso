# 챙기기 — 약속과 먼저 연락하기

## 개발 목표와 의도

> "행동으로 이어질 수 있게끔 하고 … 지금은 그 모든 것을 사용자의 의지에만 맡기고 있어. 이를 도와주고 행동을 유도하는 커리어 컨설턴트가 목표야."

Expresso AI 기획(`docs/expresso-ai/product-plan.md`, PR #252)의 넷째 마일스톤이다. 지금 컨설턴트는 사용자가 대화를 열어야만 말한다. 대화에서 "다음 주까지 해커톤에 지원하겠다"고 해도 다음 주에 그 일을 묻는 사람이 없다.

이 변경은 사용자가 하겠다고 한 일을 약속으로 저장하고, 약속한 날에 컨설턴트가 먼저 묻게 한다. 했다고 답하면 그 자리에서 기록으로 남기는 인터뷰가 시작된다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 약속 | 사용자가 제안을 받아들이거나 "다음 주까지 하겠다"고 말하면 컨설턴트가 할 일과 날짜를 약속으로 저장한다. 답변 글 아래에 약속 카드가 뜨고, 카드에서 날짜를 고치거나 약속을 거둔다. | 하겠다는 말이 대화에만 남으면 확인할 근거가 없다. |
| 약속 확인 | 약속한 날이 되면 홈에 「○○ 어떻게 됐나요?」 카드가 뜨고 알림이 온다. 카드에서 「했어요」 · 「아직이에요」 · 「안 하기로 했어요」로 답한다. | 사용자가 앱을 열었을 때 다음에 할 일이 먼저 보여야 한다. |
| 했어요 → 인터뷰 | 「했어요」를 누르면 그 약속의 대화가 열리고 컨설턴트가 한 일을 묻는다. 답하면 기록으로 저장된다(마일스톤 3). | 한 일을 기록으로 남기는 것까지가 챙기기다. |
| 아직이에요 → 날짜 다시 잡기 | 「아직이에요」를 누르면 카드에서 새 날짜를 고른다. 모델 실행 없이 저장된다. | 미루는 일에 크레딧을 쓰지 않는다. |
| 안 하기로 했어요 | 약속을 닫는다. 모델 실행이 없다. | 하지 않기로 한 일을 계속 묻지 않는다. |
| 대화가 없을 때 | 2주 동안 대화가 없으면 홈에 카드가 뜨고 알림이 한 번 온다. | 한동안 쉬던 사용자가 돌아올 계기를 만든다. |
| 먼저 연락하기 동의 | 온보딩의 동의 화면에서 받는다(기본으로 켬). 이미 가입한 사용자에게는 홈 카드로 한 번 묻는다. 계정 설정에서 끄고 켠다. 켜면 능동 제안도 함께 켜진다. | 요청하지 않은 연락은 동의가 있어야 한다. 능동 제안의 스위치와 따로 두면 사용자가 같은 일을 두 번 정해야 한다. |
| 날짜 칸 | 입력 칸 묶음의 칸이 날짜를 받을 수 있다. | 약속 날짜를 글로 받으면 "다음 주 금요일"을 날짜로 바꾸다 틀릴 수 있다. |
| 내 진행의 약속 | 「내 진행」 화면에 열린 약속과 날짜가 보인다. | 컨설턴트가 기억하는 약속을 사용자가 볼 수 있어야 한다. |

## 개발 목표

- 약속이 생긴다: 대화에서 "다음 주 금요일까지 해커톤에 지원할게요"라고 말하면 약속 카드가 뜨고 「내 진행」에 보인다.
- 약속한 날에 묻는다: 약속 날짜가 오늘인 계정으로 홈을 열면 확인 카드가 보이고, 알림 목록에 컨설턴트의 알림이 있다.
- 했어요: 카드에서 「했어요」를 누르면 대화가 열리고 컨설턴트가 한 일을 묻는다.
- 아직이에요: 새 날짜를 고르면 카드가 사라지고 약속의 날짜가 바뀐다. 크레딧이 줄지 않는다.
- 끌 수 있다: 계정 설정에서 끄면 확인 카드와 알림이 오지 않는다.

## 범위 밖과 제약

- 챙기는 강도는 기획에서 정한 대로다: 약속한 날 한 번, 답이 없으면 3일 뒤 한 번 더 하고 멈춘다. 대화가 없을 때는 2주에 한 번이다. 컨설턴트의 알림은 하루 한 건까지다.
- 준비 계획의 작업 마감은 이 변경의 확인 대상이 아니다. 계획의 작업을 약속으로 잇는 일은 뒤에 한다.
- 능동 제안을 새 소식이 있는 날에만 실행하게 바꾸는 일은 이 변경에 넣지 않았다.
- 이메일은 보내지 않는다.
- 새 컬렉션 `consultant_commitments`와 예약 작업 `consultant_checkins`가 생긴다(마이그레이션 0037).
- 화면의 모양은 구현 뒤 화면 캡처로 확인받는다. 이 PR은 병합하지 않고 열어 둔다.
