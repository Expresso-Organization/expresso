# 다듬기 채팅을 공통 에이전트 채팅으로 교체

## 개발 목표와 의도

다듬기 화면 오른쪽 「채팅」 탭은 공고 화면 · 커리어 기록 · 독립 채팅 탭이 함께 쓰는 공통 에이전트 채팅이 아니라, 따로 만든 입력창 하나다. 대화를 저장하지 않아 보내기 전에는 빈 칸만 보이고, 보낸 뒤에도 마지막 한 번의 주고받음만 남는다. 다른 요소를 고르거나 새로고침하면 사라진다.

> "공통 AI 채팅 모듈이 있는데 그게 아니라 독자적으로 구현된거 아니야?" · "여기서 옮겨 줘"

이번 변경이 끝나면 다듬기의 채팅 탭은 다른 화면과 같은 채팅이다. 포트폴리오마다 대화가 남고, 지면에서 고른 요소를 대상으로 말하면 에이전트가 그 요소를 고쳐 새 판으로 저장한다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 다듬기 채팅 탭을 공통 채팅으로 교체 | 구조화 지면의 채팅 탭에 공고 · 기록 화면과 같은 채팅(대화 목록, 새 대화, 크게 열기, 작업 흔적)이 보인다. 이 포트폴리오가 「함께 보는 자료」로 연결되어 있다. | 같은 일을 하는 채팅이 두 벌이면 한쪽만 고쳐지고, 다듬기 채팅은 대화가 남지 않는다. |
| 포트폴리오별 대화 복원 | 다듬기 화면을 다시 열거나 새로고침하면 이 포트폴리오에서 하던 대화가 그대로 열린다. 다른 요소를 골라도 대화가 이어진다. | 지금은 요소를 바꾸거나 새로고침하면 대화가 사라져 앞서 무엇을 고쳤는지 알 수 없다. |
| 고른 요소를 대상으로 보내기 | 지면이나 목차에서 요소를 고르면 입력창 위에 「작업 목차」 같은 대상 표시가 붙고, 보낸 말풍선에도 같은 표시가 남는다. 에이전트는 그 요소를 읽고 고친다. | 「이 문장 더 짧게」가 어느 요소를 가리키는지 에이전트와 사용자 모두 알아야 한다. |
| 요소 고침 카드와 되돌리기 | 에이전트가 고치면 바로 새 판이 저장되고 미리보기가 바뀐다. 채팅에는 바뀐 곳(전 → 후) 카드와 「되돌리기」 버튼이 붙는다. 그 뒤에 다른 편집이 쌓였으면 되돌리기는 막힌다. | 고친 결과를 바로 보고, 마음에 들지 않으면 한 번에 앞 판으로 돌아가야 한다. 다른 편집을 덮으면 그 편집이 사라진다. |
| 구조화 지면의 「지면 전체」 채팅 제거 | 요소를 고르지 않은 구조화 지면에서 보이던 별도 입력창(말로 지면 전체를 다시 만들기)이 없어지고, 같은 자리에 공통 채팅이 보인다. | 같은 탭에 채팅이 두 벌 있으면 다시 갈라진다. 공통 채팅에는 지면 전체를 다시 만드는 도구가 없고, 다시 만들기는 「디자인 선택으로 돌아가 다시 생성」으로 할 수 있다. |
| 옛 요소 지시 경로 제거 | 다듬기 전용 입력창과, 그 입력창만 부르던 서버의 「요소 하나 말로 고치기」 API가 없어진다. | 쓰는 곳이 없는 경로를 남기면 같은 기능이 두 갈래로 유지된다. |

## 개발 목표

- 공통 채팅: 다듬기 화면 채팅 탭에 공고 화면과 같은 머리(대화 제목 · 대화 목록 · 새 대화)와 「함께 보는 자료: 포트폴리오」가 보인다.
- 요소 고치기: 「작업 목차」를 고르고 "이 문장 더 짧게"를 보내면 그 요소의 글만 바뀐 새 판이 생기고, 미리보기와 「이력」 탭에 반영된다. 채팅에는 바뀐 곳 카드가 남는다.
- 되돌리기: 카드의 「되돌리기」를 누르면 앞 판 내용이 새 판으로 쌓이고 카드에 「되돌렸습니다」가 보인다.
- 대화 복원: 새로고침하거나 다른 요소를 고른 뒤에도 앞의 대화와 카드가 그대로 보인다.

## 범위 밖과 제약

- 사용 규칙은 공통 채팅 그대로다. 일반 사용자는 Anthropic API 키를 등록해야 보낼 수 있고, 개발 멤버와 더미 계정은 서버 인증으로 돈다(사용자 결정).
- 에이전트의 고침은 승인 없이 바로 저장된다. 대신 되돌리기가 있다(사용자 결정).
- 옛 블록 지면과 자유 HTML 지면의 채팅은 지금 그대로 둔다.
- 요소 추가 · 삭제 · 순서 바꾸기, 이름 고치기는 채팅으로 하지 않는다. 목차와 속성 탭이 맡는다.

## 열린 질문

- 구조화 지면에서 말로 지면 전체를 다시 만드는 입력창을 없앤다(기능 목록 다섯째 줄). 남겨야 하면 알려 주세요. 남기면 채팅 탭 안에 채팅이 두 벌이 된다.
