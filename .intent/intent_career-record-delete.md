# 커리어 기록 삭제 동작 정비

## 개발 목표와 의도

> "포트폴리오, 커리어 기록 등에 대한 삭제 버튼이 적절하게 제공되고 있지 않는 것 같아."

지금 커리어 기록을 지우는 길은 표 뷰에서 셀을 오른쪽 클릭해 여는 메뉴 하나뿐이다. 보드 · 갤러리 · 목록 · 타임라인 뷰에서 기록을 열면 문서 패널이 뜨지만, 패널에도 기록 전체 페이지에도 삭제 버튼이 없다. 여러 기록을 골라도 상태만 바꿀 수 있다. 표에서 지울 때도 그 기록을 쓰는 포트폴리오가 있는지 알리지 않고 바로 휴지통으로 옮긴다. 기능 명세서 T1.3.5는 "기록 삭제 시 사용 중인 포트폴리오 수를 알리고 확인을 받는다"고 정한다.

이 변경은 기록을 여는 모든 자리에서 지울 수 있게 하고, 지우기 전에 영향을 알린다. 포트폴리오 · 만들던 포트폴리오의 삭제(휴지통)는 읽는 자리가 많아 별도 변경(`portfolio-trash`)으로 나눈다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 문서 패널 삭제 버튼 | 뷰에서 기록을 열면 뜨는 문서 패널 머리말의 닫기 버튼 옆에 휴지통 버튼이 생긴다. 누르면 기록이 휴지통으로 가고 패널이 닫힌다. | 보드 · 갤러리 · 목록 · 타임라인 뷰에는 행 메뉴가 없어, 지금은 그 뷰에서 기록을 지울 수 없다. |
| 기록 페이지 삭제 버튼 | 「넓게 보기」로 연 기록 전체 페이지 머리말 오른쪽에 「삭제」 버튼이 생긴다. 확인 창에서 옮기면 카테고리 화면으로 돌아간다. | 전체 페이지에서 쓰던 기록을 지우려면 지금은 카테고리로 돌아가 표에서 다시 찾아야 한다. |
| 선택한 기록 일괄 삭제 | 기록을 여러 개 고르면 나오는 막대에 「삭제」가 생긴다. 고른 기록이 한꺼번에 휴지통으로 가고 「되돌리기」로 모두 되살릴 수 있다. | 정리할 기록이 여러 개면 지금은 하나씩 오른쪽 클릭해 지워야 한다. |
| 포트폴리오에서 쓰는 기록 확인 | 지우려는 기록을 포트폴리오가 근거로 쓰고 있으면 "포트폴리오 2곳에서 이 기록을 쓰고 있습니다"를 보여 주고 확인을 받는다. 쓰는 곳이 없으면 확인 없이 휴지통으로 옮기고 「되돌리기」를 띄운다. | 명세 T1.3.5의 요구다. 지금은 쓰는 기록을 아무 안내 없이 지울 수 있다. |

## 개발 목표

- 보드 뷰에서 카드를 눌러 문서 패널을 열고 휴지통 버튼을 누르면 카드가 사라지고 「휴지통으로 옮겼습니다 · 되돌리기」가 뜬다.
- 기록 전체 페이지에서 「삭제」 → 확인 창 → 「휴지통으로 옮기기」를 누르면 카테고리 화면으로 가고, 카테고리 메뉴의 휴지통에 그 기록이 있다.
- 표에서 기록 세 개를 골라 막대의 「삭제」를 누르면 세 개가 사라지고, 「되돌리기」를 누르면 세 개가 다시 나온다.
- 포트폴리오가 쓰는 기록을 지우려 하면 확인 창에 포트폴리오 수가 보이고, 「취소」를 누르면 기록이 그대로 남는다.

## 범위 밖과 제약

- 포트폴리오 · 만들던 포트폴리오 삭제는 `portfolio-trash` 변경에서 다룬다.
- 사용자 카테고리 삭제는 하지 않는다.
- 휴지통 보관 기간(30일), 복원, 영구 삭제 동작은 바꾸지 않는다. 백엔드는 고치지 않는다.
