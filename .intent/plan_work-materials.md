# 구현 계획

1. 계약 — 첨부 · 도구 입력 · 결과 스키마, 테스트(첨부 상한 · 항목 종류).
2. 플랫폼 — 공개 주소 검사(단위 테스트: 사설 대역 · 루프백 · 이상한 스킴), 사이트 찍기, 레포 읽기(주소 해석 단위 테스트).
3. 에이전트 서비스 · 런타임 — 첨부 저장 · 검증, `materials` 상태, 두 도구, 본문 덧붙이기(단위 테스트: `## 작업물` 아래에 잇기), 지침.
4. `main.ts` 조립.
5. 웹 — 첨부 단추 · 붙여넣기 · 보낸 메시지 축소 그림 · 카드.
6. 검사 — typecheck · test · test:infra, 실제 대화로 링크 · 레포 · 스크린샷을 붙이고 기록 본문과 카드를 확인.
