# 생성 기다림 화면과 다듬기 바로 넘어가기

## 개발 목표와 의도

지금은 지면 뼈대(청사진)가 오는 약 61초 동안 "추출하는 중" 카드만 보이고, 끝나면 "다 뽑혔습니다" 카드를 한 번 더 눌러야 편집 화면으로 간다. 요청: "브루잉 화면을 10초간 띄우고, 그 다음 입력 묶음을 시각적으로 읽기 좋게 해서, 설계 출력이 나올 때까지 사용자가 그걸 읽게끔 하자". 시안을 보며 "입력 종류별로 섹션을 나누고 그리드처럼 묘사해", "1.5초 주기로 한번씩 다음 섹션으로", "모션감을 좀더 쫀득하게"로 고쳤다(2026-10-27). 끝나면 바로 다듬기로 넘긴다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 브루잉 화면 | 시작 후 10초 동안 고른 기록이 커피잔 로고로 내려가며 잔이 찬다(쓰지 않던 레시피 대기 화면) | 무엇이 들어갔는지 먼저 보여 준다 |
| 입력 묶음 화면 | 브루잉 아래에 채용 공고 · 디자인 · 섹션 · 기록 구역을 카드 그리드로 그리고, 스크롤하지 않는 동안 1.5초마다 다음 구역으로 한 칸씩 올라가며 돈다 | 남은 약 50초를 내용 확인에 쓴다 |
| 두 화면 사이 전환 | 10초가 되면 기록 줄이 걷히고 잔만 화면 위로 올라가며, 그 아래에서 구역이 차례로 올라온다 | 한 번에 바뀌면 같은 작업의 다음 단계로 읽히지 않는다 |
| 잔 아래 한 줄 | 처음 10초는 "사용자 기록 정리 중..." 같은 읽는 입력을, 그 뒤에는 "포트폴리오 생성 중..." 같은 만드는 일을 돌아가며 적는다. "추출하는 중" 제목과 차례 문구는 없다 | 그림만으로는 지금 무엇을 하는지 알 수 없다 |
| 다시 열면 이어서 | 시작한 지 10초가 지난 뒤 다시 열면 입력 묶음부터 보인다 | 새로고침마다 10초를 다시 기다리지 않는다 |
| 완료 카드 제거 | 지면이 다 되면 06 다듬기 편집 화면으로 바로 넘어간다 | 한 번 더 누르는 단계는 시간만 쓴다 |
| 다시 뽑기 버튼 | "디자인을 바꿔 다시 뽑기"를 편집 화면 머리줄에 둔다 | 카드를 지우면 이 버튼이 사라진다 |

## 개발 목표

- 생성을 누르면 브루잉이 뜨고, 10초 뒤 브루잉이 위로 올라가며 입력 묶음이 아래에서 올라온다.
- 입력 묶음은 손대지 않으면 1.5초마다 한 칸씩 올라가고, 스크롤하면 멈췄다가 스크롤을 마친 자리에서 다시 센다.
- 청사진이 오면 지금처럼 지면 채우기로 바뀐다.
- 30초쯤 새로고침하면 입력 묶음이 바로 보인다.
- 완성되면 편집 화면으로 넘어가고 기존 "AI가 화면을 보고 다듬고" 안내가 보인다.
- 편집 화면의 "디자인을 바꿔 다시 뽑기"가 디자인 고르기 화면을 연다.

## 범위 밖과 제약

- 다듬기 기능은 새로 만들지 않고 지금 편집 화면을 쓴다.
- 설계 호출의 부분 출력은 켜지 않는다.
- 동작 줄이기 설정에서는 전환 없이 바로 바꾼다.
