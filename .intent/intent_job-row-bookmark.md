# 공고 목록 북마크로 관심 공고 담기

## 개발 목표와 의도

채용 공고 목록(`/jobs`)의 행 오른쪽 끝에 있는 북마크 아이콘을 눌러도 관심 공고에 담기지 않는다. 담는 일은 공고 상세 화면의 버튼으로만 된다. 목록에서 여러 공고를 훑으며 마음에 드는 것을 바로 담으려는 사람이 매번 상세로 들어가야 한다.

요청: "채용 공고 목록 화면에서 이 북마크 아이콘 눌러도 관심 공고에 담기지 않는 문제가 있음"

겪은 장면: 목록에서 `D-59` 옆 북마크를 누르면 아무것도 바뀌지 않고 그 공고의 상세 화면으로 넘어간다. 아이콘은 이미 담은 공고를 보여 주는 표시일 뿐 누를 수 있는 버튼이 아니었다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 목록 행 북마크 누르면 담기 | 북마크를 누르면 상세로 넘어가지 않고 그 자리에서 아이콘이 채워지며, 헤더의 "관심 공고" 개수와 사이드바 · 오른쪽 레일에 그 공고가 나타난다. | 목록에서 훑는 중에 바로 담지 못하면 상세를 열고 돌아오기를 공고마다 반복해야 한다. |
| 채워진 북마크 누르면 빼기 | 이미 담은 공고의 북마크를 누르면 아이콘이 비워지고 관심 공고에서 빠진다. | 잘못 담은 공고를 목록에서 바로 되돌릴 수 없으면 담기 기능이 한 방향으로만 동작한다. |
| 담기 실패 표시 | 서버가 담기를 받지 못하면 아이콘이 원래 모양으로 돌아가고 경고색으로 바뀐다. 아이콘에 마우스를 올리면 실패 사유가 보인다. | 실패했는데 담긴 것처럼 보이면 사용자가 담았다고 믿고 놓친다. |
| 행 본문 클릭은 상세 이동 유지 | 제목 · 회사 · 점수 등 행의 나머지를 누르면 지금처럼 상세 화면으로 간다. | 이번 수정으로 기존에 되던 상세 이동이 깨지면 안 된다. |

## 개발 목표

- 담기: `/jobs`에서 북마크를 누르면 주소가 `/jobs`로 유지되고 아이콘이 채워진다.
- 반영: 새로고침해도 채워진 상태가 유지되고 헤더가 "관심 공고 1"로 바뀐다.
- 빼기: 채워진 북마크를 누르면 비워지고 헤더 개수가 줄어든다.
- 상세 이동: 행 본문을 누르면 상세 화면으로 이동한다.
- 모양: 행의 배치와 크기가 수정 전과 같다.

## 범위 밖과 제약

- 상세 화면의 관심 공고 버튼, 관심 공고 API, 계약(`packages/contracts`)은 바꾸지 않는다.
- 행 레이아웃과 토큰(`--ex-*`)은 그대로 쓰고 새 값을 만들지 않는다.
