# 시연 리허설에서 드러난 문제 수정

## 개발 목표와 의도

문가령 계정으로 운영에서 공고 검색부터 배포까지 한 바퀴 돌렸을 때 흐름이 끊기거나 사실과 다른 내용이 나온 자리를 고친다. 끝나면 회사 이름으로 공고를 찾아 공고 화면에서 바로 제작을 시작하고, 생성된 지면의 수치가 기록과 일치하며, 부분 수정 실패 때 이유를 한국어로 읽는다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
| --- | --- | --- |
| 회사 검색 복구 | `올리브영`을 검색하면 그 회사 공고가 나온다. 근무지 칸에 회사 이름만 있으면 그 칸을 비운다. | 지역을 읽지 못한 공고 196건이 기본 `한국` 범위에서 통째로 빠졌다. |
| 공고 상세에서 제작 시작 | 공고 상세 머리에 `이 공고로 만들기` 단추가 있다. 진행 중이면 `이어서 만들기`다. | 공고를 읽은 뒤 다음 행동으로 갈 길이 없었다. |
| 다시 분석 자동 갱신 | 누르면 단추가 `분석 중…`으로 바뀌고, 끝나면 새 판정이 그려진다. | 새로고침 전까지 `맡겼습니다`에 멈춰 있었다. |
| 원문 제목 표시 | `## 요구경험`이 제목 줄로 보이고 `##`와 `\.`가 글에 남지 않는다. | 공고 269건에서 문법 기호가 그대로 보였다. |
| 연차 판정 | 4년차에게 `데이터 분석 3년 이상`을 경력 기간으로 판정한다. | 경력을 채운 사람에게 근거가 비었다고 말했다. |
| 재료 시기 표시 | 재료 표의 시기 칸에 기록 기간이 나온다. | 23건 모두 `—`였고 최근 순 정렬도 동작하지 않았다. |
| 수치 왜곡 방지 | 출처의 `반나절`을 수치로 받고, 시간이 건수로 바뀐 줄은 싣지 않는다. | 검사가 `반나절`을 막아 `3일 → 15건`이라는 없는 사실이 공개 지면에 나갔다. |
| 편집 오류 문구 | 부분 수정 실패 때 서비스가 쓴 한국어 이유가 보이고, AI 답변에 내부 필드 이름이 나오지 않는다. | `Request cannot be fulfilled as given`만 보였다. |
| 근거 없는 말 제거 | 결과 0건에서 `모두 확인됩니다`를 말하지 않고, 배포 이력에 `섹션 0 · 블록 0`을 적지 않는다. | 근거 없이 사실처럼 보였다. |
| 계산 전파 실패 수정 | 같은 대상을 두 관계로 가리켜도 `career.computation`이 실패하지 않는다. | 멱등 키 충돌로 5회 재시도 뒤 실패했다. |

## 개발 목표

- `/jobs?q=올리브영`에 CJ올리브영 공고가 나오고 근무지 칸에 회사 이름이 없다.
- 공고 상세에서 `이 공고로 만들기`를 누르면 분석 대기 화면으로 간다.
- 쿠팡 공고 `다시 분석` 뒤 새로고침 없이 판정이 바뀐다.
- 새로 만든 포트폴리오의 리포트 수치가 `3일 → 반나절`이다.
- 항목 삭제 요청의 실패 이유를 한국어로 읽는다.
