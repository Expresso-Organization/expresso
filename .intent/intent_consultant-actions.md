# 행동 제안 — 대화에서 공고와 활동을 찾아 다음에 할 일 하나를 권하기

## 개발 목표와 의도

> "… 부족한 점을 알 수 있게 도와주고, 행동으로 이어질 수 있게끔 하고 …"

Expresso AI 기획(`docs/expresso-ai/product-plan.md`, PR #252)의 여섯째 마일스톤이다. 진단(마일스톤 5)은 무엇이 부족한지까지 알려 준다. 그런데 컨설턴트는 공고와 공모전 · 해커톤을 찾아볼 수 없어서, 부족한 점을 채울 구체적인 자리를 권하지 못한다.

이 변경은 컨설턴트가 대화에서 공고와 활동을 직접 찾아 목록으로 보여 주고, 다음에 할 일 하나를 권하게 한다. 사용자가 받아들이면 약속(마일스톤 4)이 된다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 공고 찾기 | 컨설턴트가 글 · 기술 · 직군 · 지역 · 내 경력으로 열린 공고를 찾는다. 결과는 답변 글 아래에 목록으로 뜨고 누르면 그 공고가 열린다. | 부족한 점을 채울 자리나 지원할 자리를 대화 안에서 봐야 한다. |
| 활동 찾기 | 접수 중인 공모전 · 해커톤을 종류와 글로 찾는다. 결과는 같은 목록으로 뜨고 누르면 출처가 열린다. | 경험이 없는 항목은 활동으로 채운다. |
| 비교 표 | 찾은 것 몇 개를 기준별로 나란히 견주는 표를 보인다. | 둘 가운데 고를 때 글로 늘어놓으면 견주기 어렵다. |
| 다음에 할 일 하나 | 부족한 점마다 맞는 행동을 고른다 — 해 본 일이면 인터뷰, 경험이 필요하면 활동이나 프로젝트, 준비가 됐으면 공고. 그중 하나를 권한다. | 할 일을 여럿 늘어놓으면 아무것도 하지 않게 된다. |
| 받아들이면 약속 | 사용자가 권한 일을 하겠다고 하면 날짜와 함께 약속으로 저장한다. | 권하는 데서 끝나면 챙길 수 없다. |
| 넘긴 것은 다시 권하지 않기 | 홈의 제안에서 「관심 없음」으로 넘긴 공고와 활동은 찾은 결과에서 뺀다. 싫다고 말한 조건은 컨설턴트가 기억에서 읽어 거른다. | 싫다고 한 것을 다시 권하면 믿지 않게 된다. |

## 개발 목표

- 진단을 마친 대화에서 "그럼 뭐부터 할까요?"라고 하면 컨설턴트가 공고나 활동을 찾아 목록으로 보여 주고 하나를 권한다.
- 목록의 줄을 누르면 그 공고(앱 안)나 활동(출처)이 열린다.
- "그걸로 할게요"라고 하면 약속 카드가 뜬다.
- 「관심 없음」으로 넘긴 공고는 목록에 나오지 않는다.

## 범위 밖과 제약

- 공고 검색은 지금 있는 공고 목록 조회(글 · 기술 · 직군 · 지역 · 경력 필터)를 쓴다. `agentic-chat` PR의 임베딩 검색(벡터 색인)은 옮기지 않는다 — 도구의 입력 모양만 참고한다.
- 공고의 적합 여부는 추천 모델이 연결되기 전까지 컨설턴트가 목록과 기록을 보고 판단한다.
- 약속에 공고 · 활동의 링크를 따로 저장하지 않는다. 약속의 덧붙임 글에 적는다.
- 탐색 단계의 사용자는 지금의 구직 목표 대화와 공고 검색이 맡는다.
- 화면의 모양은 구현 뒤 화면 캡처로 확인받는다. 이 PR은 병합하지 않고 열어 둔다.
