# 추천 모델 제품 연결 명세

- 인증된 계정의 유효한 기록과 실제 공고만 입력한다. 권한과 외부 전송 동의를 서버에서 확인한다.
- 추천은 모집 중인 공고를 배치로 선별해 전역 상위 후보를 반환한다. 원문에서 요건을 확인할 수 없는 공고와 빈 기록 상태를 명시한다.
- 선택 공고의 근거 목록은 요건별로 사용자 본인의 기록에 연결한다. 근거 후보와 확인된 제안, 모델 추정과 기존 일치도를 구분한다.
- Worker가 완료한 공고 분석 결과로 공개 공고 벡터를 미리 준비한다. 모델이 꺼지거나 실패해도 기존 분석·제작 결과는 유지한다.
