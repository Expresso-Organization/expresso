# 포트폴리오 생성 멈추기

## 개발 목표와 의도

포트폴리오 생성을 중단하거나 취소할 방법이 없다는 제보가 왔다(Discord #issue 11-12). 디자인을 잘못 골랐거나 재료를 바꾸고 싶어도, 생성이 끝날 때까지 몇 분을 기다린 뒤 결과를 지워야 했다. 그동안 크레딧도 차감됐다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 「생성 멈추기」 버튼 | 생성 중 화면의 「새로고침」 옆. 누르면 디자인 선택으로 돌아가고 「생성을 멈췄습니다. 크레딧은 차감하지 않았습니다」가 보인다 | 원치 않는 생성을 기다리지 않고 바로 다시 고를 수 있어야 한다 |
| 늦게 끝난 결과 버리기 | 멈춘 뒤 AI가 결과를 내도 완료로 바꾸지 않고 크레딧을 차감하지 않는다. 큐가 다시 전달해도 다시 돌지 않는다 | 멈춘 생성이 몰래 끝나거나 크레딧을 쓰면 안 된다 |
| 빈 포트폴리오 정리 | 멈춘 생성이 만들던 빈 포트폴리오는 휴지통으로 간다 | 목록에 내용 없는 포트폴리오가 남지 않아야 한다 |

## 개발 목표

- 생성 중 화면에서 「생성 멈추기」를 누르면 디자인 선택 화면으로 돌아가고 멈춤 안내가 보인다.
- 그 생성은 이번 달 크레딧에 잡히지 않고, 포트폴리오 목록에 빈 포트폴리오가 남지 않는다.
- 이미 끝난 생성에서는 누르면 결과 화면으로 넘어간다.
