# 사이드바 로고 홈 이동 · 검색 줄 제거

## 개발 목표와 의도

앱 화면 왼쪽 사이드바 맨 위의 Expresso 로고는 지금 누를 수 없는 그림이다. 다른 웹 서비스처럼 로고를 눌러 홈으로 돌아가려던 사용자는 아무 일도 일어나지 않는 것을 겪는다. 사이드바의 「검색 ⌘K」 줄은 화면 위쪽 머리글의 검색 단추와 ⌘K 단축키가 이미 같은 검색 창을 연다. 팀 피드백은 이렇다. "메인 화면 왼쪽에 expresso 로고 자체를 눌렀을때 홈으로 가는 기능 추가하면 좋을것 같습니다." "사이드바에 검색탭을 지워도 괜찮을것 같습니다."

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 로고 홈 이동 | 사이드바 맨 위의 로고와 Expresso 글자를 누르면 홈(`/home`)으로 간다. 마우스를 올리면 누를 수 있는 자리로 보인다. | 로고를 눌러 처음 화면으로 돌아가는 것은 웹 서비스의 관행이다. 지금은 눌러도 반응이 없어 사용자가 고장으로 여긴다. |
| 사이드바 검색 줄 제거 | 사이드바의 「검색 ⌘K」 줄이 없어지고, 「새 포트폴리오」 아래에 홈 · 라이브러리 · 탐색 · 분석이 바로 이어진다. | 머리글의 검색 단추와 ⌘K가 같은 검색 창을 이미 연다. 같은 일을 하는 자리가 둘이라 사이드바 메뉴만 길어진다. |

## 개발 목표

- 로고 홈 이동: 공고 탐색 화면에서 사이드바 로고를 누르면 홈 화면이 열린다.
- 키보드: Tab으로 로고에 초점을 옮기고 Enter를 누르면 홈 화면이 열린다.
- 검색 줄 제거: 사이드바에 「검색」 줄이 보이지 않는다. ⌘K와 머리글 검색 단추는 그대로 검색 창을 연다.
- 접힌 사이드바: 사이드바를 접으면 로고 자리에 펴기 단추가 서고, 그 단추는 지금처럼 사이드바를 편다.

## 범위 밖과 제약

- 검색 창(명령 팔레트)과 ⌘K 단축키는 바꾸지 않는다.
- 에이전트 대화 화면 오른쪽의 「대화와 자료」 칸은 같은 틀을 쓰지만 로고가 아니라 칸 이름을 보여 주므로 링크로 만들지 않는다.
- 화면 정의서(`docs/Expresso Screens.dc.html`)의 사이드바 시안은 고치지 않는다.
