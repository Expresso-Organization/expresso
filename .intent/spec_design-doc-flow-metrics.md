# 설계서 전체 사용자 플로우 그림과 순위 지표 설명 추가 — 명세

## 요구사항

- [ ] R1 2.1 「■ 이용 절차」 표 앞에 그림 2.1 「전체 사용자 플로우」가 있고, 표의 10단계 · 화면 번호와 같다.
      최초 1회 구간 · 공고마다 반복 구간 · 배포 뒤 되돌아가는 고리가 구분되어 보인다.
- [ ] R2 기존 그림 2.1 – 2.3은 2.2 – 2.4가 되고, 설계서 전체의 「그림 2.N」 참조가 새 번호를 가리킨다.
- [ ] R3 9.2 지표 표 뒤 「■ 순위 지표의 이해」에 NDCG@k · Recall@k 각각의 정의 · 식 · 계산 예시 · 읽는 법이 있다.
      gain은 교사 적합도 점수(선형), 할인은 log2(순위+1), Recall@k의 관련 공고는 교사 적합도 60점 이상.
- [ ] R4 계산 예시 그림 1장(그림 9.1)이 있고, 기존 9장 그림 번호와 참조가 하나씩 밀린다.
- [ ] R5 예시의 모든 숫자는 손계산과 스크립트 계산이 같다.
- [ ] R6 md 초안 02 · 09, PDF가 갱신되고 그림이 쪽 밖으로 넘치지 않는다.

## 설계

- 그림은 `svg.dg`와 역할 색 클래스(제안서 양식)로 그린다. 학습 모델 자리는 `.c-tr`, 최초 1회 구간 · 반복 구간은 `.grp` 묶음.
- 계산 예시: 공고 5건, 교사 점수 A 90 · B 75 · C 60 · D 40 · E 10. 모델 순서 B · A · C · E · D.
  NDCG@5와 Recall@k(후보 20건 중 관련 4건, k=5 · 10)를 보인다.

## 버린 대안

- 실제 파일럿 결과로 예시 만들기 — 프로필 하나의 점수를 골라 쓰면 결과 요약과 섞여 읽힌다.

## 완료 기준
