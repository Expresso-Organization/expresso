# 고른 디자인의 배치를 아는 Spec 생성

## 문제

포트폴리오의 구성(사례마다 어떤 모양으로 보여 줄지, 무엇을 좌우로 나란히 놓을지)은 모델이 정합니다. 그런데 모델은 사용자가 고른 디자인이 페이지를 어떻게 배치하는지 모릅니다. 디자인 시스템 38종은 배치가 세 가지로 갈립니다.

- 단일 열: 모든 섹션이 위에서 아래로 한 줄로 이어집니다(Clarity 등).
- 촘촘한 격자: 목록과 표를 두 칸으로 펼쳐 한 화면에 많이 담습니다(Linear Midnight 등).
- 넓은 여백: 섹션 제목을 왼쪽 좁은 칸에, 본문을 오른쪽 넓은 칸에 둡니다(Monochrome 등 17종).

모델이 받는 지시에서 디자인에 관한 것은 두 문장입니다. 하나는 "색·서체·간격은 디자인 시스템이 정한다"이고, 다른 하나는 예전 렌더러의 배치 이름(dossier 등)을 쓰라는 문장입니다. 지난 실제 생성(Linear Midnight)에서 모델은 구성 이유로 "dossier의 두 열 구조를 살렸다"고 썼습니다. 그런데 dossier는 지금 화면에 아무 영향이 없습니다. 모델은 실제 배치와 다른 이름을 근거로 구성을 고른 것입니다.

화면에서는 이렇게 드러납니다. Monochrome으로 그린 가상 프로필에서, 목차와 나란히 놓인 첫 사례는 제목이 본문 위에 있습니다. 나머지 사례는 제목이 왼쪽 칸에 있습니다. 한 페이지 안에서 사례 모양이 섞입니다.

모델은 화면에 영향이 없는 값도 고릅니다. 색 묶음 이름(`design.palette`, 예: graphite)과 서체 종류(`design.font`)는 지금 렌더러가 읽지 않습니다. 디자인 시스템의 색과 서체가 대신 쓰입니다.

근거 문서: `docs/architecture/portfolio-structured-pipeline-gaps.md` 결함 1 · 6, 이슈 #97 1단계.

## 원하는 결과

- 지금은 모델이 받는 지시에 고른 디자인의 배치가 없다 → 끝나면 지시에 그 디자인이 세 배치 중 무엇인지, 섹션 제목이 어디 놓이는지, 본문 폭이 얼마인지, 좌우로 나란히 놓을 때 어떻게 보이는지가 들어간다. 확인: 실제 생성 기록에 남는 프롬프트에서 해당 문단.
- 지금은 넓은 여백 디자인에서 나란히 놓인 사례만 넓은 여백 배치를 벗어나, 왼쪽 제목 칸이 페이지 중간에서 끊긴다 → 끝나면 왼쪽 칸과 오른쪽 칸의 경계가 페이지 위에서 아래까지 같은 자리에 있다. 확인: 가상 프로필 3종의 Monochrome 1440px 화면 캡처.
- 지금은 모델이 화면에 영향 없는 색 묶음 이름과 서체 종류를 고른다 → 끝나면 고르지 않는다. 확인: 새 생성 기록의 모델 출력에 두 값이 없음.
- 이미 만든 포트폴리오는 다시 열거나 편집해도 지금과 같은 모양으로 보인다. 확인: 저장된 판을 다시 그린 결과가 지금과 같음(기존 테스트).
- 확인 방법 전체: 가상 프로필 3종 × 디자인 3종(Clarity · Linear Midnight · Monochrome)을 다시 그려 브라우저 검사를 통과하고, 체험 서버에서 실제 생성 1회가 성공한다.

## 영향 범위

- 사용자: 디자인 시스템을 골라 새로 생성하는 모든 사용자.
- 바뀌는 곳: 모델에게 주는 지시, 모델이 고를 수 있는 값, 렌더러의 사례 배치.
- 결정 권한: Nedian0Brien.

## 제약

- 이미 저장된 포트폴리오의 모양과 데이터는 바꾸지 않습니다. 색 묶음 이름 · 서체 종류가 들어 있는 저장본도 계속 열립니다.
- 지시에 넣는 수치(본문 폭 등)는 디자인 시스템 값이나 렌더러 규칙에서 그대로 가져옵니다. 출처를 댈 수 없는 숫자를 만들지 않습니다.
- PR #98(토큰 키트) 위에서 작업합니다.

## 범위 밖

- 칸이 너무 좁아지는 배치를 막는 것: 아직 실제로 관찰된 사례가 없고, 실제 폭은 브라우저로 재야 정확합니다. #97 2단계(생성 중 브라우저 측정)에서 다룹니다.
- 수치 · 단계 · 전후 값 뽑기, 사례 종류 판정 기준: 3단계.
- 새 컴포넌트(수치 강조 줄, 단계 흐름, 차트): 5단계.
- 화면을 보고 고치는 수선 에이전트: 7단계.

## 열린 질문

- 넓은 여백 디자인에서 나란히 놓인 사례를 어떻게 맞출지. 두 방법이 있습니다. ① 나란히 놓인 사례 안에서도 제목을 왼쪽 칸에 둔다. ② 나란히 놓는 묶음 전체를 오른쪽 본문 칸 안에 넣는다. spec 단계에서 두 방법을 화면으로 그려 비교한 뒤 고르고, 그 화면을 보여 드립니다.
