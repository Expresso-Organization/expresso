# 개발 목표와 의도

첫 화면 그래픽이 계속 같은 틀로 나온다. 3D를 고르면 모델이 라이브러리에서 블루프린트나 점 격자를 집어 오고, 2D를 고르면 세 장이 모두
「흩어진 선이 한 다발로 모인다」였다. 사용자: "기본은 커리어 기록과 지원 대상, 포트폴리오 내용에 맞춰서 추상화된 디자인 요소를 canvas로
그리도록 하고, 3D 디자인 등은 사용자가 카탈로그에서 선택할 수 있는 요소로 하자."

끝나면 첫 화면 그래픽은 기본적으로 그 사람의 기록 · 지원하는 공고 · 포트폴리오에 담을 내용에서 나온 canvas 2D 그림이다. 3D나 안개 같은
효과는 모델이 고르지 않는다. 사용자가 짝 고르기 줄 옆의 그래픽 카탈로그에서 효과를 골랐을 때만 그 효과가 들어간다.

# 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 그래픽 카탈로그 | 스타일 · 레이아웃 줄 아래 「그래픽」 줄에 「기록에서 그림」과 효과 카드(입자 그물 · 점 격자 물결 · 색 안개 · 블루프린트 선화)가 놓인다. 「기록에서 그림」이 처음부터 골라져 있다 | 효과는 취향이라 사용자가 보고 고른다. 기본이 정해져 있어 고르지 않아도 첫 화면을 볼 수 있다 |
| 기본 그래픽은 기록에서 | 고른 효과가 없으면 모델은 canvas 2D로 그 사람만의 추상 그래픽을 짓는다. 형태는 기록 · 공고 · 내용과 고른 스타일 · 그림 자리에서 나온다 | 모델이 효과를 고르면 사람마다 같은 효과가 나온다 |
| 고른 효과만 싣기 | 효과를 고르면 프롬프트에 그 효과 하나의 쓰는 법만 실린다 | 모델이 목록을 보고 다른 효과로 바꾸지 않게 |
| 2D · 3D 칩 제거 | 짝 고르기 줄의 「2D · 3D」를 걷어낸다 | 카탈로그가 그 자리를 맡는다 |

# 개발 목표

- 짝을 고르면 바로 「첫 화면 보기」가 켜지고, 그린 첫 화면의 스크립트는 canvas 2D이며 `ExpressoEffects`를 부르지 않는다.
- 카탈로그에서 「점 격자 물결」을 고르고 그리면 첫 화면이 `ExpressoEffects.mount("dots"`를 부른다.
