# 공고 상세 우측 채팅 사이드바 접기 · 펼치기와 너비 조절

## 문제

공고 상세(`/jobs/[jobId]`)의 우측 채팅 사이드바는 316px로 고정이다. 공고 원문을 넓게 읽고 싶을
때 채팅을 치울 수 없고, 대조 · 계획 카드처럼 내용이 많은 대화는 316px에서 줄바꿈이 많아 읽기
어렵다.

## 원하는 결과

- 채팅 머리에 "접기" 버튼이 있다. 누르면 사이드바가 좁은 띠(56px)로 접히고 왼쪽 본문이 그만큼
  넓어진다. 띠의 버튼을 누르면 다시 펼쳐진다. 접힌 동안에도 대화 상태(입력 중인 글, 진행 중인
  응답)는 그대로다.
- 사이드바 왼쪽 경계를 끌어 너비를 바꾼다. 경계에 초점을 두고 ←/→ 키로도 바꾼다.
  - 최소: 316px(지금 너비, 카드들이 맞춰 그려진 폭)
  - 최대: 본문 폭에서 왼쪽 열 700px을 뺀 값(`page.module.css`의 "옆에 세우려면 최소 700px")
  - 창 크기가 바뀌어 최대보다 넓어지면 최대로 줄어든다.
- 접힘과 너비는 브라우저에 기억되어 다음에 공고를 열 때 그대로다. 저장값은 첫 페인트 전에
  적용해 펼쳐졌다 접히는 장면이 보이지 않는다(왼쪽 사이드바 `SidebarCollapse`와 같은 방식).
- 1023px 이하(사이드바가 본문 아래로 내려가는 폭)에서는 접기 버튼과 경계 핸들이 없고 지금처럼
  동작한다.
- 화면 정의서 06b의 우측 레일에 접기 버튼과 경계 핸들이 표시된다.

## 영향 범위

  `features/agent-chat/AgentChat.tsx`(공고 모드 머리에 접기 버튼 자리).
- `docs/Expresso Screens.dc.html` 06b.
- 백엔드 · 계약 · 데이터: 변경 없음.

## 제약

- 기존 패턴을 재사용한다: 끌기 · 키보드 · `role="separator"`는 `career/[categorySlug]/DocumentPanel`,
  기억 · 첫 페인트 전 적용 · 데스크톱 폭 한정은 `components/shell/SidebarCollapse`.
- 색 · 크기는 `--ex-*` 토큰만. 접힌 띠 56px은 왼쪽 사이드바의 접힌 폭과 같은 값이다.
- 공고 상세 페이지는 서버 부품으로 두고, 상태를 가진 부분만 클라이언트 부품으로 뺀다.
- 브랜치는 D(`feat/job-chat-rail-d`) 위에 쌓아 PR E로 올린다(base D). 미리보기 브랜치
  `dev/job-chat-rail-preview`에도 합쳐 개발 서버에 반영한다.

## 범위 밖

- 독립 채팅(`/agent`) · 기록 편집기 채팅의 크기 조절.
- 공고마다 다른 너비 기억(너비 · 접힘은 모든 공고에 하나로 기억한다).
- 서버에 사용자 설정으로 저장(브라우저 저장소로 충분한 화면 편의다).

## 열린 질문

1. 접힌 띠에 무엇을 둘까. 제안: 펼치기 버튼(채팅 아이콘)과, 응답이 진행 중이면 진행 표시
   하나만 둔다.
