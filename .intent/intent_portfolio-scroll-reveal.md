# 포트폴리오 스크롤 등장 애니메이션 공통 규칙

## 개발 목표와 의도

> "생성된 포트폴리오가 스크롤에 따른 자연스러운 등장 애니메이션을 갖도록 할 것."

생성된 지면에는 스크롤 등장이 이미 일부 있습니다. 지금은 사례 블록 하나가 통째로 한 번에 떠오릅니다. 화면 높이보다 긴 사례에서는 제목과 아래쪽 그림이 같은 순간에 함께 나타납니다. 경력과 근거 자료처럼 두 칸으로 묶인 블록은 아예 움직이지 않습니다(2026-10-27 생성 지면을 Chrome 151에서 재어 확인). 떠오르는 거리와 구간은 디자인과 상관없는 고정값입니다.

이번 변경은 지면의 모든 블록이 같은 규칙으로, 읽는 순서대로 나타나게 합니다. 이 규칙은 키트 공통 규칙입니다. 그래서 다른 세션이 키트에 더하는 시각화 · 배경 부품도 따로 손대지 않고 같은 등장을 받습니다. 스크립트 없이 CSS만 씁니다. 공개 지면은 스크립트를 막아 둔 iframe이기 때문입니다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 블록 안 조각별 등장 | 블록의 제목 줄, 본문, 그림 묶음이 각자 화면에 들어올 때 아래에서 떠오르며 나타납니다. 색 면 블록은 면이 먼저 보이고 글이 그 위로 떠오릅니다. | 블록 전체가 한 번에 나타나면 긴 사례의 아래쪽 그림이 아직 화면 밖에 있을 때 등장이 끝납니다. |
| 묶인 블록 포함 | 두 칸 묶음 안의 경력 · 근거 자료 블록도 같은 방식으로 나타납니다. | 지금은 이 블록만 움직이지 않아 지면 안에서 동작이 어긋납니다. |
| 나란한 항목 차례 등장 | 수치 띠, 목차, 경력 목록, 근거 자료 목록의 항목이 한 줄에 나란하면 왼쪽부터 조금씩 늦게 나타납니다. | 같은 높이의 항목이 동시에 나타나면 한 덩어리로 보입니다. 차례가 있어야 항목 수가 읽힙니다. |
| 디자인 값으로 움직임 | 떠오르는 거리는 디자인의 요소 간격, 곡선은 디자인의 모션 곡선을 씁니다. 촘촘한 디자인은 짧게, 넉넉한 디자인은 길게 떠오릅니다. | 고정값은 디자인 38종의 밀도 차이를 무시합니다. 색 · 크기를 토큰에서 가져오는 저장소 규칙과도 맞습니다. |
| 끄는 자리 | 생성 화면의 청사진 단계, 편집 화면 가운데 지면, 움직임 줄이기 설정, 지원하지 않는 브라우저에서는 등장 없이 내용이 처음부터 보입니다. | 청사진은 글이 차는 자리로 화면을 옮깁니다. 그 자리가 투명하면 채움이 보이지 않습니다. 편집 중에는 고친 곳이 바로 보여야 합니다. |
| 새 부품의 쓰는 법 | 키트 주석과 PR 본문에 공통 규칙의 이름(`data-reveal`)과 값 두 개를 적습니다. 차례 등장(`stagger`)과 등장 제외(`none`)입니다. | 동시에 도는 시각화 · 배경 세션이 이 글만 보고 새 부품에 맞출 수 있어야 합니다. 배경처럼 움직이면 안 되는 부품은 빠질 수 있어야 합니다. |

## 개발 목표

- 공개 지면(`/site/<slug>`)을 Chrome에서 아래로 스크롤하면 사례의 제목 줄이 먼저, 본문과 그림이 화면에 들어오는 대로 떠오릅니다.
- 같은 지면에서 경력 · 근거 자료 블록도 떠오릅니다. 수치 띠 항목은 왼쪽부터 차례로 나타납니다.
- Safari(WebKit)에서 같은 지면이 Chrome과 같은 순서로 나타납니다.
- 움직임 줄이기를 켠 브라우저에서 스크롤 전에도 맨 아래 블록까지 모든 글이 불투명합니다.
- 등장을 지원하지 않는 브라우저(Firefox ESR 153 등)에서도 같은 결과입니다. Firefox 안정판은 2026-10-27에 나온 159부터 등장을 지원합니다.
- 생성 화면의 청사진 단계와 편집 화면 가운데 지면에서 화면 밖 블록도 투명하지 않습니다.

## 범위 밖과 제약

- 이미 저장된 지면과 이미 배포된 사이트는 바뀌지 않습니다. 지면 CSS는 생성하거나 편집할 때 지면에 함께 저장되기 때문입니다. 새로 생성하거나 편집한 지면부터 적용되고, 배포된 사이트는 다시 배포하면 적용됩니다.
- 첫 화면(이름 소개)은 열자마자 보이는 자리라 지금처럼 열릴 때 한 번 떠오릅니다. 거리만 같은 디자인 값으로 맞춥니다.
- 수집 원본으로 그린 옛 지면(`.sp-page`)과 모델이 CSS를 쓴 자유 HTML 지면(`.k-*` 키트)은 손대지 않습니다.
- 디자인 시스템 계약은 바꾸지 않습니다.

## 열린 질문

- 디자인마다 등장의 종류를 다르게 할지 묻습니다. 지금 디자인 토큰이 가진 모션 값은 시간 140ms · 180ms 두 가지와 곡선 `ease-out` 하나뿐입니다. 성격 설명은 문장이라 CSS로 쓸 수 없습니다. 이번 변경은 거리(요소 간격)와 곡선만 디자인에서 가져옵니다. 종류까지 다르게 하려면 디자인 시스템 계약에 등장 종류 값을 더하고 디자인 38종을 채우는 별도 변경이 필요합니다.
  - 답(2026-10-28): 이번 변경에 넣지 않습니다.
