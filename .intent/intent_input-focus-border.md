# 텍스트 입력 포커스 테두리 제거

## 개발 목표와 의도

텍스트 입력 칸을 클릭해도 칸의 테두리가 바뀌지 않게 한다. 요청은 "텍스트 입력 부분을 클릭했을 때 테두리가 생기는데, 생기지 않게 하자. 검색 바에서 주로 생겨"이다.

지금은 홈과 채용 공고 화면의 검색 바를 클릭하면 테두리가 강조색으로 바뀌고 바깥에 3px 링이 생긴다. 로그인 입력 칸, 커리어 편집기의 검색 칸과 팝오버 입력 칸, 에이전트 채팅의 입력 칸에서도 같은 일이 일어난다. 화면마다 색과 두께가 달라 입력 칸을 누를 때마다 레이아웃과 어울리지 않는 선이 나타난다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 검색 바 테두리 고정 | 홈 · 채용 공고 · 디자인 카탈로그 · 커리어 편집기 · 에이전트 채팅의 검색 바를 클릭해도 테두리 색이 그대로이고 링이 생기지 않는다. | 요청자가 가장 자주 겪는 자리이다. |
| 입력 칸 테두리 고정 | 로그인, 새 포트폴리오 폼, 속성 편집, 필터, 표 셀 팝오버, 채팅 카드의 입력 칸을 클릭해도 테두리가 그대로이다. | 검색 바만 고치면 같은 선이 다른 입력 칸에 남는다. |
| 전역 포커스 링 제외 | 화면별 규칙이 없는 입력 칸에도 전역 포커스 링이 그려지지 않는다. | 전역 규칙이 근본 원인이라, 남겨 두면 새 입력 칸마다 링이 다시 생긴다. |
| 재발 방지 검사 | 입력 칸에 포커스 테두리 규칙을 다시 넣으면 테스트가 실패한다. | 화면이 많아 눈으로 확인해서는 재발을 막을 수 없다. |

## 개발 목표

- 검색 바: `/home`과 `/jobs`의 검색 바를 클릭했을 때 테두리 색과 그림자가 클릭 전과 같다.
- 입력 칸: 로그인 화면의 이메일 칸을 클릭했을 때 테두리 색과 그림자가 클릭 전과 같다.
- 입력 표시: 클릭한 입력 칸에 텍스트 커서가 깜빡이고 글자를 입력할 수 있다.
- 버튼: Tab 키로 버튼과 링크로 이동하면 기존 포커스 링이 그대로 보인다.

## 범위 밖과 제약

- 버튼, 링크, 체크박스, 라디오, 슬라이더, `select`의 키보드 포커스 표시는 유지한다. 커서로 위치를 알 수 없는 요소이기 때문이다.
- 입력 칸을 Tab 키로 이동했을 때도 링은 생기지 않는다. 텍스트 커서가 위치를 보여 준다.
- 포커스 때 배경색이 바뀌는 입력 칸의 배경 변화, 마우스를 올렸을 때의 테두리, 오류 상태의 빨간 테두리는 유지한다.
- 공개 포트폴리오 지면과 모바일 · 데스크톱 클라이언트는 다루지 않는다.
