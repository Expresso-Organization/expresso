# 새 포트폴리오 첫 화면 최신 공고 기본 표시

## 개발 목표와 의도

"공고 분석 첫 화면에서 최신 공고 목록은 기본으로 띄우도록 하자."

PR #183 이후 첫 화면(`/brew/new`)의 공고 줄은 관심 공고, 없으면 추천 공고만 보여 준다. 둘 다 없는 사람(새 계정 · 기록 0건)에게는 공고 줄이 아예 서지 않아, 모아 둔 공고가 수백 건 있어도 첫 화면에서 고를 공고가 없다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 최신 공고 줄 | 공고 칸에 「최신 공고」 묶음이 늘 서고, 들어온 순으로 여섯 건이 「이 공고로」 버튼과 함께 선다. 「전체 보기」는 공고 목록(`?mode=list`)을 연다. | 관심 · 추천이 없어도 첫 화면에서 바로 공고를 고를 수 있어야 한다. |
| 중복 제외 | 관심(또는 추천) 묶음에 이미 선 공고는 최신 공고에서 뺀다. | 같은 공고가 두 줄에 서면 고를 것이 줄어든 것처럼 보인다. |

## 개발 목표

- 관심 · 추천이 없는 계정으로 `/brew/new`를 열면 최신 공고 여섯 건이 선다.
- 관심 공고가 있으면 관심 공고 묶음 아래에 최신 공고 묶음이 선다.

## 범위 밖과 제약

- 공고 목록 화면 · 백엔드 · 계약은 바꾸지 않는다.
