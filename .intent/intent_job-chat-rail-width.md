# 공고 상세 채팅 레일 폭 채움 수정

## 문제

공고 상세(`/jobs/[jobId]`) 우측 채팅 레일에서 채팅이 레일 폭을 다 쓰지 않는다. 대화가 없는 첫 화면에서
채팅 머리 · 구분선 · 시작 제안 · 입력창이 내용 폭만큼만 그려지고, 오른쪽은 빈 레일로 남는다.
레일을 넓힐수록 빈 자리가 커진다(측정: 레일 560px · 채팅 258px). 기본 폭 316px에서도 같다.

원인: #84가 채팅을 감싸려고 넣은 `.railChat`이 가로 방향 flex 컨테이너이고, 그 안의 채팅 루트
(`AgentChat`의 `.rail`)에 폭 규칙이 없어 내용 폭으로 줄어든다. #84 이전에는 채팅 루트가 세로 방향
레일의 직접 자식이라 가로로 늘어났다. 메시지가 쌓인 대화는 긴 글이 폭을 밀어 드러나지 않았다.

## 원하는 결과

- 레일 폭(316px ~ 최대)에 상관없이 채팅 루트가 레일 폭을 다 쓴다. 첫 화면과 대화 화면 모두.
- 1023px 이하(레일이 본문 아래로 내려가는 폭)의 채팅 높이 · 모양은 지금과 같다.
- 접기 · 펼치기, 너비 조절 동작은 그대로다.

## 영향 범위

- 웹: `services/web/src/app/(app)/jobs/[jobId]/page.module.css`의 `.railChat`
- 백엔드 · 계약 · 데이터: 변경 없음
- 결정 권한: Nedian0Brien

## 제약

- 레일 껍데기가 만든 문제이므로 껍데기(`.railChat`)에서 고친다. `AgentChat`은 `/agent` · 기록 편집기와
  함께 쓰므로 건드리지 않는다.

## 범위 밖
