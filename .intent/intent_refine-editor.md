# 다듬기 화면 — 요소 선택 편집 · 목차 · 기록 추가

## 개발 목표와 의도

생성이 끝나면 사용자는 다듬기 화면에 도착합니다. 지금 이 화면에서는 지면의 한 부분만 골라 고칠 수 없습니다. AI에게 말하면 지면 전체가 다시 만들어집니다. 직접 고칠 수 있는 것은 속성 탭의 몇 가지 문장뿐이고, 인용·단계·수치는 고칠 수 없습니다. 「전체 배치」, 「첫 화면 원본」, 「사례 원본」 메뉴는 눌러도 화면이 그대로이거나 디자인 시스템이 통째로 사라집니다.

> "다듬기 화면은 크게 세 가지 기능을 제공해야 해 … 컴포넌트를 선택하고 AI에게 수정 사항을 전달 · 색상/폰트/글자크기 등 간단한 수정은 직접 · 목차 제공 및 순서 조정 · 내 커리어 기록 라이브러리에서 새로 추가할 기록을 고를 수 있게"

이번 변경이 끝나면 사용자는 지면에서 요소를 눌러 고르고, 그 요소만 AI에게 맡기거나 직접 고칩니다. 왼쪽에서는 지면의 차례를 보고 바꾸며, 아직 넣지 않은 커리어 기록을 골라 지면에 더합니다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 지면에서 요소 고르기 | 가운데 미리보기에서 첫 화면, 사례, 인용, 수치 띠 같은 요소를 누르면 테두리가 생기고 오른쪽 패널이 그 요소를 대상으로 열립니다. 왼쪽 목차에서 골라도 같은 요소가 선택되고 미리보기가 그 자리로 이동합니다. | 지금은 미리보기를 눌러도 아무 일이 없습니다. 고칠 대상을 정하지 못하면 부분 편집이 불가능합니다. |
| 고른 요소를 AI에게 맡기기 (오른쪽 · 채팅) | 고른 요소에 "이 문장 더 짧게"처럼 말하면 그 요소만 바뀐 새 판이 저장됩니다. 답에는 바뀐 곳 목록(전 → 후)과 「되돌리기」 버튼이 붙습니다. | 지금은 한 문장을 고치려 해도 지면 전체를 다시 만들어야 하고, 고치지 않은 부분까지 바뀝니다. |
| 고른 요소 직접 고치기 (오른쪽 · 속성) | 고른 요소의 글(제목, 요약, 본문, 설명, 인용, 단계, 수치)을 고칩니다. 제목·본문 같은 글자 부분마다 색, 서체, 글자 크기를 고릅니다. 요소가 가진 모양 선택지(첫 화면 구도, 크기, 배경, 폭)도 여기서 바꿉니다. | 인용과 단계 글을 고칠 수 없다는 보고가 있었습니다. 색이나 크기 같은 작은 수정에 AI를 부를 이유가 없습니다. |
| 지면 목차와 순서 바꾸기 (왼쪽 · 목차) | 왼쪽에 지면의 요소가 위에서 아래 순서로 보입니다. 위·아래 버튼으로 순서를 바꾸면 새 판이 저장되고 미리보기에 바로 반영됩니다. | 지금 왼쪽 목록은 실제 지면 구조가 아닌 옛 블록 섹션을 보여 줍니다. 순서를 바꾸는 방법은 속성 탭 깊은 곳에만 있습니다. |
| 커리어 기록 추가 (왼쪽 · 기록) | 왼쪽 「기록」 탭에 내 커리어 기록 목록이 보이고, 이 지면에 이미 쓰인 기록은 표시됩니다. 쓰이지 않은 기록에서 「추가」를 누르면 그 기록으로 만든 사례가 다른 사례 뒤, 경력 · 근거 자료 · 연락처 앞에 더해집니다. | 생성 때 고르지 않은 기록을 나중에 넣으려면 지금은 포트폴리오를 처음부터 다시 만들어야 합니다. |
| 미리보기 등장 애니메이션 끄기 | 편집 화면의 미리보기에서는 요소가 스크롤에 따라 나타나는 애니메이션이 돌지 않습니다. 배포 지면에는 그대로 있습니다. | 애니메이션이 돌면 고른 요소가 늦게 보이거나 위치가 흔들려 편집이 어렵습니다. |
| 「전체 배치」·「첫 화면 원본」·「사례 원본」 메뉴 제거 | 속성 탭에서 세 메뉴가 사라집니다. | 「전체 배치」는 바꿔도 화면이 그대로입니다. 「원본」 둘은 하나만 골라도 디자인 시스템이 지면 전체에서 사라집니다. 동작하지 않거나 예상과 다르게 동작하는 메뉴는 남기지 않습니다. |
| 다듬는 중 저장 시 멈춘 표시 수정 | AI가 화면을 다듬는 동안 사용자가 저장해도 「AI가 다듬는 중」 표시가 정상으로 끝납니다. | 지금은 그 경우 표시가 영원히 남고 화면이 8초마다 새로고침됩니다. |

## 개발 목표

- 요소 고르기: 미리보기에서 사례 하나를 누르면 테두리가 생기고, 오른쪽 패널 제목이 그 사례 이름으로 바뀝니다.
- AI 수정: 고른 인용에 "더 짧게"라고 보내면 그 인용만 바뀐 새 판이 생기고, 「되돌리기」를 누르면 앞 판으로 돌아갑니다.
- 직접 수정: 사례 제목의 색을 강조색으로, 글자 크기를 한 단계 크게 바꿔 저장하면 미리보기와 배포 지면에 같은 모양이 보입니다.
- 목차: 사례 두 개의 순서를 바꾸면 미리보기와 「미리보기」 새 창에 바뀐 순서가 보입니다.
- 기록 추가: 쓰이지 않은 기록을 추가하면 목차와 미리보기에 새 사례가 생기고, 배포 후 공개 주소에서도 보입니다.

## 범위 밖과 제약

- 옛 블록 지면 편집기와 자유 HTML 지면은 고치지 않습니다. 자유 HTML 지면은 지금처럼 지면 전체를 채팅으로 고칩니다.
- 색·서체·글자 크기는 고른 디자인 시스템이 가진 값 안에서만 고릅니다. 임의의 색 코드나 px 값은 받지 않습니다.
- 요소 숨기기·삭제, 새 부품 종류 추가, 지면 전체의 디자인 시스템 바꾸기는 하지 않습니다.
- 다른 세션이 키트에 더하는 새 부품도 편집 칸이 나타나도록, 편집 칸은 부품 정의(카탈로그)에서 읽습니다.
- 데이터베이스 마이그레이션은 필요하지 않습니다.

## 열린 질문

- 직접 수정의 색·서체·크기를 디자인 시스템 값으로만 제한합니다(위 제약). 임의 값이 필요하면 지금 알려 주세요.
- 기록을 추가할 때 AI가 기록을 읽고 사례 글을 씁니다. AI가 꺼져 있으면 기록 제목과 본문을 그대로 사례에 넣습니다. 처음부터 기록 본문을 그대로 넣는 쪽을 원하면 알려 주세요.
- 목차에서 요소를 숨기거나 지우는 기능은 넣지 않았습니다. 필요하면 범위에 더합니다.
