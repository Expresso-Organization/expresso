# 메일 인프라와 비밀번호 재설정 · 이메일 인증

## 문제

서비스가 메일을 보낼 수단이 없다. 그래서 세 가지가 막혀 있다.

- 비밀번호를 잊은 사용자는 계정을 되찾을 길이 없다. 로그인 화면의 "잊으셨나요?"는
  글자만 있고 눌리지 않는다.
- 가입한 이메일이 본인 것인지 확인하지 않는다. 남의 주소로 가입할 수 있고, 그 때문에
  Google 연결이 비밀번호 확인을 강제하는 우회 설계를 안고 있다(`identity.ts` 주석).
- 회원가입의 약관·개인정보 처리방침 동의가 화면 안에서만 켜지고 서버에 남지 않는다.
  동의 문서도 없다 — 링크가 `<span>`이다.

## 원하는 결과

- 백엔드가 메일 공급자 어댑터 하나를 통해 메일을 보낸다. 공급자는 Resend(HTTP API),
  발신 도메인은 `expresso.kr`. 개발·CI는 `off` 어댑터가 본문을 로그로 남기고 실제로는
  보내지 않는다. 공급자 이름과 자격은 환경 변수로만 들어간다.
- 비밀번호 재설정: 로그인 화면의 "잊으셨나요?"에서 이메일을 넣으면 재설정 링크가
  메일로 간다. 링크는 한 번만 쓰이고 제한 시간이 있다. 새 비밀번호를 정하면 그 계정의
  **다른 세션이 모두 끊기고** 새 세션으로 로그인된다. 가입 여부를 응답으로 알려 주지
  않는다 — 있든 없든 같은 화면.
- 이메일 인증: 가입 직후 인증 메일이 간다. 인증 전에도 앱은 쓸 수 있으나 **포트폴리오
  발행(publishing)** 은 인증 뒤에만 된다. 앱 안에 "인증 메일 다시 보내기"가 있다.
  Google로 가입하면 Google이 확인한 이메일이라 인증된 상태로 시작한다.
- 약관·개인정보 동의: 가입 요청이 동의 여부와 문구 판을 함께 보내고, 서버가 사용자에게
  기록한다. 동의 없는 가입은 400. `/terms` · `/privacy` 문서 페이지가 있고 가입 화면의
  링크가 거기로 간다.
- 메일 발송 요청은 짧은 시간 안에 같은 주소로 반복할 수 없다(재설정·인증 각각).
- 백엔드 통합 테스트가 재설정 흐름 · 인증 흐름 · 동의 기록을 `off` 어댑터로 검증한다.

## 영향 범위

- `packages/contracts` — 재설정·인증·동의 요청 스키마, 사용자 응답에 인증 상태
- `packages/database` — 사용자 문서에 인증·동의 필드, 일회용 토큰 컬렉션
- `services/backend` — `platform/mail` 어댑터, `identity` 모듈에 재설정·인증, `publishing`에 인증 게이트
- `services/web` — 재설정 요청·완료 화면, 인증 완료 라우트, 인증 안내 배너, 약관·개인정보 페이지, 가입 폼
- 운영 — Resend 계정, `expresso.kr` DNS(SPF · DKIM · DMARC), API 키
- 결정 권한: minjaepark

## 제약

- 토큰은 해시만 저장한다. 세션 토큰과 같은 원칙.
- 모듈 경계를 지킨다 — `publishing`은 `identity`의 속을 열지 않고 사용자 응답의 인증 상태만 본다.
- 메일 본문은 한국어, 화면 정의서의 말투를 따른다.
- 인증 게이트를 넣어도 기존 사용자(인증 필드 없음)의 이미 발행된 사이트는 내려가지 않는다.
- `AI_PROVIDER`처럼 `MAIL_PROVIDER` 기본은 `off`다.

## 범위 밖

- Google 연결 시 비밀번호 확인을 없애는 것 — 인증이 자리를 잡은 뒤 별도 판단
- 이메일 변경
- 마케팅·알림 메일(`engagement`의 `NotificationDeliveryProvider`에 메일 구현을 붙이는 일)
- SMTP 어댑터 — 인터페이스만 두고 구현은 필요할 때
- 속도 제한 미들웨어(`auth-rate-limit`) — 여기서는 메일 발송 간격만 본다
- 약관·개인정보 처리방침 **본문 작성** — 페이지와 자리는 만들고 문안은 사용자가 채운다

## 열린 질문

- 재설정 링크 유효 시간 30분, 인증 링크 24시간, 같은 주소 재발송 간격 60초 — **답: 제안값으로 확정.**
- 인증 전 막는 기능 — **답: 발행 하나만 막는다.** 제작은 막지 않는다.
- Resend 계정과 API 키, DNS 레코드 등록 — **답: 사용자가 한다.** 코드는 키 없이도 `off`로 돈다.
