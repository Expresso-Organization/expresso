# 개발 목표와 의도

포트폴리오 제작(공고 분석 → 재료 → AI 대화 → 디자인 → 생성)은 대화에서 끝까지 갈 수 있게 되었다(PR #268). 그런데 사이드바의 「새 포트폴리오」 ·
공고 상세의 「이 공고로 만들기」 · 라이브러리 · 홈의 「이어서 만들기」는 여전히 옛 단계 화면(`/brew/new` · `/brew/:id/analyze · materials · counter · design`)으로
간다. 공고 없이 만드는 길과 공고 붙여넣기 · 주소 읽기도 옛 화면에만 있다. 같은 일을 하는 길이 둘이라 어느 쪽으로 가도 반쯤만 이어진다.

사용자 결정(2026-11-21):
- 대화 전용으로 한다. 옛 단계 화면은 지우되 **카탈로그 화면은 남긴다** — 활용 방법은 따로 찾는다.
- 대화로 옮긴다: 공고 붙여넣기 · 주소 읽기, 편집의 「다시 뽑기」, 예상 분량, 카탈로그 판 · 구조화 생성(카탈로그 화면으로).
- 옛 화면에서 만들다 멈춘 제작은 대화로 이어 간다.

끝나면 「새 포트폴리오」는 새 대화를 열고 「공고로 · 공고 주소나 글로 · 공고 없이」 세 시작 제안을 보인다. 어느 길이든 대화 안에서 제작 카드가 뜨고,
「이어서 만들기」 · 「다시 뽑기」는 그 제작을 붙인 대화를 지금 단계의 카드와 함께 연다.

# 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 새 포트폴리오 대화 | 사이드바 · 라이브러리 · 공고 목록 · 편집 · 온보딩의 「새 포트폴리오」가 새 대화를 열고 세 시작 제안을 보인다 | 진입이 옛 화면으로 가지 않게 |
| 공고로 시작 | 공고 상세 · 온보딩의 「이 공고로 만들기」가 그 공고를 붙인 대화로 넘어간다. 에이전트가 찾은 공고로도 시작할 수 있다 | 공고 고르기가 대화에 있다 |
| 공고 주소 · 글로 시작 | 대화에 주소나 공고 글을 주면 에이전트가 읽어 공고로 등록하고 시작한다 | 목록에 없는 공고 |
| 공고 없이 시작 | 제목과 보여 주고 싶은 것을 물어 자유 제작을 연다. 카드는 분석 없이 「담을 기록 고르기」만 보인다 | 공고 없이 만드는 사람 |
| 예상 분량 | 시작할 때 한 장 · 두 장 · 세 장을 정한다(말하지 않으면 한 장) | 옛 화면에 있던 선택 |
| 이어서 만들기 | 진행 중인 제작을 그 제작을 붙인 대화로 연다. 없으면 대화를 새로 만들어 지금 단계의 카드를 붙인다 | 옛 화면에서 만든 제작도 이어 간다 |
| 다시 뽑기 | 편집의 「다시 뽑기」가 그 제작의 대화에 디자인 카드를 열고, 다 만든 제작도 한 번 더 만들 수 있다 | 옛 design?again=1을 대신한다 |
| 옛 화면 걷어내기 | analyze · materials · counter · `/brew/new`를 지우고 옛 주소는 대화로 넘긴다. 카탈로그 화면(`/brew/:id/design?view=catalog`)은 남는다 | 길을 하나로 |

# 개발 목표

- 사이드바 「새 포트폴리오」 → 새 대화에 세 시작 제안 → 「공고 없이」로 제목 · 내용을 말하면 대화에 제작 카드 → 재료 카드로 이어진다.
- 공고 주소를 주면 공고가 등록되고 분석 카드가 뜬다.
- 라이브러리의 진행 중 제작 「이어서 만들기」가 대화를 열고 그 단계의 카드를 보인다. 옛 단계 주소는 같은 곳으로 간다.
- 편집의 「다시 뽑기」가 대화의 디자인 카드를 열고, 다시 만들 수 있다.
