# 대화에서 포트폴리오 제작 시작과 공고 분석

## 개발 목표와 의도

> "에이전트 채팅을 기반으로 포트폴리오 생성 파이프라인을 이전하자. 다듬기 단계 이전까지의 모든 단계는 전부 에이전트 채팅 기반으로 진행하도록 하고, 필요한 경우 채팅 메시지 주변에 UI 스니펫을 띄우도록 하자."
>
> "제안 순서대로 진행. 지금의 단계별 화면은 레거시로 존치했다가, 에이전트 채팅 기반으로 이전이 끝나면 제거."

제작 흐름을 한 단계씩 에이전트 채팅으로 옮긴다. 이 변경은 그 첫 단계다 — 공고를 두고 "이 공고로 포트폴리오 만들어 줘"라고 말하면 대화 안에서 제작이 시작되고 공고 분석이 돈다. 분석이 끝난 뒤의 단계(재료 고르기부터)는 아직 지금의 화면으로 이어진다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 말로 제작 시작 | 공고가 연결된 대화(공고 상세의 채팅 레일, 또는 홈 대화에 공고를 붙인 것)에서 "이 공고로 포트폴리오 만들어 줘"를 보내면, 에이전트의 답 위에 「포트폴리오 제작」 카드가 뜬다. 카드에는 회사와 공고 제목이 적혀 있다. | 지금은 「새 포트폴리오」 화면에서 공고를 다시 찾아 눌러야 제작이 시작된다. 대화에서 공고를 보던 사람이 그 자리에서 시작할 수 없다. |
| 분석 진행 보기 | 카드에 진행 막대와 지금 단계(차례를 기다리는 중 → 요건을 뽑는 중 → 원문과 맞춰 보는 중 → 내 기록과 대조하는 중)가 보인다. 대화를 닫았다 다시 열어도 그때의 진행이 보인다. | 분석은 몇 분이 걸린다. 진행이 안 보이면 멈춘 것으로 보인다. |
| 분석 결과 보기 | 분석이 끝나면 같은 카드가 결과로 바뀐다 — 요건 몇 개 중 몇 개가 내 기록으로 확인되는지(확인됨 · 일부 · 없음)가 막대와 숫자로 보인다. | 제작을 이어 갈지 정하려면 내 기록이 이 공고에 얼마나 맞는지 알아야 한다. |
| 다음 단계로 이어가기 | 결과 카드의 「담을 기록 고르기」를 누르면 제작이 만들어지고 지금의 재료 고르기 화면이 열린다. 같은 카드를 다시 눌러도 같은 제작이 열린다. | 아직 옮기지 않은 단계는 지금의 화면이 맡는다. 한 단계를 옮길 때마다 처음부터 끝까지 쓸 수 있어야 한다. |
| 실패한 분석 다시 맡기기 | 분석이 실패하면 카드에 실패했다는 말과 「다시 분석」이 뜬다. 다시 해도 같은 자리에서 멈추는 실패에는 단추가 없다. | 일시적인 실패에서 대화를 처음부터 다시 하지 않게 한다. |
| 에이전트가 지금 상태를 앎 | 분석이 끝난 뒤 "어떻게 됐어?"라고 물으면 에이전트가 카드와 같은 수치로 답한다. | 에이전트가 옛 상태나 지어낸 결과를 말하면 카드와 말이 어긋난다. |

## 개발 목표

- 공고 상세의 채팅 레일에서 "이 공고로 포트폴리오 만들어 줘"를 보내면 카드가 뜨고 진행 막대가 움직인다.
- 분석이 끝나면 카드에 요건별 확인 수가 보이고, 「담을 기록 고르기」가 재료 고르기 화면을 연다.
- 같은 말을 한 번 더 보내거나 카드를 두 번 눌러도 제작은 하나다.
- 공고가 연결되지 않은 대화에서 같은 말을 보내면 에이전트가 어느 공고인지 묻는다.

## 범위 밖과 제약

- 재료 고르기 · AI 대화 · 구성 · 디자인 · 생성은 이 변경에서 옮기지 않는다. 지금의 화면이 그대로 맡는다.
- 공고 없이 만드는 제작, 공고를 붙여넣거나 주소로 가져오는 길은 지금의 「새 포트폴리오」 화면에 남는다.
- 「새 포트폴리오」 단추는 지금의 화면을 연다.
- 분석이 끝났을 때 에이전트가 먼저 말을 잇지 않는다. 카드가 결과로 바뀌고, 에이전트는 사용자가 말을 걸 때 지금 상태를 읽어 답한다.
- 공고 분석은 AI가 꺼진 서버에서 돌지 않는다(지금도 그렇다).
- 공고 분석 동의가 꺼진 계정은 대화에서 분석을 시작하지 못한다. 지금의 화면은 이 동의를 검사하지 않는다.

## 열린 질문

- 분석이 끝났을 때 에이전트가 먼저 말을 이어야 하는가. 이으면 대화가 스스로 흘러가지만 한 번에 약 3크레딧이 든다.
