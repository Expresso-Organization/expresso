# 화면 문구 어휘 표준화 — 명세

## 요구사항

- [ ] 설정 화면: 섹션 라벨 「화면」, 항목 이름 「테마」, 라디오 그룹 `aria-label` 「테마」. 선택지 라벨(밝게 · 어둡게 · 시스템)은 그대로.
- [ ] 아래 교체표의 「옛 말」이 `services/web/src`의 사용자 노출 문자열(JSX 텍스트, 문자열 리터럴, `aria-label`, 테스트가 확인하는 문구)에 남지 않는다.
- [ ] 백엔드 `HttpStatusError` · `PageServiceError` · `LayoutRemixError` 메시지와 계약의 사용자 노출 메시지(`layout.ts`, `structured-portfolio.ts` 오류, 프리셋 한 줄 설명)도 같은 표를 따른다.
- [ ] 조사가 맞는다(지면을→페이지를, 판이→버전이). 기계 치환 뒤 모든 변경 줄을 읽어 확인한다.
- [ ] 화면 정의서(`docs/Expresso Screens.dc.html`)의 같은 문구(1685행 「지면 순서」)도 바꿔 정의서와 구현이 어긋나지 않는다.
- [ ] `pnpm typecheck`와 `pnpm test`가 통과한다.

## 설계

문자열 리터럴만 바꾼다. 식별자(`id="surface"`, `data-theme`, `ex_theme`, CSS 클래스, 파일 이름)와 주석은 그대로 둔다.

**교체표**

| 묶음 | 옛 말 → 새 말 |
|---|---|
| 테마 | 지면(설정 섹션) → 화면 · 지면 밝기 → 테마 · 디자인 카탈로그 필터 「지면」→ 「테마」 |
| 인쇄 용어 | 지면 → 페이지 · 판(버전 뜻) → 버전 · 칼럼 → 열 · 액자 → 프레임 · 서체 → 글꼴 · 쪽(페이지네이션) → 페이지 · 완독 → 끝까지 읽음 · 스파크 → 스파크라인 · 해설 → 요약 |
| 커피 비유 | 재료(고르기) → 기록(선택) · 뽑기/뽑다 → 생성(요건은 추출) · 추출(포트폴리오) → 생성 · 줄 세우다 → 정렬 · 물어볼 자리 → 질문 근거 · 어떤 자리 → 어떤 직무 |
| 용어 일관 | 매칭도 · 매칭순 · 매칭 → 일치도 · 일치도 순 · 일치 |
| 어미 | ~하십시오 / ~십시오 → ~해 주세요 · 여쭙니다 → 다시 동의가 필요합니다 |
| 풀어 쓴 표현 | 무릅니다 → 되돌립니다 · 닿지 못했습니다 → 연결하지 못했습니다 · 들이지 못했습니다 → 등록하지 못했습니다 · 맡기는 중 → 요청하는 중 · 놓기 → 추가 · 나갑니다/나가지 → 배포됩니다/배포하지 · 내려갔거나 → 삭제되었거나 · 잇기/잇습니다 → 연결 · 갔습니다 → 보냈습니다 · 칸(입력) → 입력란 · 지원 창구 → 고객 지원 |
| 오류 화면 | 그 주소에는 아무것도 없습니다 → 페이지를 찾을 수 없습니다 · 화면을 그리지 못했습니다 → 화면을 표시하지 못했습니다 · 「그 …를 찾을 수 없습니다」 → 「…를 찾을 수 없습니다」 |

교체표의 모든 항목이 기계 치환되지는 않는다. 「판」은 `(?<![가-힣])판(?![가-힣])`로 후보를 모은 뒤 버전 뜻인 줄만 바꾼다(판단 · 판매 · 심판 제외). 「자리」 · 「칸」 · 「놓기」 · 「나가」는 뜻이 갈리므로 줄마다 문맥을 읽고 바꾼다.

**재사용**: 문자열은 각 컴포넌트에 흩어져 있고(`lib/usage-copy.ts`, `consent-copy`는 이미 한곳), 새 문구 모듈을 만들지 않는다. 구조를 바꾸지 않고 문자열만 바꾼다.

## 버린 대안

- 문구를 한 파일(i18n 사전)로 모으기: 요청 범위를 넘고, 약 2,000개를 옮기며 회귀 위험이 크다.
- 백엔드 AI 지시문까지 치환: 지시문이 바뀌면 AI 출력이 달라진다. 프로젝트 지침은 AI 출력 품질을 건드리는 변경을 따로 검증하게 한다.

## 함정

- 테스트가 문구를 확인한다: `GenerationWait.test.tsx`, `layout.test.ts`, `tokens.test.ts`, `EditablePagePreview.test.ts` 등. 문구를 바꾼 만큼 같이 바꾼다.
- `packages/contracts`를 바꾸면 `dist`를 다시 지어야 웹과 백엔드 테스트가 새 문구를 본다.
- 계약의 `portfolio-styles.ts` · `page.ts` · `page-kit.ts`의 긴 글은 AI에게 가는 지시문이라 바꾸지 않는다. 프리셋 한 줄 설명(사용자가 디자인 카탈로그에서 읽는 것)만 바꾼다.
- 검색 정규식(`/remote|리모트|재택/`)처럼 문구가 아닌 한글은 건드리지 않는다.

## 완료 기준

```
pnpm typecheck && pnpm test
git grep -nP '지면 밝기|(?<![가-힣])판(?![가-힣])|십시오|여쭙' -- 'services/web/src' ':!*.test.*'   # 주석 외 결과 없음
```

설정 화면을 열어 「화면 / 테마」가 보인다.
