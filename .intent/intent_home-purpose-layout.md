# 홈 화면 목적 기준 재구성

## 개발 목표와 의도

화면 정의서는 홈을 "지금 무엇을 해야 하는지 알려주는 화면"으로 정했습니다. 지금 홈은 이 일을 하지 못합니다.
기록이 19건인 dev01 계정으로 홈을 열면 「지금 나에게 맞는 공고」 카드에 머리줄(「추천 0 · 기록 19건 기준」)만 있고 내용은 비어 있습니다. 진행 중 제작 카드의 제목은 늘 「진행 중인 포트폴리오」입니다. 포트폴리오 카드 다섯 장은 제목이 같아 서로 구분되지 않습니다. 폰 폭에서는 본문이 가로로 50px 넘칩니다.
요청자의 말: "목적 기준으로 재구성하는데, 일단 개선안 시안을 먼저 보여주고 나서 본격적으로 작업하도록 하자."
이 변경은 그 뒤 합의한 시안(`/home/draft`)을 실제 홈으로 옮깁니다. 차트는 요청자의 기준인 "로직으로 대응할 수 있는 것"만 넣습니다. 이미 수집하는 데이터를 집계해서 그릴 수 있는 차트만 남긴다는 뜻입니다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 목표 직군 공고 카드 | 공고 카드에 「프론트엔드 17 · 관심 2」 탭이 생깁니다. 첫 탭은 온보딩에서 고른 직군의 진행 중 공고이고, 둘째 탭은 관심 공고입니다. 행마다 회사 로고, 직무, 마감(「상시」 · 「D-4」), 근무지와 경력을 보여 줍니다. 내가 분석한 공고에는 점수와 「요건 6/7 · 결제 연동」이 더 붙습니다. | 지금은 사용자가 직접 분석한 공고만 카드에 오릅니다. 그래서 기록이 충분한 사용자도 빈 카드를 봅니다. |
| 만들다 만 제작을 포트폴리오 격자로 | 끝나지 않은 제작이 「내 포트폴리오」 격자에 다른 카드와 같은 모양으로 들어갑니다. 카드에는 공고 제목과 회사, 멈춘 단계 이름(「AI 대화」)이 보입니다. 누르면 그 단계로 갑니다. | 지금 카드는 어느 공고의 제작인지 알려 주지 않습니다. 단계와 상관없이 버튼이 「이어서 답하기」이고, 7건 중 1건만 보입니다. |
| 포트폴리오 카드의 실제 지면 썸네일 | 카드 위쪽에 그 포트폴리오의 지면을 축소해서 보여 줍니다. 지면이 아직 없으면 사이드바와 같은 빗금을 보여 줍니다. 아래쪽에는 대상 회사와 공고, 배포한 사이트의 주소, 30일 방문 수, 연락처 클릭 수를 보여 줍니다. | 지금은 글자만 있어서 제목이 같은 카드끼리 구분할 수 없습니다. 요청자가 직접 썸네일을 요구했습니다. |
| 사이트 반응 차트 카드 | 배포한 사이트가 있으면 공고 카드 오른쪽에 차트 카드가 나옵니다. 차트는 「지원 반응」(사이트별 방문 추이), 「섹션 체류」(섹션마다 읽은 수와 평균 체류 시간), 「유입 경로」(출처별 방문) 세 가지입니다. 단추로 바꿔 보고, 손대지 않으면 8초마다 다음 차트로 넘어갑니다. 포인터를 올리면 멈춥니다. 배포한 사이트가 없으면 이 카드를 그리지 않습니다. | 배포한 포트폴리오가 읽히는지, 어느 섹션에서 방문자가 떠나는지, 어디서 들어오는지를 홈에서 볼 자리가 없습니다. 세 차트 모두 공개 사이트가 이미 수집하는 방문 데이터로 그립니다. |
| 기록 0건 첫 화면 | 기록이 없으면 검색창 대신 「첫 기록을 남기면 공고와 맞춰 볼 수 있습니다」 카드가 맨 위에 옵니다. 주 버튼은 「경험 기록하기」 하나이고, 「공고로 바로 만들기」는 약한 링크로 둡니다. | 지금은 비교할 기록이 없는 사용자에게 검색창부터 보여 줍니다. 버튼 두 개가 같은 무게로 경쟁하고, 0이 적힌 칸 7개가 본문을 차지합니다. |
| 검색창 정리 | 검색창 안의 「⌘K」 표시와 「이렇게 물어볼 수 있어요」 라벨을 지웁니다. 예시 질문은 내 목표 직군과 경력으로 만듭니다. | ⌘K를 누르면 이 검색창이 아니라 다른 검색 창이 열립니다. 예시 질문 4개는 데이터 엔지니어용으로 고정되어 있습니다. |
| 홈 본문의 「내 커리어」 7칸 제거 | 분류별 기록 수 7칸을 본문에서 지웁니다. | 사이드바가 같은 목록과 건수를 이미 보여 줍니다. |
| 반응 없는 단추와 링크 제거 | 「저장한 검색」 단추, 「추천 N」 단추, 홈 자신으로 가는 「전체 보기」를 지웁니다. | 눌러도 아무 일이 일어나지 않거나 같은 화면으로 돌아옵니다. |
| 폰 폭 수정 | 375px에서 가로 넘침을 없앱니다. 공고 제목은 두 줄까지 보여 주고, 포트폴리오 카드는 한 줄에 하나씩 놓습니다. | 지금은 가로 스크롤 막대가 생기고, 「추천 0」 단추가 글자 단위로 꺾입니다. |

## 개발 목표

- 빈 카드 없음: dev01(기록 19건, 분석한 공고 0건)으로 홈을 열면 공고 카드에 프론트엔드 공고가 보입니다.
- 만들다 만 제작: 포트폴리오 격자에 제작 카드가 단계 이름과 함께 보입니다. 누르면 멈춘 단계 화면이 열립니다.
- 썸네일: 지면이 있는 포트폴리오 카드에 실제 지면이 축소되어 보입니다. 지면이 없는 카드에는 빗금이 보입니다.
- 차트 카드: 배포한 계정에서는 차트가 8초마다 넘어가고, 포인터를 올린 동안 멈춥니다. 배포하지 않은 계정에서는 오른쪽 열이 없습니다.
- 폰 폭: 375px에서 홈에 가로 스크롤이 없습니다.

## 범위 밖과 제약

- 모든 공고에 요건을 일괄 추출하는 일, 추천 모델은 하지 않습니다. 점수는 사용자가 분석한 공고에만 붙습니다.
- 포트폴리오 목록 화면, 제작 삭제 · 보관, 사이드바 변경은 하지 않습니다.
- 로그아웃 버튼은 홈 헤더에 그대로 둡니다. 지금 앱에서 로그아웃할 수 있는 곳은 이 버튼 하나뿐입니다.
- 첫 화면 문구는 `fix/record-threshold` 작업이 정한 문장을 그대로 씁니다.
