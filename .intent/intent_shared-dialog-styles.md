# 공용 창의 Tailwind 의존 제거

## 개발 목표와 의도

> "이 작업을 여기에서 진행해 주세요: 공용 Dialog의 Tailwind 의존 제거"

앱의 공용 창(`components/ui/dialog`)은 화면 가운데 위치, 뒤를 흐리게 덮는 배경, 크기, 닫기 단추 모양을 모두 Tailwind 클래스로 잡는다. 그런데 Tailwind CSS는 포트폴리오 지면과 에이전트 채팅을 그리는 화면에서만 불린다. 그래서 같은 창이 커리어 화면에서는 가운데 뜨고, 홈에서는 페이지 맨 아래에 배경 없이 붙는다. 닫기 단추 옆에 영어 "Close"가 그대로 보이기도 한다. 포트폴리오 휴지통 작업(PR #215)을 홈에서 확인하다가 발견했다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 어느 화면에서나 같은 창 | 공용 창이 어느 화면에서 열려도 화면 가운데에 뜨고, 뒤 화면이 옅게 덮이며, 바깥 클릭 · Esc로 닫힌다. | 지금은 Tailwind가 불리지 않은 화면에서 창이 페이지 아래에 붙어, 확인 창을 띄우는 기능을 그 화면에 넣을 수 없다. |
| 닫기 단추 | 창 오른쪽 위의 닫기(×) 단추가 어느 화면에서나 같은 크기로 보이고, 화면 읽기 프로그램에는 "닫기"로 읽힌다. | 지금은 Tailwind가 없으면 단추 모양이 사라지고 "Close" 글자가 화면에 드러난다. |
| 기존 창 모양 유지 | 커리어 휴지통 창, 에이전트 채팅의 동의 · 자료 미리보기 · 계획 창은 지금과 같은 모양으로 보인다. | 고치는 목적은 안 보이던 화면을 맞추는 것이지 이미 맞는 화면을 바꾸는 것이 아니다. |

## 개발 목표

- 홈에서 공용 창을 열면 화면 가운데에 뜨고 뒤가 옅게 덮인다.
- 커리어 화면의 휴지통 창이 지금과 같은 자리 · 크기로 뜬다.
- 에이전트 채팅의 동의 창과 자료 미리보기 창이 지금과 같은 모양이다.
- 닫기 단추 옆에 "Close" 글자가 보이지 않는다.

## 범위 밖과 제약

- 공용 `Button`의 Tailwind 의존은 이번에 다루지 않는다. 창 안의 닫기 단추만 `Button` 없이 그린다.
- PR #215의 홈 휴지통 창은 이 변경이 머지된 뒤에 공용 창으로 되돌릴지 정한다.
