# 크레딧 계산과 먼저 연락하기의 요금제

## 개발 목표와 의도

> "A. 캐시 읽기 토큰을 낮은 무게로 계산 — 이거 적용"
>
> "먼저 연락하기/능동 제안 등은 사용자가 수행하는 게 아니라 우리 서비스 측에서 제공하는 것이므로 크레딧 차감하지 말자. 대신 유료 사용자 기능으로 이관."

마일스톤 1~6을 실제 대화로 검증하면서 두 가지가 드러났다.

첫째, 컨설턴트와 한 번 완주(진단 → 확인 질문 → 기록에 더하기 → 행동 권유 → 약속)하는 데 45크레딧이 든다. 무료 한도는 월 100크레딧이다. 쓴 토큰의 96%는 캐시 읽기인데, 캐시 읽기는 공급자가 입력 가격의 10분의 1로 받는 토큰이다. 지금은 캐시 읽기 1토큰을 입력 1토큰과 똑같이 센다.

둘째, 능동 제안은 사용자가 누르지 않아도 서버가 하루 한 번 AI를 실행하고 그 몫을 사용자의 크레딧에서 뺀다. 사용자가 시키지 않은 실행의 값을 사용자가 낸다.

이 변경은 캐시 읽기를 공급자 가격 비율대로 10분의 1로 세고, 서비스가 먼저 실행하는 능동 제안은 크레딧에서 빼지 않는다. 그 대신 먼저 연락하기(약속 확인 · 안부 · 능동 제안)를 유료 요금제의 기능으로 옮긴다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 캐시 읽기 10분의 1 | 크레딧을 셀 때 캐시 읽기 토큰은 10개를 1개로 센다. 한도 판단과 계정 화면의 사용량이 같은 셈을 쓴다. | 캐시 읽기는 공급자가 입력의 0.1배로 받는다. 지금 셈으로는 대화가 길어질수록 같은 일에 드는 크레딧이 계속 커진다. |
| 능동 제안은 크레딧에서 제외 | 능동 제안이 쓴 토큰은 이번 달 크레딧과 계정 화면의 사용량에 넣지 않는다. 호출 기록은 그대로 남긴다. | 사용자가 시키지 않은 실행이다. |
| 먼저 연락하기는 유료 기능 | 약속한 날의 확인 카드와 알림, 대화가 없을 때의 안부, 능동 제안은 Pro · Team 요금제에서만 켜지고 동작한다. 서버가 막는다. | 크레딧으로 받지 않는 AI 실행을 모든 사용자에게 열면 비용에 상한이 없다. |
| 무료 요금제의 홈 | 제안 구획에 규칙으로 센 제안(AI를 쓰지 않는다)과, 먼저 연락받기가 Pro부터라는 카드가 선다. | 이미 켜 둔 무료 사용자의 화면이 까닭 없이 비면 안 된다. |
| 무료 요금제의 약속 | 약속 저장과 약속 카드, 「내 진행」의 약속은 그대로 쓴다. 컨설턴트는 약속한 날에 먼저 묻겠다고 말하지 않는다. | 약속은 사용자가 대화에서 만든 것이다. 먼저 묻는 것만 유료다. |
| 온보딩의 항목 제거 | 동의 화면의 「컨설턴트가 먼저 연락합니다」 항목을 없앤다. | 새로 가입한 계정은 무료 요금제라 켤 수 없다. |
| 요금제 카드의 기능 줄 | Pro · Team 카드에 「컨설턴트의 먼저 연락과 제안」이 선다. | 요금제 카드는 서버가 실제로 여는 기능을 적는다. |
| 마이그레이션 번호 이동 | 이 스택의 0035 · 0036 · 0037을 0036 · 0037 · 0038로 옮긴다. | #253이 0035를 쓴다. #253을 먼저 병합하기로 했다. |

## 개발 목표

- 완주 한 번이 싸진다: 검증 계정 B의 이번 달 사용량이 83크레딧에서 12크레딧으로, 계정 A는 102에서 13으로 보인다(같은 호출 기록).
- 무료 계정은 켤 수 없다: 무료 계정으로 먼저 연락하기나 능동 제안을 켜는 요청을 보내면 서버가 거절한다.
- 이미 켠 무료 계정은 멈춘다: 하루 한 번의 제안 실행과 약속 확인 작업이 그 계정을 건너뛰고, 홈에는 규칙 제안과 Pro 안내 카드가 보인다.
- Pro 계정은 그대로 동작하고 크레딧이 줄지 않는다: 능동 제안이 한 번 실행된 뒤에도 이번 달 크레딧이 같다.

## 범위 밖과 제약

- **지금은 Pro로 올리는 길이 없다.** 결제가 연결되어 있지 않아 실제 사용자는 모두 무료 요금제다. 이 변경을 병합하면 운영에서 능동 제안을 켜 둔 사용자의 제안이 모두 멈춘다. 요금제의 `features`에 `consultant.outreach: true`를 넣으면 코드 변경 없이 그 요금제에 다시 열 수 있다.
- 캐시 읽기의 무게는 모든 AI 기능에 적용된다. 포트폴리오 생성 한 번은 약 9.8크레딧에서 약 2.5크레딧이 된다(저장된 생성 40건 평균 기준). 무료 100크레딧으로 한 달에 열 번쯤이던 생성이 마흔 번쯤이 된다. 요금제의 월 크레딧 값은 바꾸지 않는다.
- 무게는 0.1 하나다. 모델마다 다른 비율(0.05 · 0.025)을 따로 두지 않는다.
- 「했어요」로 여는 인터뷰는 사용자가 누른 대화라 크레딧에서 뺀다. 유료 사용자의 「다시 받기」는 능동 제안의 실행이라 빼지 않는다.
- 병합은 하지 않는다. #253이 먼저 병합되어야 하고, #253은 다른 세션의 PR이다.
