# 커리어 기록 편집기 디자인 시스템 정합

## 개발 목표와 의도

> "Expresso 커리어 기록 편집기의 UI/UX 디자인을 익스프레소 서비스의 디자인 시스템과 컨셉에 맞게 다듬어야겠다"

커리어 편집기는 표 · 셀 편집 · 그룹을 Notion 레퍼런스에 맞춰 여러 차례 다듬었다. 그 사이 문서 패널과 보드 · 타임라인은 따라오지 못했다.
2026-11-20 로컬 화면(1440×940, 밝은 · 어두운 테마, 390 폭)을 디자인 시스템 v0.3과 화면 정의서 05 · 05b에 대 보니 세 가지가 어긋났다.

- 브라우저 기본 컨트롤이 그대로 보인다. 패널의 역량 칸은 파란 OS 체크박스 목록이다. 시기 칸은 `2025. 03. 01.` 형식의 브라우저 날짜 입력 두 개다. 보드와 타임라인 카드에도 OS 체크박스가 늘 떠 있다. 디자인 시스템의 RULE 01(시스템은 무채색, 채도는 Espresso만)을 깬다.
- 문서의 왼쪽 선이 맞지 않는다. 패널에서 제목과 속성은 26px, 본문은 112px에서 시작한다. 전체 페이지에서는 속성이 920px 폭, 본문은 가운데 760px 열이다. 제목 위에는 「이력」 버튼 하나만 든 빈 줄이 있다.
- 크기와 표기가 정의서와 다르다. 화면 제목 「경험」이 18px이다(시스템의 화면 제목은 24px). 표의 시기 칸은 `2024-08-01 – 2024-09-3`처럼 ISO 날짜로 잘린다. 같은 값을 갤러리와 정의서는 `2024.08 – 2024.09`로 쓴다. 390 폭에서는 표 제목 칸 앞 96px가 보이지 않는 행 조작 단추 자리로 비어 있다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 속성 값을 칩 · 기간으로 보이고 표의 편집 팝업 재사용 | 패널 · 전체 페이지에서 선택 · 다중 선택은 칩으로, 날짜는 `2025.03 – 2025.04`로 보인다. 누르면 표에서 쓰는 옵션 목록 · 달력 팝업이 열리고, 새 옵션도 팝업 안에서 만든다 | 지금은 파란 OS 체크박스와 브라우저 날짜 입력이 보인다. 같은 값을 표와 패널이 다른 컨트롤로 고친다 |
| 문서 한 열 정렬 | 제목 · 속성 · 본문이 같은 왼쪽 선에서 시작한다. 패널의 「이력」은 머리말 줄로 옮긴다 | 지금은 본문만 86px 안쪽에서 시작해 한 문서로 읽히지 않는다. 제목 위 빈 줄이 첫 화면을 차지한다 |
| 카드 · 목록 선택 상자 통일 | 보드 · 타임라인 · 갤러리 · 목록의 선택 상자를 표와 같은 무채색 상자로 바꾼다. 마우스를 올리거나 골랐을 때만 보이고, 호버가 없는 기기에서는 늘 보인다. 보드 카드 아래 빈 칸(숨은 이동 단추 자리)을 없앤다 | OS 체크박스가 늘 떠 있어 카드마다 시선이 걸린다. 보드 카드에 이유 없는 빈 줄이 있다 |
| 기간 표기 통일 | 표의 날짜 칸을 프로젝트 갤러리와 같은 월 단위 `2025.03 – 2025.04`로 쓴다. 끝이 없으면 `2025.03` 한 달만 쓴다 | ISO 날짜가 칸 폭에서 잘리고, 같은 값이 화면마다 다르게 보인다 |
| 화면 제목 크기 | 카테고리 제목을 시스템의 화면 제목 단계(24px)로 올린다 | 18px 제목이 툴바 글자와 구분되지 않는다 |
| 좁은 화면의 표 제목 칸 | 768px 미만에서는 행 조작 칸을 선택 상자 하나 폭으로 줄인다 | 마우스 호버가 없는 폰에서 보이지 않는 단추가 96px를 차지한다 |

## 개발 목표

- 패널과 전체 페이지의 선택 · 다중 선택 · 날짜 칸, 카드 · 목록의 선택 상자에 OS 체크박스 · 브라우저 날짜 입력이 없다: 역량 · 시기 · 고용 형태 칸을 눌러 표와 같은 팝업이 뜨는지 본다(밝은 · 어두운 테마).
- 패널과 전체 페이지에서 제목 · 속성 이름 · 본문 첫 글자의 왼쪽 좌표가 같다.
- 보드 · 타임라인 카드에 평소 선택 상자가 보이지 않고, 올리면 표와 같은 상자가 보인다. 터치 기기(390 폭)에서는 늘 보인다.
- 표 · 프로젝트 갤러리 · 패널이 같은 기록의 기간을 같은 글자로 보인다.
- 390 폭 표에서 제목이 왼쪽 36px 안에서 시작한다.

## 범위 밖과 제약

- 사이드바 · 앱 셸 · 하단 대화 입력창(AgentChat) · 툴바 구성은 바꾸지 않는다. 화면 배치나 동작을 바꾸는 제안은 따로 묻는다.
- 정의서 05의 옛 배치(상태 열, 표 밖 집계 줄 등)를 되살리지 않는다. 지금 제품의 구조 안에서 값과 컨트롤만 맞춘다.
- 새 색 · 크기 값을 만들지 않는다. `tokens.css`의 토큰만 쓴다.
- 체크박스 속성 값, 카테고리 이동 대화상자, AI 제안 비교, 타임라인 축 설정의 기본 체크박스 · 날짜 입력은 그대로 두고 OS 파랑 대신 잉크 강조색(`accent-color`)만 입힌다.
- 일반 갤러리 카드의 날짜 칩(`propertyLabel`, `2023.03.01`)은 필터 · 타임라인과 함께 쓰는 표기라 이번에 바꾸지 않는다.

## 열린 질문

- 월 단위 표기는 일 단위 선택을 보이지 않는다. 끝 날짜를 12월 20일로 고쳐도 `2024.12`로 남는다. 일 단위(`2024.12.01 – 12.20`)가 필요하면 `formatPeriodRange` 한 곳만 바꾼다.
- 프로젝트 갤러리는 끝이 없는 기간을 `2025.02 –`(진행 중)로 쓰던 것을 `2025.02`로 바꿨다. 끝이 없다는 뜻이 "진행 중"이면 꼬리 `–`를 되살린다.
