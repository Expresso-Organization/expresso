# 사이드바 공고 탐색 숫자 제거

## 개발 목표와 의도

왼쪽 사이드바의 「공고 탐색」 오른쪽에는 숫자가 하나 붙어 있다. 이 숫자는 공고 수가 아니라
홈의 추천 공고 카드 개수이고, 일치도 점수가 계산된 공고가 5건 이상이면 항상 5로 보인다.
사용자는 이 숫자를 전체 공고 수나 새 공고 수로 읽게 되므로 의미가 틀린 정보다. 숫자를 없앤다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
| --- | --- | --- |
| 「공고 탐색」 오른쪽 숫자 제거 | 사이드바의 「공고 탐색」 행에 라벨만 보이고 숫자가 없다. | 값이 5로 고정되어 공고 수처럼 읽히지만 실제 뜻은 홈 추천 카드 개수다. |
| 사이드바의 홈 추천 공고 조회 제거 | 모든 앱 화면의 사이드바가 홈 요약 API를 따로 부르지 않는다. | 그 응답을 쓰던 곳이 숫자 하나뿐이라, 숫자를 지우면 화면마다 쓰이지 않는 조회가 남는다. |
| 화면 정의서의 숫자 제거 | `docs/Expresso Screens.dc.html`의 사이드바 목업에서 「공고 탐색」 옆 `44`가 없어진다. | 화면 정의서가 기준이라 코드만 고치면 둘이 어긋난다. `44`도 어떤 값인지 정해진 적이 없다. |

## 개발 목표

- 어느 앱 화면에서든 사이드바 「공고 탐색」 행에 숫자가 보이지 않는다. 활성 상태의 굵은 글씨와 아이콘은 그대로다.
- 사이드바 라벨이 긴 폭에서도 한 줄로 보이고 줄임표 처리가 이전과 같다.
- 화면 정의서의 사이드바 목업 20곳에 숫자가 없다.
- `pnpm typecheck`와 `pnpm test`가 통과한다.

## 범위 밖과 제약

- 홈 화면의 추천 공고 카드와 백엔드 `home()` 응답은 바꾸지 않는다. 홈 화면이 계속 쓴다.
- 「관심 공고」 그룹의 숫자는 담은 공고 총수라서 그대로 둔다.
