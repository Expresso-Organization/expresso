# 네 탭 구조와 홈 화면

## 개발 목표와 의도

Expresso를 에이전트 채팅이 기본 화면인 서비스로 바꿉니다. 지금은 홈이 공고 검색창과 공고 카드, 포트폴리오 격자를 보여 주고, 에이전트 채팅은 사이드바의 다섯 번째 메뉴에 따로 있습니다. 포트폴리오와 커리어 기록은 사이드바 목록으로만 들어갈 수 있습니다.
요청자의 말: "익스프레소 서비스의 기능은 크게 네가지로 모이게 돼. (홈(에이전트)/라이브러리/검색/분석)" 그리고 "채팅이 시작되기 전의 '홈 화면'을 만들고 싶은 거야."
그래서 기능을 네 탭으로 모으고, 홈을 대화를 시작하기 전의 화면으로 다시 만듭니다. 구조는 2026-11-15에 실제 화면 시안을 보며 하나씩 정했습니다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 네 탭 | 사이드바와 폰 하단 탭바의 메뉴가 「홈 · 라이브러리 · 탐색 · 분석」이 됩니다. 「에이전트 채팅」 메뉴는 없어지고 홈이 그 자리를 맡습니다. | 기능이 여섯 메뉴와 사이드바 목록 셋에 흩어져 있어 어디서 무엇을 하는지 알기 어렵습니다. |
| 새 포트폴리오 버튼 | 사이드바 맨 위에 에스프레소 색 「새 포트폴리오」 버튼이 섭니다. | 네 탭에 자리가 없고, 서비스의 주 동작이라 어느 화면에서든 누를 수 있어야 합니다. |
| 최근 대화 목록 | 사이드바 아래쪽에 에이전트와 나눈 대화가 최근 순으로 보이고, 누르면 홈에서 그 대화가 열립니다. | 포트폴리오 · 커리어 목록이 라이브러리로 옮겨 가면서 빈자리가 생기고, 하던 대화로 돌아가는 길이 필요합니다. |
| 라이브러리 | 왼쪽 목록에서 「포트폴리오 · 커리어 기록(분류 일곱 개) · 준비 계획 · 파일」을 고르면 오른쪽에 그 내용이 보입니다. 포트폴리오는 썸네일 격자, 커리어 기록은 지금의 분류 화면입니다. | 내가 만든 것을 한곳에서 관리하게 합니다. 포트폴리오는 목록 화면이 없었습니다. |
| 탐색 | 왼쪽 목록에서 「채용 공고 · 인턴 · 공모전 · 해커톤 · 부트캠프」를 고릅니다. 채용 공고는 지금의 공고 목록이고, 공모전과 해커톤은 위비티의 접수 중인 항목을 마감 순으로 보여 줍니다. | 채용 공고만 찾던 화면을 활동 전반을 찾는 화면으로 넓힙니다. |
| 홈 | 위에서 아래로 로고, 입력창, 추천 프롬프트, 제안, 위젯(채용 공고 · 공모전 · 인턴)이 섭니다. 말을 보내면 같은 주소에서 대화 화면으로 바뀝니다. | 요청자가 정한 배치입니다. 채팅 화면의 빈 상태를 옮긴 첫 시안은 반려됐습니다. |
| 펴지는 입력창 | 홈의 입력창은 pill 한 줄이고, 누르면 둥근 사각형으로 펴지면서 「자료 추가 · 파일 · 모델」 도구 줄이 나타납니다. 「자료 추가」로 기록 · 공고 · 포트폴리오를 열 개까지 대화에 연결합니다. | 요청자가 정한 동작입니다. 대화에 자료를 붙이는 일을 홈에서 바로 하게 합니다. |
| 추천 프롬프트와 제안 | 추천 프롬프트 단추와 제안의 「요건 대조하기」 같은 동작을 누르면 요청문과 자료가 입력창에 채워집니다. 보내기를 눌러야 AI가 실행됩니다. | 무엇을 맡길 수 있는지 보여 주고, 누른 것만으로 크레딧이 쓰이지 않게 합니다. |
| 기존 홈 구획 제거 | 홈의 공고 검색창, 공고 카드, 사이트 반응 차트, 포트폴리오 격자를 걷어냅니다. 사이드바의 포트폴리오 · 관심 공고 · 커리어 목록도 걷어냅니다. | 포트폴리오와 기록은 라이브러리로, 공고는 탐색으로 옮겼습니다. 같은 것을 두 곳에 두지 않습니다. |

## 개발 목표

- 네 탭: 사이드바에 「새 포트폴리오」 버튼과 네 탭, 대화가 있으면 「최근 대화」가 보입니다.
- 라이브러리: `/library`를 열면 포트폴리오 격자가 보이고, 왼쪽에서 「프로젝트」를 누르면 프로젝트 기록 화면이 오른쪽에 보입니다.
- 탐색: `/jobs?kind=contest`에 접수 중인 공모전이 마감 순으로 보입니다.
- 홈: `/home`의 입력창을 누르면 펴지고, 말을 보내면 대화 화면으로 바뀌어 에이전트가 답합니다.
- 폰 폭: 375px에서 홈 · 라이브러리 · 탐색에 가로 스크롤이 없습니다.

## 범위 밖과 제약

- 준비 계획 · 파일의 목록 화면은 자리만 둡니다. 목록을 주는 API가 없습니다.
- 파일 첨부와 모델 선택은 꺼진 단추입니다. 서버가 첨부를 받지 않고 모델은 서버 설정 하나입니다.
- 부트캠프는 출처(고용24 훈련과정 API)를 붙이지 않아 비어 있습니다. 활동을 관심에 담는 기능도 없습니다.
- 공모전 · 해커톤은 저장하지 않고 화면을 열 때 읽습니다. 수집과 저장은 「에이전트 능동 제안」 변경에서 합니다.
- 홈의 제안은 이 변경에서는 규칙으로 센 것입니다. 에이전트가 쓰는 제안은 「에이전트 능동 제안」 변경에서 합니다.
- 에이전트를 모든 사용자에게 여는 일(서버 인증 + 크레딧)과 대화 화면의 입력창은 바꾸지 않습니다.

## 열린 질문

- 해커톤을 공모전에 합치고 필터로 가를지 정해야 합니다. 지금 접수 중인 해커톤은 1건입니다. 정해지기 전까지 따로 둡니다.
- `/agent` 주소를 홈으로 넘길지 정해야 합니다. 지금은 그대로 열립니다.
