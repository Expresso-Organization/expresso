# 포트폴리오 병렬 생성

## 개발 목표와 의도

한 사람의 포트폴리오 생성이 도는 동안 다른 사람의 생성과 공고 분석이 차례를 기다리지 않게 한다. 지금은 분석 · 질문 · 구성 · 생성이 모두 동시 1개짜리 줄 하나에 서서, 생성 하나(3~5분)가 끝나야 다음 작업이 시작된다. 끝나면 두 사람이 동시에 생성을 눌러도 둘 다 바로 진행 화면이 움직이고, 생성 중에도 다른 공고 분석이 곧바로 시작된다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
| --- | --- | --- |
| 생성 전용 줄 | 포트폴리오 생성을 분석 · 질문과 다른 줄에 세운다. | 같은 줄이면 생성이 자리를 모두 차지할 때 30초짜리 분석도 몇 분을 기다린다. |
| 동시 실행 3개 | 생성 · 일반 작업 · 다듬기가 각각 세 개까지 함께 돈다. | 한 번에 하나만 돌면 사용자가 늘수록 대기 시간이 그만큼 늘어난다. |
| 동시 실행 수 설정 | 재배포 없이 `.env` 값으로 수를 바꾼다. | 구독 사용량 한도에 닿으면 수를 바로 낮춰야 한다. |

## 개발 목표

- 운영에서 생성 두 건을 겹쳐 실행하면 진행 구간이 겹치고 둘 다 완료된다.
- 생성이 도는 동안 시작한 공고 분석이 생성 완료를 기다리지 않고 끝난다.
- 같은 공고를 두 사람이 동시에 분석해도 요건이 한 벌만 저장된다.
