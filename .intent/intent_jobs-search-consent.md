# 공고 분석 동의 없는 공고 검색

## 개발 목표와 의도

「공고 분석」 AI 동의를 켜지 않은 사람이 공고 화면에서 검색어를 넣으면 화면 전체가 오류로 끝난다.
요청: "이 계정에서 공고 검색이 안되나? 한번 확인해봐" → "고쳐 줘".
운영에서 csh0624@gachon.ac.kr 계정이 2026-11-09 15:53 · 15:56에 검색했고, 두 번 모두 검색어 해석 API가 403(동의 필요)을 냈고 웹은 오류 화면을 그렸다. 가입자 20명 중 12명이 같은 상태다.
동의는 "공고 원문을 AI로 보내도 되는가"를 묻는 것이지 검색 자체를 막는 장치가 아니다. 동의가 없으면 AI로 보내지 않고 검색은 계속되어야 한다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 동의 없이 검색 | 동의가 없어도 검색어를 넣으면 결과 목록이 나온다. AI가 꺼진 서버와 같게 검색어 원문으로 공고 이름 · 원문에서 찾는다. 최근 검색에도 남는다. | 지금은 동의가 없는 사람에게 검색 기능이 통째로 없다. |
| 동의 안내 | 검색 카드의 「이렇게 이해했습니다」 자리에 "검색어 그대로 찾았습니다 · 공고 분석 동의를 켜면 검색어를 조건으로 나눠 읽습니다"와 「동의 설정 열기」 링크를 보여 준다. | 왜 조건 칩이 안 생기는지, 어디서 켜는지 알 길이 없다. |

## 개발 목표

- 동의 없는 계정으로 `/jobs?q=서울 백엔드`를 열면 오류 화면 대신 결과 목록과 동의 안내가 보인다.
- 안내의 「동의 설정 열기」를 누르면 설정 화면의 AI 사용 동의 묶음으로 간다.
- 동의를 켠 계정은 지금과 같이 조건 칩이 생기고 안내는 보이지 않는다.
- 동의 없이 검색해도 AI 호출이 일어나지 않는다(사용량 기록이 늘지 않는다).

## 범위 밖과 제약

- 동의를 대신 켜 주지 않는다. 검색 화면에 동의 스위치를 새로 두지 않는다.
- 공고 분석(`job_analysis`) 등 다른 AI 기능의 동의 처리는 바꾸지 않는다.
