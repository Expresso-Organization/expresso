# 에이전트 채팅 전체 개방

## 개발 목표와 의도

> "에이전트 채팅를 모든 사용자에게 열어"

지금 에이전트 채팅은 세 부류만 쓴다. 운영 `.env`에 ID를 적은 개발 멤버, 관리자가 대신 로그인한 더미 계정, 자기 Anthropic API 키를 등록한 사람이다. 그 밖의 계정이 홈 입력창에 말을 보내면 「API 키를 연결해 주세요」 창이 뜨고 답을 받지 못한다.

포트폴리오 제작 흐름을 에이전트 채팅 위로 옮기려 한다. 제작은 모든 사용자가 쓰는 기능이므로, 채팅이 먼저 모든 계정에서 열려야 한다. 2026-11-15에 정한 방향도 「서버 인증 + 크레딧 차감으로 전체 개방」이다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 키 없이 대화하기 | 어느 계정이든 AI 사용에 동의했으면 홈 · 에이전트 화면 · 공고 채팅 레일 · 기록 편집기 · 다듬기 화면의 입력창에 말을 보내고 답을 받는다. 「API 키를 연결해 주세요」 창과 「Anthropic API 키를 등록하면 채팅을 시작할 수 있습니다」 안내가 뜨지 않는다. | 키를 가진 사람만 쓸 수 있으면 제작 흐름을 채팅으로 옮길 수 없다. |
| 이번 달 크레딧 한도 | 이번 달 크레딧을 다 쓴 계정은 입력창 위에 「이번 달 AI 크레딧을 모두 썼습니다. 다음 달에 다시 대화할 수 있습니다.」가 뜨고 보내기가 꺼진다. 서버에 직접 보내도 거절된다. | 서버 인증으로 도는 실행은 서버가 비용을 낸다. 다른 AI 기능(지면 생성 · 디자인 대화)은 이미 같은 한도에서 멈춘다. |
| 개인 키는 선택 | 설정의 「AI 채팅」 구획에 키를 등록해 둔 사람은 지금처럼 자기 키로 대화하고 크레딧 한도에 걸리지 않는다. 구획의 안내가 「등록하지 않아도 채팅을 쓸 수 있습니다」로 바뀐다. | 이미 키를 등록한 사람의 대화가 갑자기 서버 비용으로 넘어가거나, 등록해 둔 키가 말없이 버려지면 안 된다. |
| 개발 멤버 목록 제거 | 환경 변수 `AGENT_CHAT_DEVELOPER_USER_IDS`와 그것을 읽는 코드를 지운다. | 모든 계정이 서버 인증을 쓰면 목록이 가르는 것이 없다. |

## 개발 목표

- 개인 키도 없고 개발 멤버도 아닌 계정으로 `/home`에서 말을 보내면 키 안내 없이 답이 온다.
- 요금제의 월 크레딧을 다 쓴 계정으로 같은 일을 하면 입력창 위에 한도 안내가 뜨고 보낼 수 없다.
- 개인 키를 등록한 계정은 크레딧을 다 써도 대화가 된다.
- 설정의 「AI 채팅」 구획에 키 입력란이 선택 사항이라는 안내와 함께 보인다.

## 범위 밖과 제약

- 운영에서 채팅이 켜져 있는지(`AGENT_CHAT_ENABLED=1`)는 서버 `.env`의 일이다. 이 변경은 그 값을 바꾸지 않는다.
- 대화 한 번의 비용: 도구를 한 번 쓰는 짧은 질문이 약 3크레딧이다(검증 서버 실측 — 입력 4 · 출력 59 · 캐시 읽기 26,826토큰, $0.12). 무료 요금제의 월 100크레딧은 이런 질문 약 33번이고, 지면 생성과 같은 한도를 나눠 쓴다.
- 지금까지 한도를 보지 않던 개발 멤버 계정과 대신 로그인한 더미 계정도 이제 한도를 본다.
- 한 번에 도는 실행 수에는 상한이 없다. 실행 하나가 API 서버에서 Claude Code CLI 프로세스 하나를 띄운다.
- 크레딧 계산법(이번 달 AI 사용 토큰의 합)은 바꾸지 않는다. 채팅 사용량은 이미 같은 장부에 적힌다.
- 동의 검사(커리어 기록 사용 동의)는 그대로다.

## 열린 질문

- 개인 키 기능을 계속 둘지. 지금은 그대로 두었다. 없애려면 저장된 키를 지우는 마이그레이션이 따르고, 지운 키는 되돌릴 수 없다.
