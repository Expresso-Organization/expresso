# 커리어 기록 저장된 뷰 완성

## 개발 목표와 의도

커리어 기록 카테고리 화면의 뷰가 설계 문서 「저장된 뷰」에 못 미친다. 2026-10-28 점검
보고서(`docs/architecture/career-record-editor-status-2026-10-28.md`)는 이 영역을 45%로
평가했다. 경험 카테고리에서 「보드」 탭을 누르면 열 머리에 `draft`가 그대로 보이고, 카드의
← · → 단추는 눌러도 아무 일이 없다. 「＋ 뷰 추가」를 누르면 「뷰를 복제했습니다」만 뜨고
새 뷰로 갈 방법이 없다. 패널에서 제목을 고쳐도 왼쪽 표는 새로고침 전까지 옛 제목이다.

사용자의 말 — 「최종 완료까지 진행해」(2026-10-28, 완성 계획 3단계 · 5단계 일부 승인).

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 여러 뷰 탭 | 탭 하나가 저장된 뷰 하나다. 탭을 누르면 그 뷰의 종류 · 필터 · 정렬로 바뀐다. 「＋ 뷰 추가」에서 종류를 고르면 새 탭이 생기고 그 탭이 열린다. 탭 메뉴로 이름 변경 · 종류 변경 · 복제 · 삭제를 하고, 탭을 끌어 순서를 바꾼다. 주소에 뷰가 남아 새로고침해도 같은 탭이 열린다. | 지금은 첫 번째 저장 뷰 하나만 쓰고 탭은 종류만 바꾼다. 「경력 순 타임라인」과 「진행 중 보드」를 함께 둘 수 없다. |
| 필터 조건 묶음 | 필터 창에서 조건을 여러 줄 쌓고 「그리고 / 또는」으로 묶는다. 조건 묶음 안에 묶음을 하나 더 둘 수 있다. 연산자와 값 입력은 속성 종류(글 · 숫자 · 날짜 · 선택 등)에 맞게 바뀐다. | 지금은 속성 하나의 「값 있음」만 고른다. 「2024년 이후 + 정리됨」 같은 조건을 만들 수 없다. |
| 다중 정렬 | 정렬 창에서 정렬 기준을 여러 줄 쌓고 끌어서 우선순위를 바꾼다. | 지금은 기준이 하나뿐이라 같은 날짜 기록의 순서를 정할 수 없다. |
| 그룹 순서 끌어 옮기기 | 속성 창의 그룹 목록에서 그룹을 끌어 순서를 바꾸고, 보드에서는 눈 아이콘으로 그룹 열을 숨긴다. | 지금은 그룹 이름을 쉼표로 타이핑해야 하고, 선택 속성은 내부 ID를 알아야 한다. |
| 보드 | 열은 「초안 · 정리됨 · 검증됨」 같은 표시 이름이고, 기록이 없는 열도 보인다. 카드를 다른 열로 끌면 그 기록의 상태(또는 그룹 속성 값)가 바뀐다. ← · → 단추는 옆 열로 옮긴다. | 그룹 값을 바꾸려면 기록을 하나씩 열어야 한다. 빈 열이 없어 카드를 옮길 자리도 없다. |
| 타임라인 | 시작 날짜 순으로 세로 시간 축에 기록이 놓이고, 왼쪽에 시작 · 종료 날짜가 보이고, 종료가 없으면 시작만 보인다. 해가 바뀌는 자리에 연도 눈금이 선다. 날짜 속성이 있는 카테고리는 처음부터 그 속성이 잡힌다. 동작 없는 ← · → 단추는 지운다. | 지금은 학력 · 이력에서도 「날짜 없음」 세로 목록이다. |
| 패널 편집 즉시 반영 | 오른쪽 패널에서 제목 · 속성을 고치면 왼쪽 표 · 보드 · 카드가 바로 바뀐다. 패널에서 새로 만든 속성은 지금 뷰의 표시 속성과 표 열에 들어간다. | 지금은 새로고침해야 반영되고, 새 속성은 표에 나오지 않는다. |
| 카테고리 안 검색 | 툴바의 검색 아이콘을 누르면 입력란이 열리고, 치는 대로 제목 · 본문에 그 말이 있는 기록만 남는다. | 지금은 주소창에 `?q=`를 직접 써야 한다. |
| 휴지통 | 머리말 「…」 메뉴의 「휴지통」에서 이 카테고리에서 지운 기록과 영구 삭제까지 남은 날을 보고 「복원」한다. 기록을 지우면 「되돌리기」가 함께 뜬다. | 지운 기록을 되살릴 화면이 없다. 서버에는 30일 보관과 복원이 이미 있다. |
| 머리말 정리 | 동작 없는 「공유」와 시계 아이콘을 지운다. 「…」은 휴지통 메뉴로 쓴다. | 눌러도 아무 일 없는 단추가 머리말에 있다. |
| 첫 기록 화면 | 기록이 하나도 없는 카테고리에서는 「조건에 맞는 기록이 없습니다」 대신 「새로 만들기」 · 「AI로 만들기」가 가운데 선다. 필터 · 검색 때문에 비었을 때는 무엇을 지울지 단추가 따로 뜬다. | 필터를 건 적 없는데 필터 결과 문구가 나온다. |
| 좁은 화면 툴바 | 375px에서 필터 · 정렬 · 속성 · 새로 만들기 글자가 한 줄로 서고, 넘치면 툴바가 가로로 밀린다. | 지금은 단추 글자가 두 줄로 꺾인다. |

## 개발 목표

- 경험 카테고리에서 「＋ 뷰 추가 → 보드」를 고르면 새 탭이 열리고, 새로고침해도 그 탭이 열려 있다.
- 필터 창에서 「시기 ≥ 2024-01-01 그리고 (역량 포함 협업 또는 제목 포함 장애)」를 만들면 표가 바로 줄고, 새로고침 뒤에도 같다.
- 보드에서 카드를 「초안」 열에서 「정리됨」 열로 끌면 패널과 DB의 상태가 「정리됨」이다.
- 학력 · 이력 타임라인에 시작 · 종료 날짜와 연도 눈금이 보인다.
- 기록을 지운 뒤 「…」 → 「휴지통」 → 「복원」하면 그 기록이 표에 다시 나온다.
- 375px 화면에서 툴바 단추 글자가 꺾이지 않는다.

## 범위 밖과 제약

- 본문 편집기(`features/career-editor/editor/**`, `session/**`, `packages/editor/**`,
  `services/backend/src/modules/career-editor/**`)는 다른 세션이 BlockNote로 바꾸는 중이라 건드리지 않는다.
- 목록 · 갤러리 미리보기의 본문 문제, 변경 이력 화면, 사이드바 「카테고리 추가」, 「수요 비교」 · 「인용 지표」 분석 뷰는 이번에 하지 않는다.
- 필터 · 정렬 · 검색은 불러온 기록(처음 100건, 「더 보기」로 100건씩)에 적용한다.

## 열린 질문

- 수락: 사용자가 2026-10-28 완성 계획 전체를 「최종 완료까지 진행해」로 승인했다. 이 지시를 intent 수락으로 본다.
- 저장 뷰가 하나도 없는 카테고리의 탭: 화면 정의서 05의 기본 탭(예: 경험 = 테이블 · 보드 · 타임라인)을 아직 저장하지 않은 뷰로 보이고, 하나를 처음 바꿀 때 기본 탭 전부를 저장한다.
