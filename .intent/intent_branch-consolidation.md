# 로컬 브랜치 정리와 승인 기능 통합

## 개발 목표와 의도
오래된 로컬 작업을 백업해 정리하고, 승인된 참고 링크 기록 보강과 공고 요건 추출 제어를 현재 제품에 연결한다. 사용자가 검토 페이지에서 승인한 검색 상태·경력 테이블·추이 차트를 제품에 반영한다.

## 기능 목록
- 참고 링크 기록 보강: 대화에서 받은 링크를 읽고 인용을 검증해 기록의 근거로 저장한다. 사용자가 작업물 설명을 다시 입력하는 부담을 줄인다.
- 요건 추출 설정 분리: 예약 실행의 공고 본문 읽기를 전체 AI 설정과 별도로 제어한다. 수집량에 따라 자동 발생하는 호출을 운영자가 제어한다.
- 비교 페이지: 검색 진행, 커리어 표, 추이 차트의 현재 모습과 선별안을 직접 조작해 본다. 선택한 변경을 제품에 연결하고 비교 예시를 유지한다.
- 백업과 정리: 불필요한 여섯 브랜치의 커밋·변경 파일·설정·실험 데이터를 복구 가능하게 보관하고 브랜치와 워크트리를 제거한다.

## 개발 목표
다섯 기능의 계약·단위·Mongo 통합 검증을 통과하고, 비교 페이지의 데스크톱·모바일·키보드·움직임 줄이기 상태를 브라우저에서 확인한다. 추천 모델 작업은 보류한다.
