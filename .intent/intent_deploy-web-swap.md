# 배포 중 웹 화면 오류 제거

## 개발 목표와 의도

배포가 도는 1~2분 동안 운영 사이트의 모든 화면이 「화면을 그리지 못했습니다」나 「기록을 불러오지 못했습니다」로 넘어간다.
요청자는 "홈 화면이 떴다가 바로 화면을 그리지 못했습니다로 이어져", "커리어 기록에서도 이게 뜨는데"라고 했다.
2026-11-10 10:55와 10:58에 #186·#187 배포가 연달아 돌았고, 그동안 홈이 그려진 직후 JS 파일 요청이 500을 냈다.
배포 스크립트가 운영 웹이 쓰고 있는 빌드 폴더를 그 자리에서 지우고 다시 짓기 때문이다.
배포 중에도 사용자가 보던 화면이 깨지지 않게 한다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 별도 폴더 빌드 | 새 웹 빌드를 운영 웹이 쓰지 않는 폴더에 짓는다. 빌드하는 동안 사이트는 이전 판으로 그대로 열린다. | 지금은 빌드하는 1~2분 내내 모든 화면이 오류로 넘어간다. |
| 재시작 직전 교체 | 웹을 멈추고 새 빌드로 바꾼 뒤 다시 띄운다. 화면이 끊기는 시간은 웹이 다시 뜨는 몇 초다. | 교체를 앞당기면 옛 프로세스가 새 파일을 읽어 같은 오류가 다시 난다. |
| 이전 판 JS 보존 | 새 빌드에 최근 7일 안의 이전 판 JS 파일을 함께 남긴다. | 배포 전에 열어 둔 탭이 옛 JS를 요청하면 지금은 404가 나고 오류 화면으로 넘어간다. |
| 빌드 실패 시 운영 유지 | 빌드가 실패하면 운영 웹은 이전 판 그대로 돈다. | 지금은 빌드가 실패하면 이미 지워진 빌드 폴더로 사이트가 깨진 채 남는다. |
| 직전 판 보관 | 바로 이전 빌드를 `.next-prev`로 남긴다. | 새 판에 문제가 있으면 다시 빌드하지 않고 폴더를 되바꿔 곧바로 되돌린다. |

## 개발 목표

- 배포 중 화면: 배포가 도는 동안 `https://expresso.ai.kr/home`을 새로고침해도 오류 화면이 나오지 않고 JS 요청이 500을 내지 않는다.
- 배포 결과: 배포 로그가 「배포 완료」로 끝나고, 서버에 `.next`와 `.next-prev`가 있다.
- 열어 둔 탭: 배포 전에 연 탭에서 다른 화면으로 옮겨도 오류 화면이 나오지 않는다.

## 범위 밖과 제약

- API와 Worker 재시작 방식은 바꾸지 않는다. 웹 재시작 몇 초의 끊김은 남는다.
- nginx와 systemd 유닛 파일은 바꾸지 않는다. 서버에 손으로 반영할 단계가 생기지 않는다.
