# 분석 빈 상태 본문 정렬

## 개발 목표와 의도
“익스프레소 분석 화면에서 이런 문제가 있네. 이거 좀 해결하자.”
배포한 포트폴리오가 없을 때 안내와 버튼이 본문 왼쪽으로 치우친다. 분석 화면의 남는 공간 가운데에 안내를 놓는다.

## 기능 목록
| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 빈 상태 본문 정렬 | 안내와 이동 버튼을 본문 가운데 배치한다. | 넓은 화면에서 안내가 왼쪽에 고립된다. |
| 좁은 화면 대응 | 기존 본문 여백과 스크롤을 적용한다. | 작은 화면에서도 안내와 버튼을 읽고 누를 수 있어야 한다. |

## 개발 목표
- 데스크톱에서 안내 묶음이 사이드바를 제외한 본문 중앙에 놓인다.
- 사이드바를 접어도 안내가 본문 중앙에 놓인다.
- 모바일과 낮은 창에서도 안내와 버튼이 잘리지 않는다.
- 이동 버튼을 누르면 기존 홈으로 이동한다.

## 범위 밖과 제약
방문 집계, 배포 판정과 안내 문구는 기존 동작을 유지한다. 외부 조직 저장소의 push는 사용자 결정 후 진행한다.
