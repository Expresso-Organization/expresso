# 같은 주소 재배포와 편집 후 배포 변경 표시

## 개발 목표와 의도

포트폴리오를 한 번 배포한 뒤 고치고 다시 배포하면, 같은 주소로는 두 번째 배포가 나가지 않습니다. 배포 화면에서 「v2 배포」를 눌러도 아무 일이 없습니다. 서버는 "slug is already reserved"(409)로 거절합니다. 편집한 뒤에도 배포 화면은 「공개본과 편집본이 같습니다」라고 보여서, 사용자는 고친 내용이 아직 공개되지 않았다는 것을 알 수 없습니다.

다듬기 화면(PR #138)을 검증하다가 발견했습니다. 첫 배포 v1은 모든 편집을 싣고 공개 주소에 나갔습니다. 그 뒤 인용 한 줄을 고치고 다시 배포하려 했지만 v2는 만들어지지 않았습니다.

이번 변경이 끝나면 사용자는 고친 뒤 같은 주소로 몇 번이든 다시 배포합니다. 배포 화면은 공개본과 편집본이 다를 때 그 사실을 보여 줍니다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 같은 주소로 다시 배포 | 이미 배포한 포트폴리오를 고친 뒤 「v2 배포」를 누르면 같은 주소로 v2가 나가고, 공개 주소에 바뀐 내용이 보입니다. | 지금은 첫 배포 뒤의 모든 배포가 막혀, 고친 내용을 공개할 방법이 없습니다. |
| 주소는 한 포트폴리오만 씀 | 다른 포트폴리오가 쓰고 있는 주소로 배포하면 「이미 쓰고 있는 주소」라는 안내와 함께 거절됩니다. | 재배포를 열면서 두 포트폴리오가 같은 주소를 차지하는 일이 생기면 안 됩니다. |
| 편집 후 변경 표시 | 배포한 뒤 지면을 고치거나 다시 만들거나 판을 되돌리면, 배포 화면이 「공개본과 편집본이 다릅니다」로 바뀌고 편집 화면 상단에는 「배포 후 변경됨」이 보입니다. | 지금은 고쳐도 「같습니다」로 보여, 다시 배포해야 한다는 것을 알 수 없습니다. |
| 배포 화면 문구 · 입력 수정 | 구조화 지면을 「자유 HTML 판」이 아니라 「지면 판」으로 부릅니다. 주소 입력의 형식 검사가 브라우저에서 실제로 동작합니다. | 지금은 지면 종류를 잘못 부르고, 주소 입력의 형식 검사가 브라우저 오류로 꺼져 있습니다. |

## 개발 목표

- 재배포: 배포 v1 → 편집 → 같은 주소로 「v2 배포」를 누르면 버전 목록에 v2가 생기고, 공개 주소에 편집한 글이 보입니다.
- 변경 표시: v1 배포 직후 배포 화면은 「같습니다」이고, 편집 한 번 뒤에는 「다릅니다」로 바뀝니다. v2 배포 뒤에는 다시 「같습니다」입니다.
- 주소 지키기: 다른 포트폴리오에서 같은 주소로 배포하면 거절되고 안내가 보입니다.
- 되돌리기: 버전 목록에서 v1으로 되돌리면 공개 주소에 v1 내용이 보입니다.

## 범위 밖과 제약

- 커스텀 도메인, 주소 변경 뒤 옛 주소 이동(리다이렉트) 규칙은 바꾸지 않습니다.
- 데이터베이스 마이그레이션 번호는 0025를 씁니다. 공유 체험 DB에 바로 돌리지 않고 복사본에서 시험합니다.
- 공개를 중단해도 그 포트폴리오의 주소는 계속 그 포트폴리오 몫입니다. 지금과 같습니다.
