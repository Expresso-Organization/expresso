# 운영 완주에서 드러난 컨설턴트 대화의 문제 여섯 건

## 개발 목표와 의도

> "지금 고침"

마일스톤 8에서 운영(`expresso.ai.kr`)의 더미 계정으로 진단 → 확인 질문 → 기록 → 권유 → 약속을 한 번 완주했다. 흐름은 끝까지 동작했지만, 처음 쓰는 사용자가 바로 마주치는 자리에서 문제 여섯 건이 보였다. 이 변경은 그 여섯 건을 고친다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 내부 이름을 쓰지 않는 답변 | 컨설턴트가 「jobGoal이 아직 비어 있어서」처럼 자료의 이름을 답변에 쓰지 않고 「구직 목표」처럼 화면의 말로 부른다. | 사용자는 `jobGoal`이 무엇인지 모른다. |
| 도구 사이의 말 정리 | 도구를 부르기 전에 한 말과 마지막 답변이 띄어쓰기 없이 붙지 않는다. 컨설턴트는 도구를 부르기 전에 자기 판단을 설명하지 않고, 사용자를 「사용자」라고 부르지 않는다. | 운영에서 「사용자가 설명한 … 저장하겠습니다.고른마켓 …」이 답변 앞에 붙었다. |
| 진단의 수를 한 곳에서 셈 | 진단 카드 · 컨설턴트의 답변 · 「내 진행」의 대화 요지가 같은 수를 쓴다. 경력 연차(참고)는 어느 수에도 넣지 않는다. | 같은 진단이 카드에서는 「미확인 2」, 답변에서는 「미확인 3」, 요지에서는 「확인 7 · 미확인 3」이었다. |
| 목표를 저장하면 이어서 진행 | 대화가 목표 카드에서 멈춰 있을 때 카드를 저장하면, 한마디를 더 보내지 않아도 컨설턴트가 하던 일을 잇는다. | 진단을 부탁했는데 목표를 저장한 뒤 「이제 진단해 주세요」를 다시 써야 했다. |
| 지나간 연결 오류를 지움 | 대화를 다시 읽다가 한 번 실패해도 오류 글을 띄우지 않고, 두 번 잇달아 실패했을 때만 띄운다. 다시 읽기에 성공하면 그 글을 지운다. | 요청 한 건이 502였을 뿐인데 「서버에 연결하지 못했습니다」가 계속 남았다. |
| 켠 직후에 다시 묻지 않음 | 먼저 연락받기를 켠 뒤 홈의 확인 구획이 새 상태를 받는다. | 켜자마자 「하기로 한 일 챙기기 — 여쭤봐도 될까요?」가 떴고, 새로 고쳐야 사라졌다. |

## 개발 목표

- 목표가 없는 계정으로 「목표 진단」을 누르면 답변에 `jobGoal`이 없다.
- 목표 카드에서 「저장」을 누르면 컨설턴트가 바로 진단을 시작한다.
- 진단 카드의 상태별 수, 답변의 수, 「내 진행」의 요지의 수가 같다.
- 기록을 저장한 답변이 「…저장하겠습니다.고른마켓…」처럼 붙어 있지 않다.
- 먼저 연락받기를 켠 직후 홈에 「하기로 한 일 챙기기」 카드가 없다.

## 범위 밖과 제약

- 대화를 3초마다 다시 읽는 주기와 목록을 10초마다 읽는 주기는 바꾸지 않는다.
- 목표 카드를 저장할 때 이어서 진행하는 것은 그 카드가 대화의 마지막 답변에 있을 때만이다. 지난 답변의 카드를 저장하면 저장만 한다.
- 이어서 진행하는 실행은 사용자가 누른 일이라 크레딧에 넣는다. 크레딧이 없거나 에이전트를 쓸 수 없으면 저장만 하고 멈춘다.
- 새 저장과 새 마이그레이션은 없다.
- 병합은 따로 묻는다.
