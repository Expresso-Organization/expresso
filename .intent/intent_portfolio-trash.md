# 포트폴리오 · 만들던 포트폴리오 휴지통

## 개발 목표와 의도

> "포트폴리오, 커리어 기록 등에 대한 삭제 버튼이 적절하게 제공되고 있지 않는 것 같아."

지금은 포트폴리오를 지울 방법이 아예 없다. 홈 「내 포트폴리오」에는 다 만든 포트폴리오와 만들다 만 제작(만들던 포트폴리오)이 같은 카드로 서는데, 어느 카드에도 메뉴가 없다. 시험 삼아 만든 포트폴리오나 중간에 멈춘 제작이 계속 쌓이고, 편집기에도 삭제가 없다. 공개를 멈추는 기능(공개 중단)만 있다.

이 변경은 포트폴리오와 만들던 포트폴리오를 휴지통으로 옮기고, 30일 안에 되살리고, 30일이 지나면 지운다. 사용자는 기록과 같은 30일 휴지통 방식을 골랐다. 커리어 기록 삭제는 PR #206에서 다뤘다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 홈 카드 메뉴 | 「내 포트폴리오」의 카드마다 오른쪽 위에 「…」가 생기고, 메뉴의 「휴지통으로 옮기기」로 확인 창을 거쳐 카드를 치운다. 만들던 포트폴리오 카드도 같다. | 포트폴리오 목록이 모이는 유일한 자리인데 지금은 카드를 치울 수 없다. |
| 편집기 메뉴 | 포트폴리오 편집 화면 도구 막대 오른쪽 끝에 「…」가 생기고, 같은 확인 창을 거쳐 옮기면 홈으로 돌아간다. | 편집하다가 이 포트폴리오가 필요 없다고 판단한 자리에서 바로 지울 수 있어야 한다. |
| 공개 중이면 공개 중단 | 배포된 포트폴리오를 옮기면 공개 주소가 바로 닫힌다(공개 중단과 같다). 확인 창이 이를 먼저 알린다. 되살려도 공개는 다시 켜지지 않고, 다시 배포해야 열린다. | 지운 포트폴리오가 공개 주소에 남아 있으면 안 된다. 기능 명세 T9.1.4도 공개 중단과 삭제를 함께 다룬다. |
| 휴지통 창 | 「내 포트폴리오」 머리의 「휴지통」 버튼이 지운 포트폴리오와 만들던 포트폴리오를 지운 날짜 · 남은 날과 함께 보여 주고, 「복원」으로 되살린다. | 잘못 지운 포트폴리오를 되살릴 길이 있어야 30일 휴지통이 뜻을 가진다. |
| 30일 뒤 영구 삭제 | 30일이 지나면 포트폴리오와 지면 · 배포 기록 · 방문 데이터가 함께 지워진다. 확인 창이 이를 알린다. | 기능 명세 T9.1.4는 삭제할 때 방문 데이터를 어떻게 처리하는지 안내하라고 한다. 지우지 않으면 휴지통이 숨김에 그친다. |

## 개발 목표

- 홈에서 초안 포트폴리오 카드의 「…」 → 「휴지통으로 옮기기」 → 확인하면 카드가 사라지고, 사이드바 목록에서도 빠진다.
- 배포된 포트폴리오를 옮기면 그 공개 주소(`/site/<주소>`)가 열리지 않는다.
- 「휴지통」 창에 옮긴 포트폴리오가 "30일 뒤 영구 삭제"와 함께 보이고, 「복원」을 누르면 홈 카드로 돌아온다.
- 만들던 포트폴리오 카드도 같은 순서로 옮기고 되살릴 수 있다. 생성 중인 제작은 옮길 수 없다고 알린다.
- 휴지통에 넣은 포트폴리오의 편집 주소를 직접 열면 「찾을 수 없음」이 나온다.

## 범위 밖과 제약

- 휴지통에서 바로 영구 삭제하는 버튼은 두지 않는다. 30일 정리만 한다.
- 사이드바 포트폴리오 줄에는 메뉴를 붙이지 않는다.
- 계정 데이터 내보내기는 휴지통 항목도 그대로 담는다.
