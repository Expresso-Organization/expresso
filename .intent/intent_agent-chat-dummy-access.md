# 대신 로그인한 더미 계정의 에이전트 채팅 권한

## 개발 목표와 의도

> "관리자 계정에서 접속할 수 있는 더미 계정에 에이전트 채팅 사용 권한 부여하자"

관리자가 /admin에서 더미 계정(예: 문가령)으로 대신 로그인하면 에이전트 채팅 화면에 "Anthropic API 키를 등록하면 채팅을 시작할 수 있습니다"가 뜨고 질문을 보낼 수 없다. 서버 Claude 인증은 운영 `.env`에 ID를 적은 개발 멤버만 쓸 수 있기 때문이다. 시연은 더미 계정으로 하므로, 공고 상세 채팅 레일을 시연 때 접어 두어야 했다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 대신 로그인 중 서버 인증 허용 | 관리자가 대신 로그인한 더미 계정은 개인 API 키 없이 에이전트 채팅 화면과 공고 상세 채팅 레일에서 바로 질문을 보낸다. | 더미 계정에 개인 키를 넣을 수 없어 시연과 확인에서 채팅을 쓸 수 없다. |
| 설정 화면 안내 문구 | 설정의 AI 채팅 구획이 "개발 멤버 계정" 대신 서버 인증을 쓰는 계정이라는 안내를 보인다. | 지금 문구는 더미 계정에 "개발 멤버"라고 말해 사실과 다르다. |

## 개발 목표

- 관리자가 더미 계정으로 대신 로그인한 뒤 `/agent`에서 키 등록 안내 없이 질문을 보내고 답을 받는다.
- 같은 상태에서 설정의 AI 채팅 구획에 API 키 입력란이 없다.
- 일반 사용자 계정은 지금처럼 개인 API 키가 있어야 질문을 보낼 수 있다.

## 범위 밖과 제약

- 더미 계정에 직접 로그인하는 길은 만들지 않는다. 더미 계정은 지금처럼 관리자 대신 로그인으로만 열린다.
- 운영 `.env`의 `AGENT_CHAT_DEVELOPER_USER_IDS`는 건드리지 않는다.
- 채팅 사용량 크레딧 차감 방식은 바꾸지 않는다.
