# 시연 전 제품 화면 결함 정리

## 개발 목표와 의도

시연 흐름을 운영에서 점검했을 때 심사위원에게 바로 보이는 결함 세 가지가 나왔다. 요청은 "위 문제들 다 해결하자"이다. 공고 탐색 첫 줄에 10월 3일에 마감한 박람회 공고가 보였고, 공고로 만든 포트폴리오는 홈과 공개 페이지 제목에 `Generated portfolio`로 나왔으며, 로그인 화면에는 눌리지 않는 GitHub 버튼이 있었다. 이 변경은 제품 코드에서 이 세 가지를 없앤다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 마감 공고 기본 제외 | 공고 탐색을 열면 마감이 지난 공고가 목록과 개수에서 빠진다. 관심 공고 목록에는 그대로 남는다. | 지원할 수 없는 공고가 첫 줄에 보이면 제품의 데이터를 믿기 어렵다. 관심 공고는 사용자가 저장한 것이라 사라지면 안 된다. |
| 일치도가 같을 때 최신순 | 일치도 순 목록에서 점수가 같거나 없는 공고는 최근 수집한 공고부터 나온다. | 지금은 내부 ID 순서라 사실상 무작위로 보인다. 기록이 적은 사용자는 목록 전체가 이 순서를 따른다. |
| 포트폴리오 기본 제목 | 공고로 만든 포트폴리오의 제목이 `쿠팡 지원 포트폴리오`처럼 나온다. 회사를 알 수 없으면 `새 포트폴리오`다. | 영어 자리 표시 문구가 홈 카드와 공개 페이지 제목에 그대로 노출된다. |
| GitHub 로그인 버튼 제거 | 로그인 · 회원가입 화면에서 눌리지 않는 GitHub 버튼이 사라지고 Google과 이메일만 남는다. 화면 정의서도 같이 고친다. | 백엔드 경로가 없어 동작하지 않는 UI다. |

## 개발 목표

- 마감 공고: 운영 `/jobs` 기본 목록에 마감이 지난 공고가 없고 전체 개수가 그만큼 줄어든다.
- 관심 공고: 마감이 지난 관심 공고는 `관심 공고` 목록에 계속 보인다.
- 제목: 공고로 새로 만든 포트폴리오가 홈 카드에 `<회사> 지원 포트폴리오`로 보인다.
- 로그인: `/login`과 `/signup`에 GitHub 버튼이 없다.

## 범위 밖과 제약

- 이미 만들어진 포트폴리오의 제목은 바꾸지 않는다.
- 공고 상세에서 연봉 · 근무 시간이 자격 요건에 섞이는 문제는 다루지 않는다. 운영 필수 요건 237건 중 한 공고의 3건뿐이고, 그 공고는 이미 마감되어 목록에서 빠진다.
- `BREW_INPUT_REJECTED`는 질문 근거가 3개 미만일 때의 정상 거절이고 화면이 이유를 안내하므로 바꾸지 않는다.
- Worker 재시작 처리는 별도 세션이 맡는다. `services/backend/src/worker/main.ts`를 건드리지 않는다.
- 온보딩의 GitHub 저장소 가져오기 항목은 시연 흐름 밖이라 건드리지 않는다.
