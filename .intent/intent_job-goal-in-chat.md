# 대화에서 구직 목표 읽기 · 고치기

## 개발 목표와 의도

에이전트 대화가 사용자의 구직 목표를 알고 답하게 하고, 대화 중에 목표가 바뀌면 그 자리에서 고칠 수 있게 한다. 사용자는 구직 목표가 "이후 에이전트 대화에서도 사용자의 메시지에 따라 바뀔 수 있도록 하고, 에이전트가 먼저 물어볼 수도 있도록" 하며, 에이전트가 "자신이 기록중인 목표와 실제 사용자의 목표가 달라진 것 같다고 느끼면 사용자에게 해당 부분에 대한 질문을 하도록 하고, 필요한 경우 메모리를 갱신"하게 하자고 정했다. 고칠 때는 사용자 확인을 받는다.

지금은 목표를 온보딩과 `/goal` 화면에서만 적을 수 있고, 대화는 목표를 읽지 않는다. 대화에서 "이제 백엔드로 가고 싶다"고 말해도 적어 둔 목표는 그대로다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 대화가 목표를 읽음 | 대화를 시작하면 에이전트가 적어 둔 구직 목표를 함께 받는다. 조언을 구하면 목표를 기준으로 답한다. 목표가 없으면 아는 것처럼 말하지 않는다. | 홈의 제안만 목표를 알고 대화는 모르면, 같은 에이전트가 자리마다 다른 사람처럼 답한다. |
| 목표 변경 카드 | 사용자가 대화에서 목표를 새로 말하거나 바꾸겠다고 하면 대화에 「구직 목표 변경」 카드가 선다. 바뀌는 칸마다 지금 적힌 글과 새 글이 나란히 보이고, 「저장」과 「그대로 두기」 버튼이 있다. | 사용자가 정한 대로 대화에서 목표가 바뀔 수 있어야 하고, 저장 전에 사용자가 확인한다. |
| 저장은 카드에서만 | 「저장」을 눌러야 목표가 바뀐다. 누르기 전에는 에이전트가 바꿨다고 말하지 않는다. 「그대로 두기」를 누르면 바뀌지 않고, 에이전트는 사용자가 다시 말하기 전에는 같은 변경을 되풀이해 권하지 않는다. | 에이전트가 잘못 읽은 목표가 확인 없이 저장되면 이후의 제안이 모두 틀린 기준으로 나온다. |
| 달라진 것 같으면 질문 | 사용자의 말이 적어 둔 목표와 달라 보이기만 하고 바꾸겠다는 말은 없으면, 에이전트가 목표가 바뀌었는지 한 번 묻는다. 그렇다고 답하면 카드가 선다. | 사용자가 정한 동작이다. 암시만으로 카드를 세우면 지나가는 말이 목표로 굳는다. |
| 목표가 없을 때 대화로 받기 | 목표가 없는 사용자가 진로 조언을 구하면 에이전트가 하고 싶은 일 · 가고 싶은 곳 · 시기를 한 번에 하나씩 묻고, 답을 모아 카드로 제안한다. | 사용자가 정한 대로 목표를 자연스러운 대화로 받는다. |
| 바뀐 칸만 고침 | 사용자가 하고 싶은 일만 바꿔 말하면 그 칸만 바뀌고 나머지 칸은 적어 둔 그대로 남는다. | 에이전트가 말하지 않은 칸을 다시 써서 바꾸는 일을 막는다. |
| 대기 카드는 하나 | 저장하지 않은 카드가 있는데 사용자가 고쳐 말하거나 다른 칸을 말해 새 카드가 서면, 앞선 카드는 버튼이 사라지고 「새 제안으로 바뀌었습니다」로 닫힌다. 새 카드는 앞선 카드의 칸을 이어받고, 같은 칸은 새로 말한 글이 이긴다. | 옛 카드를 나중에 눌러 새 목표를 덮어쓰는 일을 막는다. 칸을 하나씩 말해도 앞서 말한 칸이 사라지지 않는다. |

## 개발 목표

- 읽기: 목표를 적어 둔 계정이 대화에서 "어떤 준비를 해야 할까"라고 물으면, 답이 적어 둔 목표를 기준으로 삼는다.
- 바꾸기: "이제 백엔드 개발로 가고 싶어"라고 말하면 카드가 서고, 「저장」을 누른 뒤 `/goal` 화면에 새 글이 보인다.
- 그대로 두기: 「그대로 두기」를 누르면 `/goal` 화면의 글이 바뀌지 않는다.
- 질문: 목표와 다른 분야의 공고에 관심을 보이기만 하면 카드 없이 질문이 온다.

## 범위 밖과 제약

- 카드에서 글을 고쳐 저장하는 기능은 두지 않는다. 글을 다듬으려면 `/goal` 화면에서 고친다.
- 대화로 칸을 비우는 것은 받지 않는다. 비우려면 `/goal` 화면에서 한다.
- 대화에서 목표를 바꿔도 이미 만든 홈의 제안은 바뀌지 않는다. `/goal`에서 저장할 때와 같다.
- 목표를 기준으로 「부족한 점」을 판단하는 것은 다음 변경이다.
