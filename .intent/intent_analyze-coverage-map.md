# 공고 분석 화면 충족 지도와 원문 근거 표시

## 개발 목표와 의도

요청은 이렇다. "텍스트가 너무 많아. 글이 아니라 레이아웃과 시각적 신호로 말하게 해야 하는데 죄다 글로 써져 있어." 지금 공고 분석 화면은 같은 요건 문장을 왼쪽 목록, 오른쪽 목록, 오른쪽 아래 안내 상자에 세 번 적고, 요약 문장이 그 수를 다시 설명한다. 게다가 데이터 분석가 계정에서 Python과 SQL이 든 기록이 15건인데도 `6개 중 0개`로 나온다. 계산이 공고 문장의 "보유하신 분"까지 기록에 있기를 요구해 사실상 `기록 있음`이 나올 수 없기 때문이다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 충족 막대 | 공고 제목 아래에 요건 하나당 한 칸인 막대가 놓인다. 칸의 채움으로 충족 상태를, 필수와 우대 사이의 틈으로 묶음을 보여 준다. | 요약 문장을 읽지 않고 한눈에 얼마나 준비됐는지 알아야 한다. |
| 요건 목록 | 상태 표시, 요건 이름, 근거 기록 수만 남는다. 비어 있는 요건은 밝게 보이고 대화 아이콘이 붙는다. | 태그와 번호, 인용이 한 줄에 몰려 줄이 깨지고 무엇이 비었는지 안 보인다. |
| 원문 위 근거 표시 | 오른쪽에 공고 원문 전체가 나오고, 요건의 근거 문장이 상태 색으로 표시된다. 요건에 마우스를 올리거나 누르면 해당 문장이 강조되고, 문장을 누르면 요건이 강조된다. | 같은 문장을 다시 나열하는 대신 근거가 원문의 어디인지 직접 보여 준다. |
| 설명 문장 제거 | "이 공고가 건 조건", "AI 분석", 요약 문장, 원문 안내, 대화 안내 상자, 번호, "분석 v1"이 사라진다. | 레이아웃이 전달하는 뜻을 글로 반복한다. |
| 충족 계산 수정 | 요건에 든 핵심 키워드가 내 기록에 모두 있으면 `기록 있음`이 된다. | 지금은 어떤 계정도 `기록 있음`을 받기 어려워 화면의 신호가 무의미하다. 일치도와도 어긋난다. |

## 개발 목표

- 문가령 계정으로 쿠팡 판매자 데이터 분석 공고를 다시 분석하면 Python · SQL 요건과 Airflow 요건이 `기록 있음`으로 보인다.
- 화면에서 같은 요건 문장이 한 번씩만 보인다. 라벨과 원문 문장이 다를 때 원문 문장은 오른쪽 원문 안에만 있다.
- 요건에 마우스를 올리면 원문의 해당 문장이 강조되고, 누르면 그 문장까지 스크롤된다.
- 필수와 우대의 칸 사이에 틈이 있고, 막대 칸 수가 요건 수와 같다.
- 390px 폭에서 줄이 깨지지 않고 원문이 목록 아래로 내려간다.

## 범위 밖과 제약

- 이미 분석된 공고의 충족 상태는 `다시 분석`을 누르거나 다시 계산될 때 바뀐다.
- 근거 기록의 제목 목록을 펼치는 기능은 다음 단계인 재료 고르기 화면이 맡으므로 넣지 않는다.
- 기존 토큰(`--ex-*`)과 앱 셸을 그대로 쓴다. 화면 정의서는 이 화면만 구현과 달라지며 따로 고치지 않는다.
