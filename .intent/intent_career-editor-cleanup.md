# 커리어 편집기 옛 코드 정리 · 근거 블록 · 저장 상태 표시

## 개발 목표와 의도

본문 편집기를 BlockNote로 바꿨습니다(PR #137). 이제 모든 기록이 BlockNote로 열리지만, 옛 Tiptap 편집기 코드와 의존이 남아 있습니다. 문서 패널 머리말은 저장 여부와 상관없이 늘 「저장됨」을 보여 줍니다. 패널 아래 AI 영역은 처음 불러온 본문 사본으로 비교 화면을 그립니다. 근거 참조 블록은 BlockNote에 대응이 없어 문단으로 낮아집니다.

요청: "최종 완료까지 진행해" (2026-10-28, 구현 순서 1-3단계 승인)

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 옛 편집기 제거 | Tiptap 편집기, 옛 슬래시 메뉴 · 블록 손잡이 · 선택 툴바와 Tiptap 의존이 저장소에서 빠집니다. | 쓰지 않는 코드가 같은 일을 두 번 정의하고, 웹 묶음에 Tiptap 두 판이 함께 들어갑니다. |
| 저장 상태 표시 | 문서 패널과 전체 페이지에 「저장 중 · 저장됨 · 오프라인 · 충돌 확인 필요」가 실제 상태대로 보입니다. | 지금 패널은 늘 「저장됨」이라 연결이 끊겨도 알 수 없고, 전체 페이지에는 표시가 없습니다. |
| 패널 AI 비교의 최신 본문 | 패널 아래 AI 영역이 편집 중인 지금 본문을 기준으로 제안을 보여 줍니다. | 지금은 처음 불러온 본문 사본으로 비교해, 고친 뒤에는 바뀌기 전 문장이 틀리게 보입니다. |
| 근거 참조 블록 | 옛 기록의 근거 참조 블록이 출처 표시와 함께 그대로 열리고 저장됩니다. | 지금은 문단으로 낮아져 출처가 사라집니다. |
| 슬래시 메뉴 묶음 | 콜아웃이 「기본 블록」 묶음 안에 들어가 묶음 머리가 한 번만 보입니다. | 지금은 「기본 블록」 머리가 두 번 나옵니다. |

## 개발 목표

- 웹 패키지에 `@tiptap/*` 직접 의존이 없고, 옛 편집기 파일이 없습니다.
- API를 멈추면 패널 머리말이 「오프라인」으로, 다시 띄우면 「저장됨」으로 바뀝니다.
- 패널에서 문장을 고친 뒤 AI 편집을 요청하면 비교 화면의 「바뀌기 전」이 고친 문장입니다.
- `> [evidence:job:1] 문장`이 든 기록을 열면 출처가 붙은 근거 블록으로 보이고, 저장 뒤 `bodyMd`에도 남습니다.

## 범위 밖과 제약

- 근거 참조 블록을 새로 만드는 화면(공고 · 기록 고르기)은 없습니다. 지금 이 블록을 만드는 기능이 없어 보존과 표시만 합니다.
- 목록 · 뷰 화면은 다른 세션이 맡습니다. `DocumentPanel.tsx`는 머리말 상태 한 줄과 AI 영역 문서만 고칩니다.
