# 다듬기에서 디자인 선택으로 돌아가 다시 생성

## 개발 목표와 의도

다듬기 화면에서도 디자인을 다시 골라 포트폴리오를 새로 생성할 수 있게 한다.

> "포트폴리오 생성이 다듬기 단계까지 간 뒤에도 디자인 선택으로 돌아가서 다시 디자인을 선택하고 생성할 수 있게끔 하자."

다듬기 화면 위쪽 단계 줄에서 「디자인 선택」을 누르면 디자인 카탈로그가 아니라 같은 다듬기 화면이 다시 열린다. 디자인 선택 화면이 이미 끝난 생성을 다듬기로 되돌려 보내기 때문이다. 다시 뽑기로 가는 길이 화면에 없다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 다듬기의 「디자인 선택」 단계 링크 | 다듬기에서 단계 줄의 「디자인 선택」을 누르면 디자인 카탈로그가 열린다. 이전에 고른 디자인이 골라져 있다. | 지금은 눌러도 다듬기로 되돌아와서, 마음에 안 드는 디자인을 바꿀 길이 없다. |
| 카탈로그에서 다시 생성 | 카탈로그에서 디자인을 고르고 생성을 누르면 기존과 같은 생성 대기 화면을 거쳐 다듬기로 돌아온다. | 디자인을 고르는 것만으로는 결과가 바뀌지 않는다. 생성까지 이어져야 한다. |

## 개발 목표

- 단계 줄 이동: 생성이 끝난 포트폴리오의 다듬기에서 「디자인 선택」을 누르면 디자인 카탈로그가 열린다.
- 재생성: 다른 디자인을 골라 생성하면 대기 화면을 지나 다듬기가 새 결과로 열린다.
- 일반 흐름 유지: 디자인 선택 단계에서 아직 생성하지 않은 사용자는 지금과 같이 카탈로그를 본다.

## 범위 밖과 제약

- 생성 대기 화면, 생성 횟수 한도, 백엔드 재생성 처리는 바꾸지 않는다.
- 다듬기에서 고친 내용이 재생성 뒤 어떻게 남는지는 기존 백엔드 동작을 따른다.
