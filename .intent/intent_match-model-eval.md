# 적합도 모델 인코더 비교 · 평가 · 지연 측정 실험

## 개발 목표와 의도

설계서 4.4와 9.2는 인코더 4종 비교, ROC · AUC, 스크리닝 Recall@K, 모델 B NDCG@10, p95 지연을 요구한다. 지금 9.2 「지표별 측정 현황」에는 이 다섯 칸이 모두 「측정하지 않음」으로 남아 있다. 10/27에 파일럿 코드를 main에 들인 뒤로 학습 커밋은 없다. 오늘은 12주차이고 13주차가 완료 보고서 주간이다.

> "PC는 지금 접근 불가능. 오늘 저녁부터 접근 가능. 지금 맥에서는 그 전에 실험 설계와 코드 개발만 진행"

이번 변경은 오늘 저녁 학습 PC(RTX 5080)에 앉으면 명령만 차례로 돌려 다섯 칸을 채울 수 있게 만든다. 데이터는 파일럿 `fit-v1` 10,000쌍을 그대로 쓴다. 새 라벨이 필요한 일은 이번 주 안에 끝나지 않는다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 인코더 비교 실행 | `--encoder e5`처럼 인코더를 고르면 같은 데이터와 같은 MLP로 학습하고, 검증 분할 성능과 임베딩 시간 · 처리량 · GPU 메모리 · 벡터 저장 용량 · 잘린 비율을 한 표로 남긴다 | 설계서 4.4 2단계가 인코더를 비교 실험으로 정하라고 한다. 지금 코드는 E5만 돈다 |
| ROC · AUC | 평가 결과에 60점 이상을 양성으로 둔 ROC 좌표와 AUC가 들어간다 | 9.2가 양식 보조 지표로 요구하고 그림 9.5 자리가 비어 있다 |
| 스크리닝 Recall@K | 평가 프로필마다 평가 분할 공고 228건 전체를 Bi-Encoder+MLP로 채점하고, 적합 공고가 상위 K 안에 드는 비율을 K마다 곡선으로 남긴다 | 지금 Recall@10은 후보가 10개라 항상 1이다. 스크리닝 후보 수 K를 정할 근거가 없다 |
| 모델 B 평가 | (공고, 기록 1건) 쌍을 Cross-Encoder · 코사인 · 현행 규칙으로 채점하고, 교사가 요건에 연결한 기록을 정답으로 NDCG@10을 낸다 | 9.2가 모델 B를 「측정하지 않음」으로 둔다. 교사 판정에 근거 기록이 이미 있어 새 라벨 없이 잴 수 있다 |
| 규칙 baseline | 서비스의 실제 규칙 함수(일치도 · 재료 순위)로 같은 쌍을 채점한다 | 9.2 시험절차가 규칙 baseline과 비교하라고 한다. 파일럿은 규칙 함수를 비교하지 않았다 |
| 공고쌍 순서 일치율 5점 기준 | 정답 차가 5점 이상인 공고쌍만 센 순서 일치율을 함께 낸다 | 설계서는 5점 이상으로 정의하지만 파일럿 코드는 1점 차이도 셌다 |
| CPU 지연 측정 | 학습한 모델을 ONNX로 내보내 맥이나 운영 서버 CPU에서 p50 · p95 지연을 잰다 | Cross-Encoder 유지 여부를 p95로 정하기로 했는데 한 번도 재지 않았다 |
| 산출물 표준화 | 실행마다 `bi-v1-001` 같은 버전 폴더에 `metrics.json` · `metadata.json`이 생긴다 | 설계서 4.4가 정한 산출물인데 파일럿은 다른 이름으로 썼다 |
| 오늘 저녁 실행 절차 | 데이터 확인부터 실험 순서까지 PC에서 따라 칠 명령을 문서로 둔다 | PC 시간이 한정돼 있다. 중간에 끊겨도 앞 순서의 수치가 남게 한다 |

## 개발 목표

- 맥에서 `pnpm ml:data:test`가 새 테스트까지 통과한다.
- 맥에서 작은 무작위 모델로 ONNX 내보내기와 지연 측정 명령이 돌고 p50 · p95가 출력된다.
- 가짜 데이터 10쌍으로 인코더 비교 · 평가 명령이 끝까지 돌고 `metrics.json`에 ROC 좌표 · AUC · Recall@K 곡선 · 모델 B NDCG@10 · 규칙 baseline이 들어간다.
- 실행 절차 문서만 보고 PC에서 첫 명령부터 칠 수 있다.

## 범위 밖과 제약

- 새 교사 라벨링(Sonnet 5.5), 합성 프로필 v5, 후보 구성 v2, 사람 평가 세트는 하지 않는다. 이번 주 안에 끝나지 않는다.
- 추론 서비스와 백엔드 연결(`MATCH_MODEL`)은 하지 않는다. 오늘 밤 지연 수치를 보고 정한다.
- 설계서 본문은 고치지 않는다. 수치가 나온 뒤 따로 반영한다.
- 실제 학습은 맥에서 하지 않는다. 데이터와 가중치가 PC에만 있다.

## 열린 질문

- 파일럿 가중치가 PC에 남아 있는가. 없으면 Bi-Encoder+MLP와 Cross-Encoder를 다시 학습한다. 실행 절차에 두 경우를 모두 적는다.
