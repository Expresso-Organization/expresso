# 사이드바 크레딧 카드 사용량 섹션 연결

## 개발 목표와 의도

사이드바 아래의 「이번 달 크레딧 4 / 100」 카드는 지금 눌러도 아무 일이 없다. 숫자를 보고
어디에 얼마를 썼는지 궁금해진 사용자는 설정을 따로 열고 사용량 구획을 다시 찾아야 한다.
요청은 "이거 누르면 설정 창의 사용량 섹션으로 가도록 하자"이다. 카드를 누르면 설정 화면이
열리고 사용량 구획이 화면 맨 위에 선다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 크레딧 카드 링크 | 사이드바의 크레딧 카드를 누르면 설정 화면(`/account`)의 사용량 구획으로 이동한다. | 카드가 사용량 숫자를 보여 주는데 자세한 내역으로 가는 길이 없다. |
| 누를 수 있다는 표시 | 마우스를 올리면 카드 테두리가 진해지고, 키보드로 옮기면 포커스 표시가 생긴다. | 지금 모양은 정보 카드라서 눌러지는 자리인지 알 수 없다. |
| 접힌 사이드바에서 제외 | 사이드바를 접어 카드가 사라지면 키보드 Tab도 이 카드에 멈추지 않는다. | 보이지 않는 링크에 포커스가 가면 키보드 사용자가 어디 있는지 잃는다. |

## 개발 목표

- 카드 이동: 어느 앱 화면에서든 크레딧 카드를 누르면 주소가 `/account#usage`가 되고 사용량 구획이 맨 위에 보인다.
- 설정 화면 안에서 누를 때: 이미 설정 화면 아래쪽에 있어도 사용량 구획으로 올라간다.
- 표시: 카드에 마우스를 올리면 테두리 색이 바뀐다.
- 접힘: 사이드바를 접은 상태에서 Tab을 눌러도 크레딧 카드에 포커스가 가지 않는다.

## 범위 밖과 제약

- 포트폴리오 만들기 화면의 재료 고르기 카드(같은 「이번 달 크레딧」 문구)는 바꾸지 않는다.
- 카드의 모양·숫자·게이지는 그대로 둔다.
