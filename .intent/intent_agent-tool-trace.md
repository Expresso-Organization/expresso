# 에이전트 채팅 도구 호출 복구와 작업 흔적 표시

## 개발 목표와 의도

공고 상세의 Expresso AI 채팅에서 "응. 내 기록이랑 대조해서 정리 좀 해줘"라고 보내면, AI가 "사용자의 커리어 기록을 먼저 확인하겠습니다."라고 쓴 뒤 `{"tool":"list_career_records","arguments":{}}` 같은 글자를 본문에 그대로 남기고 답을 끝낸다. 기록을 읽지도, 대조하지도 않는다. 이번 변경은 AI가 기록 목록 · 기록 읽기 · 요건 대조 같은 도구를 실제로 부르게 되돌린다.

함께, AI가 도구를 부르는 동안과 끝난 뒤의 흔적을 채팅 화면에 보이게 한다. 요청자의 말: "모델이 도구 호출하면, 적절한 애니메이션과 시각 효과와 함께 채팅 화면이 툴 콜링 흔적이 예쁘게 나타나도록". 지금은 도구 하나마다 테두리 상자가 쌓이고, 기록 목록 확인 · 기록 읽기는 끝난 상태로만 나타나 진행 중인 모습이 없다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 도구 호출 복구 | AI가 기록 목록 확인 · 기록 읽기 · 요건 대조 · 기록 변경 제안 등 9개 도구를 실제로 부른다. 본문에 도구 이름이나 JSON이 찍히지 않는다. | 지금은 도구가 하나도 불리지 않아 채팅의 핵심 기능(기록과 공고 대조, 기록 초안, 준비 계획)이 전부 멈춰 있다. |
| 도구가 빠지면 실패로 알림 | AI 실행 준비 단계에서 도구가 하나라도 빠지면 그 답변을 "실패"로 끝내고 다시 보내기 버튼을 보여 준다. | 같은 종류의 고장이 다시 생겨도 사용자가 가짜 도구 호출 글을 답으로 받지 않는다. |
| 도구 실행 중 표시 | 모든 도구가 시작할 때 "실행 중" 줄을 먼저 띄우고, 끝나면 같은 줄이 "완료"나 "실패"로 바뀐다. | 기록 목록 확인 · 기록 읽기는 지금 끝난 뒤에야 나타나, AI가 무엇을 하는지 기다리는 동안 알 수 없다. |
| 작업 흔적 타임라인 | 한 답변 안의 도구 호출이 왼쪽 세로선으로 이어진 단계 목록으로 보인다. 새 단계가 생기면 선이 그 단계까지 내려오며 이어지고, 실행 중인 단계의 점은 돌고 이름은 빛이 지나가며, 완료되면 점이 체크로 바뀌고 요약이 펼쳐진다. | 도구마다 쌓이는 테두리 상자 대신 AI가 거친 순서를 한눈에 따라갈 수 있다. |

## 개발 목표

- 공고 채팅에서 "내 기록이랑 대조해서 정리해 줘"를 보내면 본문에 도구 이름 · JSON이 없고, 작업 흔적에 "기록 목록 확인", "기록 읽기", "요건 대조"가 차례로 나타난다.
- 도구가 실행되는 동안 그 단계 점이 돌고, 끝나면 체크로 바뀌며 요약("기록 N개를 확인했습니다.")이 보인다.
- 요건 대조 · 새 기록 초안 같은 카드와 기록 변경 제안의 승인 화면은 지금처럼 동작하고, 타임라인의 한 단계로 붙는다.
- 운영체제의 "동작 줄이기"를 켜면 회전 · 빛 지나감 · 선 그리기 없이 상태만 바뀐다.

## 범위 밖과 제약

- 채팅의 다른 화면(입력창, 대화 목록, 자료 연결)과 카드 내용은 바꾸지 않는다.
- 색 · 크기 · 모션은 `tokens.css`에 있는 값만 쓴다.
- Agent SDK 버전은 올리지 않는다.
