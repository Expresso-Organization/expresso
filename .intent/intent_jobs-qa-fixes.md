# QA 지적 세 건 — 입력 칸 · 비슷한 검색 · 마감순

## 개발 목표와 의도

팀 QA 문서(Discord #qa 11-13)의 개발 항목 세 건을 고친다. 「테이블 · 보드 · 타임라인이 모두 필요한가」는 기획 판단이라 이 변경에 넣지 않는다.

1. 커리어 기록의 제목 · 속성 칸이 비어 있으면 어디에 입력하는지 보이지 않는다. 칸이 투명하고 안내 문구가 없다.
2. 공고 검색의 「비슷한 검색」에 「ㄹ옹로」처럼 입력하다 만 검색이 뜬다. 최근 검색을 그대로 권해서다.
3. 장소로 찾은 뒤 「마감 순」을 눌러도 마감 순서가 뒤섞인다. 장소 검색은 고른 정렬과 상관없이 가까운 순을 먼저 걸었다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 빈 칸 안내 문구 | 빈 제목 칸에 「제목 없음」, 빈 속성 칸에 「비어 있음」을 옅은 색으로 | 입력할 자리가 보여야 한다 |
| 비슷한 검색 거르기 | 조합하다 만 글자가 든 검색, 0건이었던 검색은 권하지 않는다 | 누르면 다시 빈 결과가 나오는 검색을 권하지 않는다. 「최근 검색」 기록은 그대로 |
| 고른 정렬 우선 | 장소 검색에서 「마감 순」 · 「최신 순」을 고르면 그 순서가 먼저, 거리는 같은 값끼리만 정한다. 기본 정렬은 지금처럼 가까운 순 | 고른 정렬이 화면에 그대로 보여야 한다 |

## 개발 목표

- 제목이 빈 기록을 열면 제목 자리에 「제목 없음」이 보인다.
- 「ㄹ옹로」를 검색한 뒤 다른 검색을 하면 「비슷한 검색」에 「ㄹ옹로」가 없다.
- 「판교」로 찾고 「마감 순」을 누르면 마감이 가까운 공고부터 온다.
