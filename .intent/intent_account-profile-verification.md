# 설정 프로필 화면과 이메일 인증 안내 자리 이동

## 개발 목표와 의도

아직 주소를 확인하지 않은 계정으로 로그인하면, 앱의 어느 화면을 열어도 본문 맨 위에
누런 띠가 가로로 붙는다. 홈·커리어·제작·편집기 어디서든 같은 문장이 반복되고, 띠가
본문을 한 줄씩 아래로 밀어낸다. 지금 하려던 일과 상관없는 안내가 모든 화면을 차지한다.

사용자의 말 — "이거 띄우지 말고, 메일 인증 안내는 설정-프로필에서 띄우도록 하자".

인증 상태는 계정에 속한 사실이므로 계정을 보는 자리에 둔다. 설정 화면의 좌측 탭에는
「프로필」이 이미 있지만 눌러도 아무 일이 일어나지 않는다. 이 탭을 실제 화면으로 만들고
인증 안내를 그 안에 세운다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 상단 인증 안내 띠 제거 | 앱 화면 맨 위에 붙던 누런 띠가 사라진다. 모든 화면이 본문부터 시작한다. | 인증 여부는 지금 하려던 일과 무관한데도 모든 화면의 첫 줄을 차지하고 본문을 밀어낸다. 띠를 닫을 방법도 없다. |
| 설정 · 프로필 화면 | 설정 좌측 탭의 「프로필」을 누르면 열리는 화면. 계정의 표시 이름과 로그인 주소를 보여 준다. | 탭은 있는데 눌러도 아무 일이 없다. 인증 안내를 둘 자리가 먼저 있어야 한다. |
| 프로필 화면의 인증 안내 | 로그인 주소 줄에 인증 여부가 함께 선다. 아직이면 「인증 메일 보내기」 버튼과 공개 발행이 막혀 있다는 한 줄이 그 자리에 붙고, 확인된 계정이면 확인한 날짜만 남고 버튼이 없다. | 인증 메일을 다시 받을 방법이 띠 하나뿐이었다. 띠를 지우면 이 자리가 유일한 입구가 된다. |
| 설정 좌측 탭 이동 | 「프로필」과 「요금제 · 사용량」을 누르면 각 화면으로 간다. 지금 보고 있는 탭이 강조된다. | 두 화면을 오갈 방법이 없으면 프로필 화면에 들어갈 수도, 거기서 나올 수도 없다. |
| 배포 실패 안내 문구 교체 | 인증 전에 포트폴리오를 공개하면 나오는 빨간 줄이 "화면 위쪽 안내에서" 대신 "설정 → 프로필에서" 받으라고 말한다. | 지금 문구는 사라질 띠를 가리킨다. 그대로 두면 없는 자리를 찾아 헤매게 된다. |

## 개발 목표

- 인증하지 않은 계정으로 홈·커리어·제작 화면을 열면 본문 위에 아무 띠도 없다.
- 설정 화면 좌측의 「프로필」을 누르면 `/account/profile`이 열리고, 로그인 주소 줄에
  「인증 메일 보내기」 버튼이 보인다. 누르면 "메일을 보냈습니다"로 바뀐다.
- 인증을 마친 계정으로 같은 화면을 열면 로그인 주소 줄에 확인한 날짜만 있고 버튼이 없다.
- 프로필 화면에서 「요금제 · 사용량」을 누르면 기존 설정 화면으로 돌아간다.
- 인증 전 계정으로 포트폴리오를 공개하면 배포 화면의 빨간 줄이 설정 → 프로필을 가리킨다.

## 범위 밖과 제약

- 표시 이름·비밀번호를 고치는 기능은 넣지 않는다. 백엔드에 해당 API가 없다.
- 「결제」·「알림」·「데이터 관리」 탭은 지금처럼 눌리지 않는 자리로 둔다.
- 백엔드는 건드리지 않는다. 발행을 막는 검사(`publishing/routes.ts`)와 인증 메일 발송
  API는 이미 동작하므로 그대로 쓴다.
- 배포 실패 줄은 문장만 바꾸고 누를 수 있는 링크로 만들지 않는다. 그 줄은 지금 문자열
  하나로 그려지므로 링크를 넣으려면 배포 화면의 결과 구조를 함께 바꿔야 한다.
- 프로필 화면에 요금제를 적지 않는다. 세션에는 요금제 코드(`free`·`pro`·`team`)만 있고
  이것을 사람이 읽는 이름으로 바꾸는 표가 웹에 없다. 이름을 새로 지어 붙이지 않는다.
