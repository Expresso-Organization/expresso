# 인증서 DNS 갱신 자동화

Expresso 와일드카드 인증서가 사람의 TXT 등록 없이 갱신되게 한다. 사용자는 DNS 관리 연결과 자동화를 승인했다.

인증용 하위 DNS만 기존 서버에 위임하고, Certbot 훅이 토큰을 안전하게 추가·제거한다. 기존 서비스 레코드와 유효 인증서는 유지한다. 실제 DNS 위임과 외부 53번 개방은 구체적 변경 내용을 보여 주고 실행 시점에 확인받는다.

완료 기준은 외부 DNS 응답과 Certbot staging 갱신 성공, 기존 갱신 timer 연결이다. intent 자동 수락 지침에 따라 진행한다.
