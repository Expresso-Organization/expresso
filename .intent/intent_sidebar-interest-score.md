# 사이드바 관심 공고 일치도 표시 제거

## 개발 목표와 의도

좌측 사이드바의 관심 공고 줄 오른쪽에는 그 공고의 일치도(0–100)나 "분석 대기"가 붙어 있다.
요청자는 화면에서 `(주)핀인사이트 … 0`을 보고 이 숫자가 무엇인지 물었다. 같은 사이드바의 다른
오른쪽 숫자(공고 탐색 `1`, 경험 `1`, 학력 `0`)는 모두 건수인데, 이 줄만 단위 없는 백분율이라
"0건"으로 읽힌다. 요청자의 결정은 "지우자"다. 줄 오른쪽 값을 없애고, 헤더의 건수는 남긴다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 줄 오른쪽 일치도 숫자 제거 | 관심 공고 각 줄 끝의 `0`, `92` 같은 숫자가 사라진다. | 단위가 없어 건수로 읽히고, 이미 지원하려고 담은 공고라 사이드바에서 이 숫자로 정할 일이 없다. 점수와 근거는 공고 상세에서 본다. |
| 줄 오른쪽 "분석 대기" 제거 | 일치도가 없는 공고 줄 끝의 "분석 대기" 글자가 사라진다. | 요건을 읽지 못한 공고는 기다려도 점수가 생기지 않는데 같은 글자가 붙어 사실과 다르다. 이 글자가 회사·공고 이름을 더 짧게 자른다. |
| 화면 정의서 같은 줄 수정 | 정의서 사이드바의 관심 공고 줄에서도 `92` · `78` · "분석 대기"가 사라진다. | 정의서가 기준이라, 남겨 두면 다음 작업에서 다시 붙는다. |

## 개발 목표

- 앱 화면 사이드바의 관심 공고 줄이 회사 로고와 "회사 · 공고 제목"만 보여 준다.
- 관심 공고 헤더에는 담은 공고 건수(예: `2`)와 `+` 버튼이 그대로 있다.
- 줄 오른쪽 값이 빠진 만큼 공고 이름이 더 길게 보인다.
- `docs/Expresso Screens.dc.html`을 열면 사이드바 관심 공고 줄 끝에 숫자나 "분석 대기"가 없다.

## 범위 밖과 제약

- 공고 상세 · 공고 탐색 · 홈의 일치도 표시는 그대로 둔다.
- 일치도 계산과 API 응답(`match`)은 바꾸지 않는다.
