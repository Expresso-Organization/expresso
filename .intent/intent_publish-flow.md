# 편집에서 배포 · 재배포 · 공개 중단까지 이어지는 배포 흐름

## 개발 목표와 의도

요청은 "편집에서 배포, 재배포, 공개 중단까지 이어지는 화면을 고친다"입니다. 지금 배포 화면(`/edit/{id}/deploy`)과 편집 화면 상단을 따라가 보면 다음 문제가 있습니다.

- 배포한 뒤 내 포트폴리오가 어디에 열렸는지 바로 열거나 복사할 곳이 없습니다. 「열어 보기」는 공개 주소(`{주소}.expresso.ai.kr`)가 아니라 앱 안의 `/site/{주소}`를 엽니다.
- 「공개 중단」과 「되돌리기」는 누르는 즉시 실행됩니다. 공개 중단은 방문자가 보던 주소를 바로 닫는데도 확인을 묻지 않습니다.
- 공개를 중단한 뒤 같은 판을 다시 여는 길이 없습니다. 다시 열려면 고친 것이 없어도 새 판을 배포해야 합니다.
- 상단 「vN 배포」 버튼은 배포가 진행되는 동안에도 눌려, 두 번 누르면 판이 두 개 생길 수 있습니다. 배포할 지면이 없을 때도 눌립니다.
- 편집 화면의 버튼은 상태와 상관없이 늘 「배포하기」입니다. 고친 내용을 다시 내보내야 하는지, 이미 최신인지 버튼만 봐서는 알 수 없습니다.

이번 변경이 끝나면 사용자는 편집 화면에서 지금 상태에 맞는 버튼으로 배포 화면에 가고, 배포 화면 맨 위에서 공개 상태와 실제 공개 주소를 보고 바로 열거나 복사합니다. 공개 중단과 되돌리기는 무엇이 바뀌는지 확인한 뒤 실행되고, 중단한 포트폴리오는 같은 판으로 다시 열립니다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 공개 상태 머리 | 배포 화면 맨 위에 지금 상태(아직 배포 전 · 공개 중 vN · 공개 중이지만 고친 내용이 아직 안 나감 · 공개 중단)와 실제 공개 주소가 보입니다. 주소 옆 「열기」는 새 탭에서 공개 주소를 열고, 「복사」는 주소를 복사합니다. | 배포한 사람이 가장 먼저 하는 일은 주소를 열어 보고 지원서에 붙이는 것인데, 지금은 주소 입력칸 안의 글자뿐이고 앱 안 경로로 열립니다. |
| 공개 중단 확인 | 「공개 중단」을 누르면 확인 창이 뜨고, 주소가 바로 닫히며 문서와 기록은 남는다는 것, 언제든 다시 공개할 수 있다는 것을 알린 뒤 실행합니다. | 방문자가 보던 주소를 닫는 일을 한 번의 클릭으로 하면 실수로 누른 경우 지원서에 붙인 링크가 바로 깨집니다. |
| 다시 공개 | 공개를 중단한 포트폴리오는 상태 머리와 판 목록의 현재 판에 「다시 공개」가 보이고, 누르면 같은 판이 같은 주소로 다시 열립니다. 새 판을 만들지 않습니다. | 지금은 다시 열려면 고친 것이 없어도 새 판을 배포해야 하고, 그 사실을 화면이 알려 주지 않습니다. |
| 되돌리기 확인 | 지난 판의 「되돌리기」를 누르면 "vN을 공개할까요?" 창이 뜨고, 지금 공개 중인 판은 목록에 남고 편집본은 바뀌지 않는다는 것을 알린 뒤 실행합니다. | 되돌리기는 방문자가 보는 내용을 바로 바꾸는 일이라 무엇이 바뀌는지 알고 눌러야 합니다. |
| 배포 버튼 상태 | 배포하는 동안 버튼이 「배포하는 중」으로 바뀌고 다시 눌리지 않습니다. 배포할 지면이 없으면 눌리지 않습니다. 첫 배포는 「v1 배포」, 그 뒤로는 다음 판 번호로 보입니다. | 두 번 눌러 판이 두 개 생기거나, 지면이 없는데 눌러서 오류를 받는 일을 막습니다. |
| 결과 알림의 주소 | 배포 · 다시 공개 뒤 알림에 공개 주소가 링크로 들어갑니다. | 방금 나간 판을 확인하러 가는 길이 알림 안에 있어야 합니다. |
| 편집 화면 배포 버튼 | 편집 화면 상단 버튼이 상태를 따릅니다. 아직 배포 전이면 「배포하기」, 공개 뒤 고친 내용이 있으면 「다시 배포」, 공개본이 최신이면 「배포 관리」, 공개 중단이면 「다시 공개」로 보이고 모두 배포 화면으로 갑니다. | 고친 내용을 다시 내보내야 하는지 편집 화면에서 바로 알 수 있어야 재배포를 잊지 않습니다. |

## 개발 목표

- 배포 화면 맨 위에서 공개 상태와 실제 공개 주소를 보고, 새 탭으로 열거나 복사할 수 있다.
- 「공개 중단」과 「되돌리기」는 확인 창을 거쳐야 실행된다.
- 공개 중단한 포트폴리오를 「다시 공개」로 같은 판 · 같은 주소로 다시 연다. 판 번호가 늘지 않는다.
- 배포하는 동안 배포 버튼을 다시 누를 수 없다.
- 편집 화면 상단 버튼 이름이 배포 상태를 따른다.

## 범위 밖과 제약

- 서버 API는 바꾸지 않습니다. 다시 공개는 이미 있는 되돌리기 API를 현재 판에 부르는 방식입니다(서버의 되돌리기가 상태를 공개로 바꿉니다).
- 사용자 도메인 연결, 주소 체계 변경은 하지 않습니다.
- 배포 전 확인 항목(사전 확인)의 내용과 검색 노출 · 연락처 설정은 그대로 둡니다.

## 열린 질문

- 고친 것이 없을 때도 새 판 배포를 막지 않았습니다. 주소 · 검색 노출 · 연락처를 바꾸려면 새 판을 내야 하기 때문입니다. 막기를 원하면 버튼의 비활성 조건 한 줄이 바뀝니다.
- 편집 화면에서 공개 중단 상태의 버튼을 「다시 공개」로 두고 배포 화면으로 보냅니다. 편집 화면에서 바로 다시 열기를 원하면 확인 창을 편집 화면에도 둡니다.
