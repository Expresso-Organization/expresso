# 녹화된 AI 응답

`AI_PROVIDER=claude-code AI_RECORD=true`로 돌린 호출이 여기 쌓입니다.
`AI_PROVIDER=fixture`는 이걸 재생합니다 — 네트워크도 쿼터도 쓰지 않고 결정적입니다.

경로는 `<계약>/<호출키>.json`이고, 호출키는 계약 · 프롬프트 · 프롬프트 버전 ·
모델 티어 · 스키마를 합친 sha256입니다. 그래서 **프롬프트를 고치면 다른 파일이
됩니다** — 낡은 녹화가 조용히 재생되지 않습니다.

여기 담기는 것은 **모델이 낸 그대로**입니다. 근거 구간을 찾아 붙이고 원문에 없는
인용을 버리는 일은 그 뒤에 일어납니다(`ai-extractor.ts`). 그래서 픽스처를 보면
모델이 무엇을 냈는지, 우리가 무엇을 걸러냈는지 둘 다 보입니다.

## 무엇을 보는가

픽스처는 두 가지를 봅니다. 구현 명세서 §8.3이 규칙을 그렇게 두 벌로 적어 뒀습니다.

**품질 — 결과물이 보여줄 만한가.** 이게 제품이 파는 것입니다(P0). 문장이 그
지원자에게만 해당하는 사실을 담았는지, 기록에 있던 숫자와 도구 이름이 살아
있는지, 공고의 말투로 쓰였는지. 탐색하다 마음에 드는 결과가 나오면 그대로
골든이 되고, 프롬프트를 고쳤을 때 **지면이 밋밋해지지 않았는지**를 이걸로 봅니다.

**안전 — 틀린 것이 새어 나가지 않는가.** 지어낸 수치, 원문에 없는 인용, 스키마는
맞지만 근거가 틀린 응답. 이런 적대적 픽스처는 손으로 만들어 넣고, 도메인
검증기(`validateExtractionSource` · `validateGenerationOutput`)와 DB 트리거가
막는지 봅니다.

둘 다 통과해야 사용자에게 보여줍니다. 안전만 통과한 밋밋한 지면은 실패입니다.
