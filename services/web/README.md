# Expresso Web

Expresso 제품 웹 서비스입니다. **아직 착수 전이며 스택이 정해지지 않았습니다.**

## 제품 요약

커리어 기록을 평소에 쌓아 두고, 채용 공고에 맞춰 포트폴리오를 만들어 배포하고,
방문 데이터로 다음 행동을 잡는 서비스입니다.

```
커리어 기록  →  공고 분석  →  AI 인터뷰  →  레시피  →  생성  →  편집  →  배포  →  통계
    D1          D2 D3         D5          D6       D7      D8      D9      D10
```

전역 제약 — 명세의 모든 도메인에 걸립니다.

1. AI 산출물에는 근거(공고 인용 · 기록 ID · 질문 번호)가 반드시 있고, 없으면 화면에 띄우지 않는다
2. 사용자가 직접 고친 내용은 AI 재생성 대상에서 제외한다 (잠금)
3. 사용자가 말하거나 기록한 적 없는 수치·사실을 생성하지 않는다
4. 모든 작업은 자동 저장하고, 되돌릴 수 없는 조작은 확인을 받는다
5. 30초 이상 걸리는 작업은 백그라운드로 진행하고 창을 닫아도 계속된다

## 착수 전에 정할 것

스택이 결정되지 않았습니다. 데이터 모델 명세서는 PostgreSQL을 전제로 쓰여 있습니다
(uuid PK · `timestamptz` · `jsonb` · snake_case). 프론트엔드·백엔드 프레임워크,
AI 모델 연동 방식, 배포 대상은 미정입니다.

기능 범위 자체에도 미결 항목이 있습니다 — 기능 명세서 **부록 B** 참고:

- **B1** 공고 수집 경로 (공식 API · 제휴 · 사용자 입력 전용) → D2 전체 범위가 여기서 갈립니다
- **B2** 업계 비교 데이터의 초기 노출 여부
- **B3** 공동 편집 모드의 상호작용 방식
- **B4** 로그인·온보딩·설정·결제 화면 미설계
