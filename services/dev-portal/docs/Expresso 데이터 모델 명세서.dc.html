Expresso 데이터 모델 명세서

기능 명세서 D1–D12의 태스크에서 도출한 물리 스키마입니다. 테이블·컬럼 정의와 제약, 관계의 삭제 정책, 상태 전이, 보존 규칙을 담습니다. 전체 구조를 한눈에 보려면 데이터 구조 다이어그램을 함께 보십시오.

표기 규칙 — 테이블·컬럼명은 snake_case, 모든 PK는 uuid, 시각은 timestamptz(UTC 저장 · 표시 시 변환).
jsonb 사용 기준 — 사용자마다 형태가 달라지는 값(속성 스키마 · 근거 배열 · 위젯 배치)만 jsonb로 두고, 질의·집계 대상이 되는 값은 컬럼으로 승격합니다.
소유자 격리 — 사용자 데이터를 담는 모든 테이블은 user_id를 갖고, 모든 질의는 소유자 조건을 먼저 적용합니다. 표에서는 지면상 생략된 경우가 있습니다.
enum — 값이 늘어날 수 있는 분류는 DB enum이 아니라 코드 테이블 또는 text + 체크 제약으로 둡니다(마이그레이션 비용).
