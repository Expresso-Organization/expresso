# T12 포트폴리오 읽기·편집·레이아웃·지면

## 구현

- 포트폴리오 목록·상세·revision/checkpoint 읽기를 MongoDB 컬렉션과 기존 Zod 응답 계약으로 옮겼다.
- 편집 preview/apply, stale proposal 차단, revision, 블록·섹션 구조 변경, 삭제 전 checkpoint, snapshot 복원을 하나의 MongoDB 트랜잭션 경계로 옮겼다.
- source record는 preview와 apply 시점에 다시 검사하고 career 공개 guard를 사용한다.
- 레이아웃 선택과 remix는 포트폴리오 소유권 및 현재 선택값을 재검사하며 partial unique index로 하나만 선택한다.
- generated page는 `(portfolioId, revision)`별 불변 문서로 저장하고 이전 HTML·CSS·QA·manifest·portfolio plan·style snapshot을 유지한다. Redis stream 인터페이스와 event 흐름은 변경하지 않았다.
- snapshot payload는 BSON 크기 8 MiB 이상에서 UTF-8 JSON을 1 MiB 조각으로 나누며, 순번·개수·조각 checksum·전체 checksum을 모두 검증한다. 생성 초기 snapshot, 편집 snapshot, recipe revision이 같은 계층을 사용한다.
