# T02 · 컬렉션·마이그레이션·초기 데이터

2026-08-29 직접 구현으로 전환한 뒤 완료했다. 외부 검토 에이전트는 실행하지 않았다.

## 변경

- 71개 제품 컬렉션과 6개 운영 컬렉션, BSON 저장 타입과 타입 지정 접근자.
- UUID 문자열, BSON Date·Decimal128, date-only 문자열, nullable partial unique 인덱스.
- 원본 TS·JSON 바이트 체크섬, 단계별 완료 기록, 재실행과 명시적 실패 복구.
- 만료만으로 재점유하지 않는 migration lease. 이전 실행 및 서버 명령 종료 확인과 token 비교가 복구 조건이다.
- 기존 MySQL seed 51행(요금제 3·카테고리 7·예약 작업 8·템플릿 33) 보존.
- 별도 DB를 만들고 자신이 만든 DB만 정리하는 공용 fixture.
- 최종 SQL 제약과 트리거 409개의 후속 도메인 책임 매핑. 외래 키·트리거가 MongoDB에서 자동 실행되는 것은 아니다.

## 검증

| 실행 | 결과 |
| --- | --- |
| `pnpm typecheck` | 통과 |
| `TEST_MONGODB_URL=… pnpm --filter @expresso/database test` | 11 통과, MySQL 전용 15 생략 |
| `node scripts/test-infra.mjs --mongo src/platform/mongodb.integration.test.ts` | 5 통과, 별도 standalone/restart 설정 2 생략 |
| 빌드된 `dist/index.js`로 신규 DB 마이그레이션 및 독립 MySQL 결과 대조 | 77개 컬렉션, seed 51행 전체 필드 일치 |
| `pnpm test` | 백엔드 222 통과. 기존 Windows Codex fixture 실패 4개 동일, 새 실패 없음 |

실제 테스트는 인증된 로컬 rs0를 사용했다. 기존 DB·운영 데이터에는 쓰지 않았고
각 테스트가 만든 `expresso_test_*` DB만 정리했다.
원시 로그는 `var/mongodb-run/T02-direct-{schema,fixture,typecheck,seeds,full-test}.log`다.

## 경계

서비스 실행 경로는 아직 기존 MySQL이다. 모든 도메인 전환 뒤 T17에서 한 번에 연결한다.
T19 운영 전환은 별도 승인이 필요하다. 커리어 편집기는 이번 변경에 포함하지 않는다.
