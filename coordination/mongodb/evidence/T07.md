# T07 · 공고 수집·검색

코디네이터 직접 구현·검토. MongoJobMarketService, MongoJobBoardService,
MongoJobIngestService는 기존 공개 API 타입을 구현한다.

- 수집의 외부 HTTP·AI·로고 호출은 트랜잭션 밖에서 실행한다.
- 원문/식별자/해시와 기존 분석 배열을 보존한다. 출처/externalId 및 본문 해시
  중복 경로와 동시 수집을 검증했다. 재수집 시 분류·지역·마감만 갱신한다.
- 회사 로고 Binary, 재시도 가능한 본문 분석, experienceMinYears 유지.
- 목록/집계는 같은 필터 builder와 facet을 사용한다. 각 facet은 자기 축만 제외한다.
- 점수 없는 공고·타인 관심/분석·리터럴 검색·회사 비율·정렬 동점 경계를 검사했다.
- 제출/분석 등록/Outbox와 사용자 변경은 트랜잭션으로 저장한다.
  관심/검색 저장 제한도 계정 guard로 동시성에 안전하게 적용한다.

검증:
- 기존 5개 통합 suite를 MySQL/MongoDB에서 재사용하고 추가 경합 사례도 실행:
  jobs 대상 95 통과, MySQL 사례 38 스킵.
- 전체 typecheck 및 backend build 통과.
- MongoDB/Redis 전체: 백엔드 343 통과, 기존 Windows Codex fixture 4 실패 동일.
- 격리 MySQL/Redis 회귀 통과.
- 실제 회사 필터 aggregation explain: 1,000개 중 선택 회사 10개,
  IXSCAN(job_posting_company_id_fkey), totalDocsExamined=10, nReturned=10.
  contains 검색의 전용 텍스트 인덱스 성능을 이 수치로 주장하지 않는다.
