# T14 검증 증적

## 구현

- 분석 이벤트 receipt와 payload digest를 트랜잭션으로 저장하고 동일 ID 충돌, 중복, owner 제외, section 체류시간, hot visitor rate limit을 MongoDB 원자 연산으로 처리했다.
- 일별 집계, 대시보드 view/widget/revision, 홈·검색 cursor, 알림 설정·수신함·재시도 경로를 MongoDB로 전환했다.
- 알림 설정은 `users.notificationPreferences`, 수신함은 별도 컬렉션으로 분리했고 0003 마이그레이션에 validator와 index를 추가했다.
