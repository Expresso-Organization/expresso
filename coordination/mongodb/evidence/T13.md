# T13 배포·미디어·내보내기

## 구현

- 배포 snapshot, version, 현재 deployment 포인터를 하나의 MongoDB 트랜잭션으로 확정하고 T12 snapshot payload를 사용한다.
- 공개 slug 현재 포인터 검증, 30일 redirect, deployment 이력·rollback·unpublish를 MongoDB로 옮겼다.
- export job과 outbox를 함께 등록하고 중복 worker를 1개 asset·attempt로 수렴시켰다. resume 교체 시 이전 asset의 nonce와 revoked 상태를 함께 갱신한다.
- 미디어 디코딩·variant 생성·storage 쓰기는 트랜잭션 밖에서 수행하고, DB 확정 실패 시 자신이 쓴 content key를 정리한다. checksum과 variant width unique를 유지한다.
- 모든 쓰기 경로가 활성 owner guard를 다시 통과한다.

## 검증

- backend typecheck 통과.
- Mongo T13 통합 테스트 4건 통과.
  - 두 사용자 동일 slug 경쟁에서 배포 1건만 성공.
  - 불변 배포 판, 30일 redirect 만료, rollback, unpublish.
  - export idempotency/outbox 1건, 중복 worker 1회 완료, 서명 만료와 resume 교체 무효화.
  - 미디어 checksum 중복 제거, 640/1200 width unique, 원본 byte 보존, 타 사용자 asset 배치 거부.
- 기존 MySQL 인프라 회귀: 34 파일·157 테스트 통과, 2 파일/149 테스트 건너뜀 (`var/mongodb-run/T13-final-legacy-infra.log`).
- `git diff --check` 통과.
