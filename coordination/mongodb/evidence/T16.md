# T16 검증 증적

## 구현

- 기본 dry-run, 명시적 `--apply`, `--verify-only`를 제공하는 MySQL→MongoDB 선택 이관 도구를 추가했다.
- 보존 범위를 source/company/posting/requirement로 고정하고 read-only snapshot, 열 manifest, keyset pagination, checkpoint, `_id` 멱등성, 전수 hash/reference/span 검증을 구현했다.
- 사용자 데이터와 지원하지 않는 테이블은 거절하며 전체 DB drop/truncate 경로는 만들지 않았다.

## 실제 리허설

- 기존 개발 MySQL을 읽기 전용으로 읽어 격리된 임의 MongoDB에 출처/회사/공고/요구사항 중 실제 존재한 10/11/14건을 이관했다.
- 동일 `IMPORT_RUN_ID`로 두 번 실행해 건수와 hash가 같음을 확인했고 대상 격리 DB만 삭제했다.
- 증적: `T16-import-first.log`, `T16-import-repeat.log`, `T16-import-scope.txt`.
- importer 테스트 4개 통과. MySQL prepared statement가 `LIMIT ?`를 거절하는 실제 문제를 발견해 정수 검증 후 literal limit, cursor만 bind하도록 수정했다.
- 직접 검토에서 비밀/원문 로그 배제, 원본 변경 시 중단, 충돌 시 자동 덮어쓰기 금지를 확인하고 승인했다.
